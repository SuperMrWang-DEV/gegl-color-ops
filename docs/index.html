三分钟装上

  1. 解开压缩包

    把 29 个 .dll 放进 GEGL 的用户插件目录，目录不存在就自己建一个：

    %LOCALAPPDATA%\gegl-0.4\plug-ins

  2. 重启 GIMP

    没有安装步骤，也没有注册表。GEGL 启动时扫描这个目录，GIMP 跟着加载。

  3. 在菜单里找

    滤镜位于 图像 → 颜色 → SuperMrWang，按四个分类排开； 也可以按 / 搜算子名直接调。

这些算子是怎么来的

多数是按黑盒标定做的：拿目标实现（多为常见修图软件的调整图层）做对照，逐档采样、 拟合公式，再在 16 位精度上把残差压到几码以内——只看输入输出，不读对方的代码。 少数是直接实现公开的数学定义（Lab / LCh / HSL 色阶就是换了个色彩空间做同一件事）。

所以每篇算法说明里都有误差表、以及「哪一段没能对上、偏差多大」。没有说成 「完全一致」的地方，都是实测过确实对不上——例如色温 / 色调对角线上的硬裁切。

算法来源在文件头 reference 字段里逐条标注，源码与文档在同一个仓库。
