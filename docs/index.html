两个目录，三个动作Two directories, three moves

  1. 模块进 GEGLModules into GEGL

    解压后把 .dll / .so 整个扔进 GEGL 的模块目录。Unpack and drop every .dll / .so into GEGL's module directory.

    Windows  %LOCALAPPDATA%\gegl-0.4\plug-ins
Linux    ~/.local/share/gegl-0.4/plug-ins

  2. .py 进 GIMPScripts into GIMP

    插件包里的 .py 放进 GIMP 的插件目录，两处都要放，缺一个就报「找不到过程」。The plug-in bundle's .py files go into GIMP's plug-in directory. Both places — miss one and the procedure won't be found.

    Windows  %APPDATA%\GIMP\3.x\plug-ins
Linux    ~/.config/GIMP/3.x/plug-ins

  3. 重启 GIMPRestart GIMP

    完全退出再打开，菜单栏顶层就有 SuperMrWang（和「颜色」「图层」平级）。Quit completely and reopen: SuperMrWang is now a top-level menu, a sibling of Colors and Layer.
