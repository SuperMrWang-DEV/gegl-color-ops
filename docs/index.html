两个目录，三个动作Two directories, three moves

  1. 模块进 GEGLModules into GEGL

    解压后把 .dll / .so 整个扔进 GEGL 的模块目录，locale/ 也一起放（中文语言包，不放就只有英文）。Unpack and drop every .dll / .so into GEGL's module directory — together with locale/, the Chinese catalogue.

    Windows  %LOCALAPPDATA%\gegl-0.4\plug-ins
Linux    ~/.local/share/gegl-0.4/plug-ins

  2. .py 进 GIMPScripts into GIMP

    插件包里的 .py 放进 GIMP 的插件目录，两处都要放，缺一个就报「找不到过程」；_shared/ 与 locale/ 跟 .py 放同一层。The plug-in bundle's .py files go into GIMP's plug-in directory. Both places — miss one and the procedure won't be found. Keep _shared/ and locale/ at that same level.

    Windows  %APPDATA%\GIMP\3.x\plug-ins
Linux    ~/.config/GIMP/3.x/plug-ins

  3. 重启 GIMPRestart GIMP

    完全退出再打开，菜单栏顶层就有 SuperMrWang（和「颜色」「图层」平级）。Quit completely and reopen: SuperMrWang is now a top-level menu, a sibling of Colors and Layer.

这些算子是怎么来的Where these operators come from

黑盒标定 + 公开数学Black-box calibration, plus published maths

多数按目标实现逐档采样、拟合公式，在 16 位精度上把残差压到几码以内——只看输入输出， 不读对方代码；少数直接实现公开的数学定义。每篇算法说明都带误差表，以及「哪一段没能对上、 偏差多大」，没说成「完全一致」的地方都是实测确实对不上。Most are fitted against a reference implementation sample by sample, residual pressed to a few code values at 16-bit — inputs and outputs only, no source reading; a few implement published definitions directly. Every algorithm note carries an error table and says which part does not match, and by how much.
