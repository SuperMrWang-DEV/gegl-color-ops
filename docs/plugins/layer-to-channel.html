Layer to Channel

plugin/layer-to-channel 通道 图层转换

右键点一个图层，就把它变成一条新的 Alpha 通道，留档复用。恒为灰度： 黑 = 不选中、白 = 完全选中、中间灰 = 部分选中。想拿它当蒙版，就在通道 面板右键「通道到选区」（GIMP 原生）再回图层。

菜单位置

两处
  • 图层右键 → SuperMrWang → Layer to Channel
  • 选择 → SuperMrWang → Layer to Channel

两处是同一个动作，处理的是当前选中的那一个图层。图层组不行—— 组没有自己的像素，会直接报错并提示先合并。

脚本调用

lb-plugin-layer-to-channel(
    image, drawable, invert, name)

标准 PDB 过程，参数留空走默认值。

依赖

不依赖任何自研算子：直接读图层字节，只调 GIMP 自己的通道 PDB。

恒为灰度

语义明确

彩色图层先按亮度转成灰度，黑白图层原样——然后把这些灰度值写进通道。 没有「取 R 通道」这类选项：要的就是明暗，不给单色通道捣乱的机会。

通道值 = 该像素是否被选中
  黑 0     → 不选中
  中灰     → 部分选中
  白 255   → 完全选中

名字与反相

默认沿用图层名，可以自己改——通道面板里一眼能认出来。可反相， 建好后状态栏会提示通道名。

想把它变回选区：通道面板右键该通道 → 通道到选区（GIMP 原生）， 或者反过来用 Layer to Selection 直接从图层取。

为什么现成通道不行

复制粘贴能把灰度塞进通道，但会带上图层蒙版等显示效果， 而且要先新建通道、再定位粘贴为选区，四步。这里读的是原始像素， 一步，而且更快。

实测

23 条

tools/check_layer_to_mask.py：通道值、名字、反相、 彩色转通道 = 亮度、半透明图按 alpha 加权、有活动选区时通道不被截断 （写通道前先挂起选区，写完恢复）。

和 gray-mask 的分工

plugin/gray-mask 走复制粘贴，会带上显示效果（蒙版、 图层模式）；这两个插件读原始像素、不认显示效果，也更快。 要「所见即所得」用 gray-mask，要「数据本身」用这两个。
