Layer to Channel

plugin/layer-to-channel 通道 图层转换

右键点一个图层，就把它变成一条新的 Alpha 通道，留档复用。恒为灰度： 黑 = 不选中、白 = 完全选中、中间灰 = 部分选中。想拿它当蒙版，就在通道 面板右键「通道到选区」（GIMP 原生）再回图层。

菜单位置
  • 图层右键 → SuperMrWang → Convert → Layer to Channel
  • SuperMrWang → Convert → Layer to Channel

这几条是同一个动作，处理的是当前选中的那一个图层。图层组不行——组没有自己的像素，会直接报错并提示先合并。

脚本调用
lb-plugin-layer-to-channel( image, drawables, invert, name)

标准 PDB 过程，参数留空走默认值。

依赖

不依赖任何自研算子：直接读图层字节，只调 GIMP 自己的通道 PDB。

恒为灰度

语义明确

彩色图层先按亮度转成灰度，黑白图层原样——然后把这些灰度值写进通道。 没有「取 R 通道」这类选项：要的就是明暗，不给单色通道捣乱的机会。

通道值 = 该像素是否被选中
  黑 0     → 不选中
  中灰     → 部分选中
  白 255   → 完全选中

名字与反相

默认沿用图层名，可以自己改——通道面板里一眼能认出来。可反相， 建好后状态栏会提示通道名。

想把它变回选区：通道面板右键该通道 → 通道到选区（GIMP 原生）， 或者反过来用 Layer to Selection 直接从图层取。

为什么现成通道不行

复制粘贴能把灰度塞进通道，但会带上图层蒙版等显示效果， 而且要先新建通道、再定位粘贴为选区，四步。这里读的是原始像素， 一步，而且更快。

实测

23 条

tools/check_layer_to_mask.py：通道值、名字、反相、 彩色转通道 = 亮度、半透明图按 alpha 加权、有活动选区时通道不被截断 （写通道前先挂起选区，写完恢复）。

它取代了 gray-mask

原来的 plugin/gray-mask 走复制粘贴、会带上蒙版和图层模式， 但彩色层不按亮度转、也不管偏移，2026-11-18 已下线。这两个插件读 原始像素，更快也更准，转换就只剩这一条路。

Layer to Channel

plugin/layer-to-channel Channels Convert

Right-click a layer and it becomes a new alpha channel you can keep around. Always greyscale: black = not selected, white = fully selected, mid grey = partly selected. To use it as a mask, right-click it in the Channels tab and pick "Channel to Selection" (native GIMP), then come back to the layer.

Menu location
  • Layer right-click → SuperMrWang → Convert → Layer to Channel
  • SuperMrWang → Convert → Layer to Channel

These are all the same action, applied to the one layer you have selected. Layer groups do not work — a group has no pixels of its own, so the plug-in stops with an explicit error and asks you to merge first.

Scripting
lb-plugin-layer-to-channel( image, drawables, invert, name)

A standard PDB procedure; leave an argument empty to take its default.

Dependencies

No dependency on this project's operators: it reads layer bytes directly and only calls GIMP's own channel PDB.

Always greyscale

unambiguous

A colour layer is converted to luminance first, a black-and-white layer goes in as it is, and those grey values become the channel. There is no "take the R channel" option: the point is light and dark, without a single-colour channel getting in the way.

The channel value is whether the pixel is selected:

black 0    → not selected
mid grey   → partly selected
white 255  → fully selected

Name and invert

The channel takes the layer's name by default and you can change it, so it is recognisable in the Channels tab. It can be inverted, and the status bar shows the channel name once it is created.

To turn it back into a selection: right-click the channel → Channel to Selection (native GIMP), or go the other way and use Layer to Selection straight from the layer.

Why copy-paste is not enough

Copy-paste can put grey into a channel, but it carries display effects such as layer masks along, and you still have to create the channel first and then paste as a selection — four steps. This reads the raw pixels: one step, and faster.

Measured

23 assertions

tools/check_layer_to_mask.py: channel values, name, invert, colour layer to channel equals luminance, semi-transparent images weighted by alpha, and that the channel is not clipped by an active selection (the selection is suspended before the write and restored after).

It replaces gray-mask

The old plugin/gray-mask went through copy-paste and carried masks and layer modes, but it skipped luma conversion for colour layers and ignored offsets. Retired on 2026-11-18. These two read raw pixels — faster, and now the only way to convert.
