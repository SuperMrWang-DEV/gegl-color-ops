双曲线磨皮

plugin/dodge-burn 磨皮 Shortcut 快捷方式

提亮一条曲线、压暗一条曲线，各自压在一张全黑蒙版下。涂到哪里，哪里才变亮或变暗——没涂的地方与原图逐像素相同，所以可以反复叠加、随时反悔。

菜单位置

两处
  • 颜色 → SuperMrWang → Shortcut → 双曲线磨皮
  • 图层右键 → SuperMrWang → Shortcut → 双曲线磨皮

两处是同一个动作，处理的是当前选中的那一个图层。图层组不行—— 组没有自己的像素，会直接报错并提示先合并。

脚本调用

lb-plugin-dodge-burn(image, drawable, amount, group)

标准 PDB 过程，参数留空走默认值。

依赖

靠下面这些算子干活，装插件时它们必须已注册（build.sh 或 dll 包里都有）：

  • gimp:curves

生成的结构

两层 · 黑蒙版
双曲线磨皮              组 · 穿透（带 alpha 时组上还有蒙版）
  ├─ 2 · 压暗（黑蒙版）  正常 · 曲线下压
  ├─ 1 · 提亮（黑蒙版）  正常 · 曲线上提
  └─ 原图层（不动，可以隐藏）

两层都是「正常」模式，各挂一条 gimp:curves（值通道）； 蒙版全黑，所以刚建好时两层根本不参与合成——结果与原图逐像素相同。

涂的是蒙版，不是图层

点中图层的蒙版缩略图（白框套住的那张小图，不是图层缩略图）， 选柔边画笔、白色，不透明度 10–20%。涂到的地方蒙版变白，那一层才显形： 涂提亮层变亮、涂压暗层变暗。涂过头就把前景色换成黑，盖回去。

曲线有多强

12%

「强度」参数是曲线在中间调偏离对角线的幅度：12 表示 0.5 处抬 0.12， 约 30 码。默认 12，范围 1–40。宁少勿多——一层不够就再涂一遍， 比一次涂死好收。

怎么修

  1. 提亮：额头、鼻梁、颧骨高点、眼下三角区——把该亮的地方推上去， 脸就立起来了。
  2. 压暗：脸颊两侧、下颌线、鼻翼阴影、眼窝——把该退的地方收回去。
  3. 每涂一遍就切到下一个图层顺序（提亮 → 压暗 → 再看），避免一路加亮 把皮肤涂成塑料。
  4. 想检查涂了多少：按住 Alt 点蒙版缩略图，只看蒙版；黑白分布 一目了然。

实测

check_retouch.py

恒等往返浮点 0 码、8 位 0 码（蒙版全黑，两层不参与）； 蒙版涂白处严格等于曲线在该点的值；没涂的地方一位不动；带 alpha 的图 透明度交给组蒙版，零误差。
