中性灰磨皮

plugin/neutral-grey 磨皮 Retouch 修饰

一张 50% 灰的柔光层，柔光在 0.5 处是恒等映射——刚建好时与原图逐像素相同。之后白色画笔提亮、黑色画笔压暗，原图像素一个都没动，整层删掉就能回到起点。

菜单位置
  • SuperMrWang → Retouch → 中性灰磨皮
  • 图层右键 → SuperMrWang → Retouch → 中性灰磨皮

这几条是同一个动作，处理的是当前选中的那一个图层。图层组不行——组没有自己的像素，会直接报错并提示先合并。

脚本调用
lb-plugin-neutral-grey(image, drawables, group)

标准 PDB 过程，参数留空走默认值。

依赖

不依赖任何自研算子：只往缓冲区里写像素，用 GIMP 自己的柔光混合模式。装了插件就能用。

生成的结构

一层
中性灰磨皮            组 · 穿透（带 alpha 时组上还有蒙版）
  └─ 1 · 中性灰        模式 柔光 · 整层 128 灰
  └─ 原图层（不动，可以隐藏）

只有一层、没有蒙版：整层铺满 0.5 编码灰，混合模式柔光。修的时候直接 在这层上涂，不像双曲线要切到蒙版。

为什么是柔光，不是叠加

两者在 0.5 处都恒等，区别在斜率：柔光平缓，一两笔的改动落在几个码以内， 适合反复微调；叠加是 2 倍斜率，同样力度下手重一倍，更容易出色斑。

为什么是 128，不是 Lab 中灰

灰层填的是编码值 0.5（8 位图 128）。Lab 的 L*=50 换算到 sRGB 只有 0.46 左右，柔光叠上去会把整张图压暗一点点——那就不是恒等了。这条是中性灰 最容易踩的坑。

怎么修

  1. 点中「1 · 中性灰」这一层，柔边画笔，不透明度 5–15%、 流量 10–30%。
  2. 白色涂＝提亮：推平暗斑、眼袋、法令纹阴影。
  3. 黑色涂＝压暗：收一收高光、压住油光、加深轮廓。
  4. 涂过头就用 50% 灰（#808080）盖回去——这就是它比 双曲线更好反悔的地方。

实测与一个实现注记

0 码

恒等往返浮点与 8 位都是 0 码；涂白变亮、涂黑变暗、没涂的地方 一位不动；带 alpha 的图由组蒙版保住透明度。

灰层的像素走 get_shadow_buffer() → merge_shadow()。 直接写 get_buffer() 再 flush+update（上一版的做法）只保证数值对， 投影和图层缩略图仍可能停在新图层的空内容上：导出是对的、界面上那一层 却是黑的——而且只有「不带 AI」这一支会这样，AI 版本来就走 shadow 路径。回归里盯住 merge_shadow 确实被调到。

Neutral Grey

plugin/neutral-grey Retouching Retouch

A 50% grey layer set to soft light — soft light is an identity at 0.5, so a freshly created layer is pixel-identical to the original. From there a white brush lightens and a black brush darkens, without a single original pixel being touched: delete the layer and you are back at the start.

Menu location
  • SuperMrWang → Retouch → Neutral Grey
  • Layer right-click → SuperMrWang → Retouch → Neutral Grey

These are all the same action, applied to the one layer you have selected. Layer groups do not work — a group has no pixels of its own, so the plug-in stops with an explicit error and asks you to merge first.

Scripting
lb-plugin-neutral-grey(image, drawables, group)

A standard PDB procedure; leave an argument empty to take its default.

Dependencies

No dependency on this project's operators: it only writes pixels into the buffer and uses GIMP's own soft-light mode. Install the plug-in and it works.

What gets created

one layer
Neutral Grey group · pass-through (plus a mask when there is alpha)
 └─ 1 · Neutral grey  Soft light · the layer is all 128 grey
 └─ original layer (untouched, can be hidden)

One layer, no mask: the whole layer is filled with encoded grey 0.5 and set to soft light. You paint straight on this layer, unlike dodge & burn where you switch to a mask.

Why soft light, not overlay

Both are identities at 0.5 and differ in slope: soft light is gentle, so one or two strokes land within a few codes — right for repeated fine adjustment. Overlay is twice the slope, twice as strong for the same pressure, and much easier to blotch.

Why 128, not Lab mid grey

The layer is filled with encoded value 0.5 (128 in 8-bit). Lab's L*=50 converts to about 0.46 in sRGB, and soft-lighting that darkens the whole image a little — which is no longer an identity. This is the trap neutral grey is most often caught by.

How to work with it

  • Select the "1 · Neutral grey" layer, soft brush, opacity 5–15%, flow 10–30%.
  • White paints light: flatten dark patches, bags under the eyes, nasolabial shadows.
  • Black paints dark: pull back highlights, knock down shine, deepen contours.
  • Overdone? Paint it back with 50% grey (#808080) — this is where it beats dodge & burn, which needs the mask inverted.

Measured, and one implementation note

0 codes

Identity round trip is 0 codes in both float and 8-bit; white lightens, black darkens, untouched pixels do not move by one bit; images with alpha keep transparency through the group mask.

After writing the grey pixels the plug-in must flush() and then update(): changing only the private buffer without telling the core leaves the projection stale, so the export is right while that layer looks black on screen. This release fixes exactly that, and the regression suite now asserts an update(0,0,W,H).
