高低频磨皮

plugin/frequency-separation 磨皮 Shortcut 快捷方式

把一张脸拆成影调与细节两层：低频管大块明暗与肤色过渡，高频管毛孔、痘印、细纹。调低频等于重新铺光，调高频等于控制质感，两者互不干扰——这是影楼修图里最老也最稳的一套结构。

菜单位置

多条
  • 颜色 → SuperMrWang → Shortcut → 高低频磨皮
  • 图层右键 → SuperMrWang → Shortcut → 高低频磨皮

这几条是同一个动作，处理的是当前选中的那一个图层。图层组不行—— 组没有自己的像素，会直接报错并提示先合并。

脚本调用

lb-plugin-frequency-separation(image, drawables, radius, group)

标准 PDB 过程，参数留空走默认值。

依赖

靠下面这些算子干活。它们已经打进这个插件的下载包（modules-windows-x64 / modules-linux-x64），不用另外去下：

  • gegl:gaussian-blur
  • gegl:high-pass

生成的结构

穿透组
高低频磨皮            组 · 穿透（带 alpha 时组上还有蒙版）
  ├─ 2 · 高频（细节）  模式 颗粒合并 + 高通
  ├─ 1 · 低频（影调）  模式 正常 + 高斯模糊
  └─ 原图层（不动，可以隐藏）

两层各挂一条非破坏滤镜，半径是同一个量：改半径时两层一起改， 否则叠回去就不再是原图。

两个滤镜的参数

低频层是 gegl:gaussian-blur，std-dev = 半径； 高频层是 gegl:high-pass，std-dev = 半径， contrast 必须设 2.0。默认的 1.0 只出一半差值， 叠回去整张图会偏灰——这条是实测踩出来的，不是猜的。

恒等是怎么来的

逐像素相同

高通层其实是 H = 0.5 + (原图 − 低频)，叠回去用颗粒合并 （H + L − 0.5），那个 0.5 的偏移正好抵消。所以刚建好时合成 结果与原图逐像素相同；剩下的误差来自 gegl:high-pass 内部约 1 码的定点偏移，与半径无关。

怎么修

  1. 低频层：低透明度画笔、图章或涂抹工具把色块铺平——汗斑、肤色不均、 明暗过渡都归它。
  2. 高频层：图章 / 修复画笔点掉痘印、毛孔、细纹，只动质感不动明暗。
  3. 半径就是分界线：1024 长的图从 4–8 px 起试。太大，细节被当成影调 一起揉掉；太小，高频里会留下大块色斑。
  4. 想整体重来：把两层的半径同时改回，或直接删组重生成——原图层一直没动。

实测

check_retouch.py

浮点与 8 位恒等 ≤ 1.5 码；改半径后仍然恒等（说明是活的非破坏结构）； 隐藏原图层后两层自己还原；带 alpha 的图由组蒙版保住透明度，零误差。

参数：radius 0.2–100 px（默认 8）、 group 收进图层组。
