高低频磨皮

plugin/frequency-separation 磨皮 Retouch 修饰

把一张脸拆成影调与细节两层：低频管大块明暗与肤色过渡，高频管毛孔、痘印、细纹。调低频等于重新铺光，调高频等于控制质感，两者互不干扰——这是影楼修图里最老也最稳的一套结构。

菜单位置
  • SuperMrWang → Retouch → 高低频磨皮
  • 图层右键 → SuperMrWang → Retouch → 高低频磨皮

这几条是同一个动作，处理的是当前选中的那一个图层。图层组不行——组没有自己的像素，会直接报错并提示先合并。

脚本调用
lb-plugin-frequency-separation(image, drawables, radius, group)

标准 PDB 过程，参数留空走默认值。

依赖

靠下面这些算子干活。它们已经打进这个插件的下载包（modules-windows-x64 / modules-linux-x64），不用另外去下：

  • gegl:gaussian-blur
  • gegl:high-pass

生成的结构

穿透组
高低频磨皮            组 · 穿透（带 alpha 时组上还有蒙版）
  ├─ 2 · 高频（细节）  模式 颗粒合并 + 高通
  ├─ 1 · 低频（影调）  模式 正常 + 高斯模糊
  └─ 原图层（不动，可以隐藏）

两层各挂一条非破坏滤镜，半径是同一个量：改半径时两层一起改， 否则叠回去就不再是原图。

两个滤镜的参数

低频层是 gegl:gaussian-blur，std-dev = 半径； 高频层是 gegl:high-pass，std-dev = 半径， contrast 必须设 2.0。默认的 1.0 只出一半差值， 叠回去整张图会偏灰——这条是实测踩出来的，不是猜的。

恒等是怎么来的

逐像素相同

高通层其实是 H = 0.5 + (原图 − 低频)，叠回去用颗粒合并 （H + L − 0.5），那个 0.5 的偏移正好抵消。所以刚建好时合成 结果与原图逐像素相同；剩下的误差来自 gegl:high-pass 内部约 1 码的定点偏移，与半径无关。

怎么修

  1. 低频层：低透明度画笔、图章或涂抹工具把色块铺平——汗斑、肤色不均、 明暗过渡都归它。
  2. 高频层：图章 / 修复画笔点掉痘印、毛孔、细纹，只动质感不动明暗。
  3. 半径就是分界线：1024 长的图从 4–8 px 起试。太大，细节被当成影调 一起揉掉；太小，高频里会留下大块色斑。
  4. 想整体重来：把两层的半径同时改回，或直接删组重生成——原图层一直没动。

实测

check_retouch.py

浮点与 8 位恒等 ≤ 1.5 码；改半径后仍然恒等（说明是活的非破坏结构）； 隐藏原图层后两层自己还原；带 alpha 的图由组蒙版保住透明度，零误差。

参数：radius 0.2–100 px（默认 8）、 group 收进图层组。

Frequency Separation

plugin/frequency-separation Retouching Retouch

Splits a face into tone and detail: low frequency carries the broad light and shade and skin transitions, high frequency carries pores, blemishes and fine lines. Editing low frequency is relighting, editing high frequency is controlling texture, and the two do not interfere — the oldest and steadiest structure in retouching.

Menu location
  • SuperMrWang → Retouch → Frequency Separation
  • Layer right-click → SuperMrWang → Retouch → Frequency Separation

These are all the same action, applied to the one layer you have selected. Layer groups do not work — a group has no pixels of its own, so the plug-in stops with an explicit error and asks you to merge first.

Scripting
lb-plugin-frequency-separation(image, drawables, radius, group)

A standard PDB procedure; leave an argument empty to take its default.

Dependencies

The operators below do the work. They are already inside this plug-in's download (modules-windows-x64 / modules-linux-x64) — nothing else to fetch:

  • gegl:gaussian-blur
  • gegl:high-pass

What gets created

pass-through group
Frequency Separation group · pass-through (plus a mask when there is alpha)
 ├─ 2 · High frequency (detail)  Grain merge + high pass
 ├─ 1 · Low frequency (tone)     Normal + Gaussian blur
 └─ original layer (untouched, can be hidden)

Each layer carries one non-destructive filter and both use the same radius: change the radius on one and it has to change on the other, otherwise the stack no longer reproduces the original.

The two filter settings

Low frequency is gegl:gaussian-blur with std-dev = radius; high frequency is gegl:high-pass with std-dev = radius and contrast set to 2.0. The default 1.0 produces only half the difference and the stack comes back grey — that one was measured, not guessed.

Why it is an identity

pixel exact

The high-pass layer is really H = 0.5 + (original − low), and stacking back uses grain merge (H + L − 0.5), so the 0.5 offset cancels. A freshly created group is therefore pixel-identical to the original layer; the remaining error comes from about 1 code of fixed-point offset inside gegl:high-pass and does not depend on the radius.

How to work with it

  • Low frequency: a low-opacity brush, clone or smudge tool flattens the patches — blotchiness, uneven skin tone and light transitions all live here.
  • High frequency: clone or healing brush removes blemishes, pores and fine lines without touching the light.
  • The radius is the dividing line: on a 1024-pixel image start at 4–8 px. Too large and detail gets smeared into tone; too small and broad patches stay in the high frequency.
  • To start over, set both radii back or delete the group and generate it again — the original layer was never touched.

Measured

check_retouch.py

Identity within 1.5 codes in float and 8-bit; still an identity after changing the radius (so the structure really is live); hiding the original layer lets the two rebuild it; images with alpha keep their transparency through the group mask, zero error.

Parameters: radius 0.2–100 px (default 8), and a group toggle.
