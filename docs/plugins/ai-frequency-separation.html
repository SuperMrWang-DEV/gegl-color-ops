高低频磨皮（AI 预修）

plugin/ai-frequency-separation 磨皮 Retouch 修饰

结构和「高低频磨皮」一模一样，只有内容换了人做：两层用的不是原图， 而是一张已经修过一遍的参考图——AI 低重绘，或本地降采样模糊。所以 打开文件时色块已经铺平、痘印已经淡掉，接着在高频层补几笔就行，不必从 零开始。

菜单位置
  • SuperMrWang → Retouch → 高低频磨皮（AI 预修）
  • 图层右键 → SuperMrWang → Retouch → 高低频磨皮（AI 预修）

这几条是同一个动作，处理的是当前选中的那一个图层。图层组不行——组没有自己的像素，会直接报错并提示先合并。

脚本调用
lb-plugin-ai-frequency-separation( image, drawables, prompt, source, radius, denoise, server, checkpoint, steps, group)

标准 PDB 过程，参数留空走默认值。

依赖

只用 GIMP 自带的 gegl:gaussian-blur 与 gegl:high-pass，不需要额外的算子模块。但要 plugin/_shared/ 里的 retouch_prep.py、retouch_math.py、ai_client.py——下载包里已经带上了。

  • gegl:gaussian-blur
  • gegl:high-pass

生成的结构

与原版同构
高低频磨皮（AI 预修）      组 · 穿透（带 alpha 时组上还有蒙版）
  ├─ 2 · 高频（细节）      颗粒合并 + 高通
  ├─ 1 · 低频（影调）      正常 + 高斯模糊
  └─ 原图层（不动，隐藏它也不掉东西）

合成结果等于参考图，不是原图——这就是「工作痕迹」。想对照就把组 的眼睛关掉，或按住 Shift 点眼睛临时隐藏。

参考图从哪来

参数 source

AI 参考：整层交给 ComfyUI 低重绘（默认 denoise 0.35）， 它认得出「这是皮肤」——痘印、泛红、局部色块被推平，五官与轮廓留住。 本地参考：整层降采样再放大当低通，毫秒级、零依赖。

AI 连不上时自动退回本地参考，并在提示里说清原因，不会弹一堆报错。

选区

有选区时，参考图只替换选区内，选区外逐像素等于原图——可以只修脸， 不动头发和背景。这一点三支 AI 磨皮插件一致。

接着怎么修

  1. 高频层：剩下没抹干净的痘印、毛孔，图章或修复画笔点掉。
  2. 低频层：还想更平的地方用低透明度画笔铺一下；铺过头就吸周围的 颜色盖回来。
  3. 半径就是分界线：1024 长的图从 4–8 px 起试。两层半径是同一个量， 改的时候一起改，否则叠回去就不再是参考图。

实测

check_retouch_ai*.py

结构 / 混合模式 / 滤镜与原版逐项一致；本地参考路径在软斑测试图上把高频 残留压到 ≤ 6 码（原图为对照组）；参考图与原图一致时（mock 返回原图） 痘印一位不动，说明不是无条件抹平。

参数：source（ai / local）、 radius 0.2–100 px、denoise 0.05–0.9、 prompt、server / checkpoint / steps、group。

前提：本机有个 ComfyUI

只有 AI 参考要

「AI 参考」这条路是跟本机的 ComfyUI 讲 HTTP 的。还没装？ SuperMrWang → AI → AI 环境… 里有一键安装（约 10 GB，无人值守）和启动 两个按钮，整个流程见 AI 局部重绘 那一页。

服务没开也不会失败：自动退回本地参考，并在提示里说明原因。 结构照出，只是少掉 AI 那一步。

Frequency Separation (AI prep)

plugin/ai-frequency-separation Retouching Retouch

The structure is exactly the same as Frequency Separation — the pixels are not. Both layers carry a reference that was already retouched once: a low-denoise ComfyUI pass, or a locally blurred copy. You open a file where the colour is already evened out and most blemishes are gone, and finish on top.

Menu location
  • SuperMrWang → Retouch → Frequency Separation (AI prep)
  • Layer right-click → SuperMrWang → Retouch → Frequency Separation (AI prep)

These are all the same action, applied to the one layer you have selected. Layer groups do not work — a group has no pixels of its own, so the plug-in stops with an explicit error and asks you to merge first.

Scripting
lb-plugin-ai-frequency-separation( image, drawables, prompt, source, radius, denoise, server, checkpoint, steps, group)

A standard PDB procedure; leave an argument empty to take its default.

Dependencies

Only GIMP's own gegl:gaussian-blur and gegl:high-pass — no extra operator modules. It does need retouch_prep.py, retouch_math.py and ai_client.py from plugin/_shared/, and they are inside the download.

  • gegl:gaussian-blur
  • gegl:high-pass

What it builds

same as the original
Frequency Separation (AI prep)   group · pass-through (masked when the source has alpha)
  ├─ 2 · High frequency (detail) grain merge + high pass
  ├─ 1 · Low frequency (tone)    normal + gaussian blur
  └─ the original layer (untouched, safe to hide)

The composite equals the reference, not the original — that is the pre-work. Toggle the group to compare, or hold Shift and click its eye.

Where the reference comes from

source

AI: the whole layer goes through ComfyUI at denoise 0.35. It knows this is skin — blemishes, redness and blotches flatten out while features and edges stay. Local: downscale-then-upscale as a low-pass, milliseconds and no dependencies.

If ComfyUI is not reachable the plug-in falls back to the local reference and says so in the message, instead of throwing a wall of errors.

Selections

With a selection active, only that area is replaced by the reference; everything outside stays pixel-identical to your layer. All three AI retouching plug-ins behave this way.

Finishing it

  1. High layer: clone or heal the blemishes that are left.
  2. Low layer: brush a little more evenness where you want it; sample neighbouring colour to undo.
  3. Radius is the cutoff: start at 4–8 px on a 1024-px image. Both layers share the radius — change them together or the stack no longer rebuilds the reference.

Measured

check_retouch_ai*.py

Structure, blend modes and filters match the original plug-in item for item. On the soft-blob test image the local reference leaves ≤ 6 levels of high-pass residue (the original image is used as the control). When the reference equals the original (the mock returns it unchanged) nothing is flattened.

Arguments: source (ai / local), radius 0.2–100 px, denoise 0.05–0.9, prompt, server / checkpoint / steps, group.

Prerequisite: a local ComfyUI

AI reference only

The AI reference path talks to a local ComfyUI over HTTP. Not installed yet? SuperMrWang → AI → AI Environment… has a one-click installer (about 10 GB, unattended) and a start button; the whole flow is on the AI Inpaint page.

If the server is down this plug-in does not fail: it falls back to the local reference automatically and says why in the message. You still get the two-layer structure, just without the AI pass.
