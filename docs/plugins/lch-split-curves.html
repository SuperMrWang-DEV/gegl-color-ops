LCh Split (Curves)

plugin/lch-split-curves 曲线 Retouch 修饰

同样的思路换到 CIE LCh：明度、彩度、色相三条曲线。LCh 是 Lab 的 极坐标写法——a、b 是直角坐标，一条一维曲线改它会连带改彩度和色相；换成 (L, C, h) 之后，调彩度不动色相、调色相不动彩度。

菜单位置
  • SuperMrWang → Retouch → LCh Split (Curves) · single
  • SuperMrWang → Retouch → LCh Split (Curves) · multi
  • 图层右键 → SuperMrWang → Retouch → 同上两条

这几条是同一个动作，处理的是当前选中的那一个图层。图层组不行——组没有自己的像素，会直接报错并提示先合并。

脚本调用
lb-plugin-lch-split-curves(image, drawables, group) lb-plugin-lch-split-curves-multi(image, drawables, group)

标准 PDB 过程，参数留空走默认值。

依赖

靠下面这些算子干活。它们已经打进这个插件的下载包（modules-windows-x64 / modules-linux-x64），不用另外去下：

  • lb:lch-dual
  • lb:lch-compose
  • gimp:curves

两种模式

两条菜单

菜单里是两条独立的过程——… · single 与 … · multi， 点哪条就是哪个模式。对话框里只剩「收进图层组」一个开关。

single   LCh split            组 · 穿透（带 alpha 时组上还有蒙版）
           └─ 1 · LCh L/C/h     模式 正常      ← 一条算子链算完整 LCh 色

multi    LCh split            组 · 穿透（带 alpha 时组上还有蒙版）
           ├─ 3 · Lightness     模式 LCh 明度
           ├─ 2 · Chroma        模式 LCh 彩度
           └─ 1 · Hue           模式 LCh 色相

single 的滤镜栈：decompose（lb:lch-dual）→ L 曲线（红） → C 曲线（绿） → h 曲线（蓝） → compose（lb:lch-compose）。

量程

转换由 babl 的 CIE LCH(ab) alpha float（D50）完成，与 lb:lch-levels 同一口径。数据图里：L* 0…100 → L/100、 C* 0…140 → C/140（sRGB 最饱和的纯蓝约 133.8，留了余量）、 h 0…360° → h/360。

single 还是 multi

multi 用 GIMP 原生的三个 LCh 分量混合模式，每层要把分量值「编码」 成混合模式读得出来的颜色——色相层得造一个等 L*、等 C* 的色相圆（L*=70、 C*=39.8，整圈在 sRGB 内），彩度层走黑→蓝直线。三层就是三次编码、三次 量化，但每层能单独关掉。

single 把三个分量一起送进 compose，那套编码整个不需要，也没了 逐层量化把色相带偏的风险。层数三降到一，滤镜十四条降到五条。

实测：浮点恒等往返 0.0005 码（multi 三层 0.002 码）、 8 位 0.49 码——single 更准，multi 换的是分层开关。 这个插件额外要过色相、彩度两张编码表，但曲线本身三个控制点踩在格点上， 不额外引入误差。只改 C 曲线时 L* 与色相的偏差 0.00001 码级。彩度或色相推到极端会出 sRGB 色域，8 位图按 0/1 裁掉——LCh 的色域比 sRGB 大，这是它本身的性质。 近中性色（C*≈0）的色相是噪声，但合成不受影响。依赖 lb:lch-dual / lb:lch-compose。

LCh Split (Curves)

plugin/lch-split-curves Curves Retouch

The same idea in CIE LCh: three curves for lightness, chroma and hue. LCh is Lab in polar form — a and b are rectangular, so a 1D curve on one of them drags chroma and hue along. In (L, C, h) you can move chroma without touching hue, and hue without touching chroma.

Menu location
  • SuperMrWang → Retouch → LCh Split (Curves) · single
  • SuperMrWang → Retouch → LCh Split (Curves) · multi
  • Layer right-click → SuperMrWang → Retouch → same as the two above

These are all the same action, applied to the one layer you have selected. Layer groups do not work — a group has no pixels of its own, so the plug-in stops with an explicit error and asks you to merge first.

Scripting
lb-plugin-lch-split-curves(image, drawables, group) lb-plugin-lch-split-curves-multi(image, drawables, group)

A standard PDB procedure; leave an argument empty to take its default.

Dependencies

The operators below do the work. They are already inside this plug-in's download (modules-windows-x64 / modules-linux-x64) — nothing else to fetch:

  • lb:lch-dual
  • lb:lch-compose
  • gimp:curves

Two modes

two menu entries

The menu holds two separate procedures — … · single and … · multi — and the one you click is the mode you get. The dialog has a single switch left: put everything in a layer group.

single  LCh split group · pass-through (plus a mask when there is alpha)
 └─ 1 · LCh L/C/h mode  Normal  ← one operator chain computes the whole LCh colour

multi   LCh split group · pass-through (plus a mask when there is alpha)
 ├─ 3 · Lightness mode  LCh lightness
 ├─ 2 · Chroma mode     LCh chroma
 └─ 1 · Hue mode        LCh hue

The single stack is: decompose (lb:lch-dual) → L curve (red) → C curve (green) → h curve (blue) → compose (lb:lch-compose).

Ranges

The conversion is babl's CIE LCH(ab) alpha float (D50), the same one lb:lch-levels uses. In the data image: L* 0…100 → L/100, C* 0…140 → C/140 (the most saturated sRGB blue is about 133.8, so there is headroom), and h 0…360° → h/360.

single or multi

multi uses GIMP's three native LCh component blend modes, which forces every layer to encode its component as a colour the mode can read — the hue layer has to fake a ring of constant L* and C* (L*=70, C*=39.8, the whole circle inside sRGB), the chroma layer goes along the black→blue line. Three layers, three encodes, three quantisations, but every layer switches off on its own.

single sends all three components into compose, so none of that encoding is needed and hue can no longer be dragged off by per-layer quantisation. Three layers become one, fourteen filters become five.

Measured

Float identity round trip 0.0005 codes (multi with three layers: 0.002 codes), 0.49 codes in 8-bit — single is more accurate, multi trades that for the switches. This plug-in additionally has to cross the hue and chroma encoding tables, but the curves themselves sit on grid points and add nothing.

Editing only the C curve leaves L* and hue at the 0.00001-code level. Extreme chroma or hue leaves sRGB and 8-bit output clips at 0/1 — LCh's gamut is simply larger. Hue near neutral (C*≈0) is noise, but composition is unaffected. Depends on lb:lch-dual / lb:lch-compose.
