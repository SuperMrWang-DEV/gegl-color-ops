LCh Split (Curves)

plugin/lch-split-curves 曲线 Shortcut 快捷方式

同样的思路换到 CIE LCh：明度、彩度、色相三条曲线。LCh 是 Lab 的 极坐标写法——a、b 是直角坐标，一条一维曲线改它会连带改彩度和色相；换成 (L, C, h) 之后，调彩度不动色相、调色相不动彩度。

菜单位置

两处
  • 颜色 → SuperMrWang → Shortcut → LCh Split (Curves)
  • 图层右键 → SuperMrWang → Shortcut → LCh Split (Curves)

两处是同一个动作，处理的是当前选中的那一个图层。图层组不行—— 组没有自己的像素，会直接报错并提示先合并。

脚本调用

lb-plugin-lch-split-curves(image, drawable, mode, group)

标准 PDB 过程，参数留空走默认值。

依赖

靠下面这些算子干活，装插件时它们必须已注册（build.sh 或 dll 包里都有）：

  • lb:lch-dual
  • lb:lch-compose
  • gimp:curves

两种模式

mode 参数
single   LCh split            组 · 穿透（带 alpha 时组上还有蒙版）
           └─ 1 · LCh L/C/h     模式 正常      ← 一条算子链算完整 LCh 色

multi    LCh split            组 · 穿透（带 alpha 时组上还有蒙版）
           ├─ 3 · Lightness     模式 LCh 明度
           ├─ 2 · Chroma        模式 LCh 彩度
           └─ 1 · Hue           模式 LCh 色相

single 的滤镜栈：decompose（lb:lch-dual）→ L 曲线（红） → C 曲线（绿） → h 曲线（蓝） → compose（lb:lch-compose）。

量程

转换由 babl 的 CIE LCH(ab) alpha float（D50）完成，与 lb:lch-levels 同一口径。数据图里：L* 0…100 → L/100、 C* 0…140 → C/140（sRGB 最饱和的纯蓝约 133.8，留了余量）、 h 0…360° → h/360。

single 还是 multi

multi 用 GIMP 原生的三个 LCh 分量混合模式，每层要把分量值「编码」 成混合模式读得出来的颜色——色相层得造一个等 L*、等 C* 的色相圆（L*=70、 C*=39.8，整圈在 sRGB 内），彩度层走黑→蓝直线。三层就是三次编码、三次 量化，但每层能单独关掉。

single 把三个分量一起送进 compose，那套编码整个不需要，也没了 逐层量化把色相带偏的风险。层数三降到一，滤镜十四条降到五条。

实测：浮点恒等往返 0.0005 码（multi 三层 0.0053 码）、 8 位 0.49 码——single 更准，multi 换的是分层开关； 只改 C 曲线时 L* 与色相的偏差 0.00001 码级。彩度或色相推到极端会出 sRGB 色域，8 位图按 0/1 裁掉——LCh 的色域比 sRGB 大，这是它本身的性质。 近中性色（C*≈0）的色相是噪声，但合成不受影响。依赖 lb:lch-dual / lb:lch-compose。
