Lab Split (Curves)

plugin/lab-split-curves 曲线 Shortcut 快捷方式

在 CIELAB 里调曲线：L* 是感知明度，a 是绿–品红轴，b 是蓝–黄轴。 「黄了压 b、偏绿推 a」比在 RGB 里拉曲线直观得多。三个分量打包进一张数据图， 三条曲线各管一个通道。

菜单位置

两处
  • 颜色 → SuperMrWang → Shortcut → Lab Split (Curves)
  • 图层右键 → SuperMrWang → Shortcut → Lab Split (Curves)

两处是同一个动作，处理的是当前选中的那一个图层。图层组不行—— 组没有自己的像素，会直接报错并提示先合并。

脚本调用

lb-plugin-lab-split-curves(image, drawable, group)

标准 PDB 过程，参数留空走默认值。

依赖

靠下面这些算子干活，装插件时它们必须已注册（build.sh 或 dll 包里都有）：

  • lb:lab-dual
  • lb:lab-compose
  • gimp:curves

生成的结构

一层
Lab split          组 · 穿透（带 alpha 时组上还有蒙版）
  └─ 1 · Lab a/b/L   模式 正常   ← 一条算子链算完整 Lab 色
  └─ 原图层（不动，可以隐藏）

滤镜栈：decompose（lb:lab-dual）→ a 曲线（红） → b 曲线（绿） → L 曲线（蓝） → compose （lb:lab-compose）。

为什么只有一层

a、b 是直角坐标，GIMP 没有「a」「b」分量模式；旧版把 a/b 合一层、L* 另起 一层借 LCh 明度（L* 在两个空间里是同一个量，逐位精确）。现在 L* 也进 compose，两层变一层——少的不只是一个图，还少了「这层用混合模式、那层用 正常模式」两套语义并存的地方。

数据图里中性灰落在 0.502：a 曲线在 0.5 附近往上抬是往洋红推、 往下压是往绿推；b 曲线同理（上=黄、下=蓝）。

量程与实测

按 babl 的 CIE Lab float（D50）：a' = (a*+128)/255、 L' = L*/100。浮点恒等往返 0.0024 码、8 位 0.49 码； 只改 a 曲线时结果的 b* 与 L* 偏差 0.00001 码级。

a、b 是直角坐标：调 a 会连带改彩度与色相（这正是「整体偏绿」该有的 行为）。要彩度、色相各自单独动，用 LCh 那个插件。超 sRGB 色域的点在 8 位图上 会被裁——那是色域的事实。依赖 lb:lab-dual / lb:lab-compose。
