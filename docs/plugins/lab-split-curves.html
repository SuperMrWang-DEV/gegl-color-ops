Lab Split (Curves)

plugin/lab-split-curves 曲线 Retouch 修饰

在 CIELAB 里调曲线：L* 是感知明度，a 是绿–品红轴，b 是蓝–黄轴。 「黄了压 b、偏绿推 a」比在 RGB 里拉曲线直观得多。三个分量打包进一张数据图， 三条曲线各管一个通道。

菜单位置
  • SuperMrWang → Retouch → Lab Split (Curves) · single
  • SuperMrWang → Retouch → Lab Split (Curves) · multi
  • 图层右键 → SuperMrWang → Retouch → 同上两条

这几条是同一个动作，处理的是当前选中的那一个图层。图层组不行——组没有自己的像素，会直接报错并提示先合并。

脚本调用
lb-plugin-lab-split-curves(image, drawables, group) lb-plugin-lab-split-curves-multi(image, drawables, group)

标准 PDB 过程，参数留空走默认值。

依赖

靠下面这些算子干活。它们已经打进这个插件的下载包（modules-windows-x64 / modules-linux-x64），不用另外去下：

  • lb:lab-dual
  • lb:lab-compose
  • gimp:curves

两种模式

两条菜单

菜单里是两条独立的过程——… · single 与 … · multi， 点哪条就是哪个模式。对话框里只剩「收进图层组」一个开关。

single   Lab split            组 · 穿透（带 alpha 时组上还有蒙版）
           └─ 1 · Lab a/b/L     模式 正常        ← 一条算子链算完整 Lab 色

multi    Lab split            组 · 穿透（带 alpha 时组上还有蒙版）
           ├─ 2 · L             模式 LCh 明度   ← 只替换 L*
           └─ 1 · a / b         模式 正常        ← 算出 a、b 与明度

single 的滤镜栈：decompose（lb:lab-dual）→ a 曲线（红） → b 曲线（绿） → L 曲线（蓝） → compose（lb:lab-compose）。

single 还是 multi

GIMP 只有 LCh 的三个分量混合模式，Lab 的 a、b 没有对应项。好在 L* 在 Lab 与 LCh 里是同一个量（逐位精确），所以明度能单独一层借过来；a、b 必须成对还原——它们共同决定彩度与色相，拆开就不是线性映射了。

multi 因此是两层：a/b 数据图层在下面算完整颜色，L 层用 LCh 明度 模式盖上去只换明度。关掉 L 层就能看「原明度 + 调过 a/b」的中间结果。

single 把 L* 也收进 compose，两层变一层。少的不只是一个图，还少了 「这层用混合模式、那层用正常模式」两套语义并存的地方。

数据图里中性灰落在 0.502：a 曲线在 0.5 附近往上抬是往洋红推、 往下压是往绿推；b 曲线同理（上=黄、下=蓝）。

量程与实测

按 babl 的 CIE Lab float（D50）：a' = (a*+128)/255、 L' = L*/100。浮点恒等往返 0.0024 码（multi 两层 0.0044 码）、8 位 0.49 码； 只改 a 曲线时结果的 b* 与 L* 偏差 0.00001 码级。

a、b 是直角坐标：调 a 会连带改彩度与色相（这正是「整体偏绿」该有的 行为）。要彩度、色相各自单独动，用 LCh 那个插件。超 sRGB 色域的点在 8 位图上 会被裁——那是色域的事实。依赖 lb:lab-dual / lb:lab-compose。

Lab Split (Curves)

plugin/lab-split-curves Curves Retouch

Curves in CIELAB: L* is perceptual lightness, a runs green–magenta, b runs blue–yellow. "Pull b down when it is too yellow, push a up when it is too green" is far more direct than pulling RGB curves. The three components are packed into one data image, one channel each.

Menu location
  • SuperMrWang → Retouch → Lab Split (Curves) · single
  • SuperMrWang → Retouch → Lab Split (Curves) · multi
  • Layer right-click → SuperMrWang → Retouch → same as the two above

These are all the same action, applied to the one layer you have selected. Layer groups do not work — a group has no pixels of its own, so the plug-in stops with an explicit error and asks you to merge first.

Scripting
lb-plugin-lab-split-curves(image, drawables, group) lb-plugin-lab-split-curves-multi(image, drawables, group)

A standard PDB procedure; leave an argument empty to take its default.

Dependencies

The operators below do the work. They are already inside this plug-in's download (modules-windows-x64 / modules-linux-x64) — nothing else to fetch:

  • lb:lab-dual
  • lb:lab-compose
  • gimp:curves

Two modes

two menu entries

The menu holds two separate procedures — … · single and … · multi — and the one you click is the mode you get. The dialog has a single switch left: put everything in a layer group.

single  Lab split group · pass-through (plus a mask when there is alpha)
 └─ 1 · Lab a/b/L mode  Normal  ← one operator chain computes the whole Lab colour

multi   Lab split group · pass-through (plus a mask when there is alpha)
 ├─ 2 · L mode      LCh lightness  ← replaces L* only
 └─ 1 · a / b mode  Normal         ← computes a, b and lightness

The single stack is: decompose (lb:lab-dual) → a curve (red) → b curve (green) → L curve (blue) → compose (lb:lab-compose).

single or multi

GIMP only has LCh component blend modes; Lab's a and b have no counterpart. L* is the same quantity in Lab and LCh (bit-exact), so lightness can be borrowed as its own layer — but a and b have to be restored as a pair, since together they set chroma and hue and splitting them is not a linear map.

multi is therefore two layers: the a/b data layer computes the full colour underneath, the L layer goes on top in LCh lightness mode and swaps lightness only. Switch the L layer off to see "original lightness plus edited a/b".

single folds L* into compose and turns two layers into one. What goes away is not just a layer but the situation where one layer uses a blend mode and the other uses Normal.

In the data image neutral grey sits at 0.502: pulling the a curve above 0.5 pushes towards magenta, below it towards green; the b curve works the same way (up = yellow, down = blue).

Ranges and measurements

Following babl's CIE Lab float (D50): a' = (a*+128)/255, L' = L*/100. Float identity round trip 0.0024 codes (multi with two layers: 0.0044 codes), 0.49 codes in 8-bit. Editing only the a curve leaves b* and L* at the 0.00001-code level.

Watch out

a and b are rectangular: moving a changes chroma and hue as well (which is exactly what "the whole image went green" looks like). For chroma and hue independently, use the LCh plug-in. Points outside sRGB are clipped in 8-bit output — that is the gamut. Depends on lb:lab-dual / lb:lab-compose.
