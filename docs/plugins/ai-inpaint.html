AI 局部重绘

plugin/ai-inpaint AI AI

框一块地方，写一句提示词，剩下的交给本机 ComfyUI（Stable Diffusion）： 插件把选区连同周围上下文裁下来、连蒙版一起送过去，等画完再把结果当新图层贴回原位。 不需要联网，不需要账号，一张 1024×512 的图在本机显卡上约 9 秒。

菜单位置
  • SuperMrWang → AI → AI Inpaint…（简版：只问画什么）
  • SuperMrWang → AI → AI Inpaint (Advanced)…（全参数）
  • SuperMrWang → AI → AI Environment…（装 / 起 ComfyUI，看底模）

处理对象是当前选区：先框出要改的地方，插件把这块连同周围一圈裁下来交给 ComfyUI，回来的图当新图层贴回原位，羽化过的选区做图层蒙版。没有选区它不会乱猜，会直接提示先框一块。

脚本调用
lb-plugin-ai-inpaint( image, drawables, prompt, preset, negative) lb-plugin-ai-inpaint-advanced( image, drawables, prompt, preset, negative, server, checkpoint, steps, cfg, seed, denoise, grow, grow-mask-by, feather, timeout, keep-mask, scale) lb-plugin-ai-env(image)

标准 PDB 过程，参数留空走默认值。

依赖

不依赖任何自研算子，也不用编译：像素由你自己那台 ComfyUI 里的 Stable Diffusion 画，插件只负责裁图、发 HTTP、贴回。需要 plugin/_shared/ 里的 ai_client.py 与 prompt_tools.py（下载包里带上了），以及一个在跑的 ComfyUI——没有的话菜单里的 AI 环境… 可以一键装、一键起，安装器就在这个包的 ai-setup/ 目录里。

一次点击做了什么

五步
  1. 选区外扩 grow（默认 8 px，收拾接缝），外接框再带一圈上下文；
  2. 裁切框宽高对齐到 8——VAE 是 8× 下采样，不对齐回来就错位；长宽比补到 ≤ 2:1，见下面「四个坑」；
  3. 从可见合成读这块像素（图层比画布小时取到的是下面图层，不是黑）， 连同蒙版 PNG 发给 ComfyUI；
  4. 轮询 /history 等它画完；
  5. 结果读回成新图层，插在原图层正上方、偏移对回原地，羽化选区做图层蒙版。
AI Inpaint            新图层 · 带羽化图层蒙版
  └─ 原图层             不动，随时关掉对比

keep-mask 打开时，另存一条 "AI Mask" 通道，
以后想重新限定范围可以直接拿来用。

选区要紧

最容易踩

蒙版盖住多少，模型就重画多少——它没有「这副眼镜戴在脸上该多大」的尺度概念。 框满整个额头到脸颊，出来的就是一副盖住半张脸的巨大墨镜。贴着目标该在的位置 框一条，上下各留 8~16 px 就够。

边缘不用抠准：grow 会把选区外扩，feather（默认 4 px） 管贴回时的过渡。真要精确形状，先在选区上做好再跑。

三个框

简版只有这些

Prompt —— 这里该变成什么。写结果，不写动作：要去掉一只瓶子，写 empty wooden table, wood grain，别写 remove the bottle。 常用词可以直接写中文，prompt_tools 翻成英文再送（SD 本身只读英文， 中文提示词在它那里等于噪声）。

What to paint（preset）—— 主体下拉。猫 / 狗 / 人 / 花 / 树 / 咖啡 / 食物 / 车。选了以后提示词只补细节（颜色、姿态、环境）。

Negative prompt —— 不要什么。默认已把画风压向照片： illustration, cartoon, flat graphic, poster, vector art, cgi。 这是修图插件，先让模型别往矢量插画跑；想要画风自己改这一栏。

参数框

GIMP 3 不会替插件生成参数对话框，得插件自己建。这一支在 run() 里 调 _shared/lb_dialog.py：交互模式弹框、取消就是取消， 批处理与「上次的值」直接放行，不再偷偷按默认值跑一遍。

这一课上过的不止这一支：不自己建框，参数就全部隐形， 永远按默认值执行。

高级版多出来的参数

按需改，不是都得填
参数默认什么时候动它
server空 ComfyUI 不在 127.0.0.1:8188 时填；空则读 $LB_COMFY_URL
checkpoint自动 下拉，选项当场问 ComfyUI 要；「自动」= 第一个非 inpaint 专用底模
steps25 要更细的质感往上加，25–30 之后收益很小
cfg7.5 听不听话。太高会硬、出现重复图形；太低会飘
seed-1 想复现同一张：把上一次日志里的种子填进来
denoise1.0 加新物体保持 1.0；只在「保留原结构、轻度改写」时降

grow-mask-by8 模型可动的额外像素，8 px = 一个 latent 格；越大接缝越少、漂移越多

timeout600 等 ComfyUI 的上限。CPU 兜底跑大图时往上调
keep-mask开 要不要留 "AI Mask" 通道；只想要干净结果就关掉

四个坑

都在代码里绕开了

1. 蒙版方向是反的。ComfyUI 的 LoadImage 用 alpha 倒推蒙版 （mask = 1 - alpha），所以「要重绘」必须写成透明。直接送灰度图 会得到全 0 蒙版，跑完像素纹丝不动。

2. 8× 对齐。裁剪框宽高不是 8 的倍数就会被截断，回来的图比请求的小， 贴回去整块错位。

3. inpaint 专用底模不认提示词。9 通道模型在 ComfyUI 的 VAEEncodeForInpaint 路径上只会把蒙版区抹平，边界还留一圈淡影。 工作流走普通底模，下拉里也把 inpaint 专用模型单独标出来。

4. 画幅比例。SD 只在自己训练过的比例附近画得对。选区是眼睛那样一条 1024×400（2.56:1）时，SDXL 会把整块画成平涂海报——一句 sunglasses 出来是一块绿底配重复白色箭头。 plan_canvas_rect() 一律先补到 ≤ 2:1：优先往画面里长真实像素， 画面到边了才复制边缘，补出来的那圈贴回时被蒙版挡住。

AI 环境

装在哪都行

AI Environment… 打开先报状态：连不连得上、什么版本、几个底模，以及 ComfyUI 装在哪、用的是哪个 python。目录不对就点 Choose folder… 手选（含 main.py 的目录，或包着 ComfyUI/ 的外层目录），选择会存进配置文件，下回不用再选。

Start 起服务、Stop 停掉插件自己起的那个进程、 One-click install… 首次装环境（约 10 GB：嵌入式 Python + torch cu128 + ComfyUI + 一份底模）、Model folder 直接打开 models\checkpoints、Refresh 重新探测并带出日志尾几行。

默认开着「ComfyUI 没在运行时自动启动」：跑 AI 之前先探活，连不上就按选好的 目录在后台拉起来（不弹控制台，输出写 comfyui.log），等它就绪 再继续。只用手选过的目录、不去猜——猜错会拿另一个 Python 起别人的 ComfyUI。

配置：Windows 在 %APPDATA%\SuperMrWang\comfyui.json， Linux/macOS 在 ~/.config/SuperMrWang/comfyui.json。安装器随插件走 （包里的 ai-setup/），不需要另外去找。

实测

check_ai_inpaint*.py

tools/check_ai_inpaint.py 168 条断言跑在本地 mock 服务上 （不需要显卡）：蒙版方向、8× 对齐、画布补边、缩放倍率上下限、底模家族判定、 工作流节点与连线、提示词中英转换、失败退路。

tools/check_ai_inpaint_gimp.py 在真实 GIMP 3.2 里把过程跑一遍： 选区 → 提示词 → 新图层、蒙版与通道、乱填的底模名被下拉拒回。

速度（RTX 3070 Ti，SDXL，25 步，1024×512）：8.7 秒。同一尺寸走 CPU 兜底是 94 秒（384×256 实测），能跑但不适合批量。

前提

一个在跑的 ComfyUI + 一份底模。插件只用标准库发 HTTP，不装任何 Python 依赖； HTTP 与 PNG 编解码都在 plugin/_shared/ai_client.py 里， 回归测试用 tools/mock_comfy.py 顶替真服务。

中文界面的人不用记参数名：po/zh_CN.po 里这些标签都翻过， 菜单、参数框、状态提示都是中文。

AI Inpaint

plugin/ai-inpaint AI AI

Frame an area, write one line of prompt, and your own ComfyUI (Stable Diffusion) does the rest: the plug-in crops the selection plus a ring of context, sends it with a mask, waits for the answer and pastes it back as a new layer. No account, no upload — 1024×512 comes back in about 9 seconds on a local GPU.

Menu location
  • SuperMrWang → AI → AI Inpaint… (three boxes)
  • SuperMrWang → AI → AI Inpaint (Advanced)… (every knob)
  • SuperMrWang → AI → AI Environment… (install / start ComfyUI)

It works on the current selection: frame what should change and the plug-in crops that area plus a ring of context, sends it to ComfyUI, then pastes the answer back as a new layer masked by your feathered selection. With no selection it says so instead of guessing.

Scripting
lb-plugin-ai-inpaint( image, drawables, prompt, preset, negative) lb-plugin-ai-inpaint-advanced( image, drawables, prompt, preset, negative, server, checkpoint, steps, cfg, seed, denoise, grow, grow-mask-by, feather, timeout, keep-mask, scale) lb-plugin-ai-env(image)

A standard PDB procedure; leave an argument empty to take its default.

Dependencies

No operator modules and nothing to compile: the pixels are painted by Stable Diffusion inside your own ComfyUI, and the plug-in only crops, posts over HTTP and pastes back. It needs ai_client.py and prompt_tools.py from plugin/_shared/ (inside the download) plus a running ComfyUI — if there is none, the AI Environment… menu entry installs and starts one, and the installer ships in the ai-setup/ folder of this zip.

What one click does

five steps
  1. Grow the selection by grow (8 px by default, hides the seam) and take its bounding box plus context;
  2. Align the crop to 8 — the VAE downsamples 8×, and a crop that is not a multiple comes back truncated and pastes out of place — then pad the aspect ratio to ≤ 2:1 (see “four traps” below);
  3. Read those pixels from the visible composite (a layer smaller than the canvas gives you the layer below, not black) and post them with a mask PNG;
  4. Poll /history until the job is done;
  5. Load the result as a new layer directly above the original, offset back to where it came from, masked by the feathered selection.
AI Inpaint            new layer · feathered layer mask
  └─ original layer     untouched, toggle it to compare

With keep-mask on, an "AI Mask" channel is kept as well,
so you can re-limit the area later.

Keep the selection tight

the usual trap

Whatever the mask covers is what gets repainted — the model has no idea how big a pair of glasses should be on a face. Frame the whole forehead-to-cheek band and you get glasses covering half the head. Frame the strip where they belong, 8–16 px of slack on each side is plenty.

The edges do not need to be precise: grow expands the mask and feather (4 px by default) blends the pasted result back in.

Three boxes

that is the simple version

Prompt — what should be there. Describe the result, not the action: to remove a bottle write empty wooden table, wood grain, not remove the bottle. Common Chinese words are fine — the plug-in translates them first; SD itself only reads English, so raw Chinese is just noise to it.

What to paint (preset) — a subject drop-down.Cat / dog / person / flower / tree / coffee / food / car. Pick one and the prompt only needs the details (colour, pose, surroundings).

Negative prompt — what must not appear.The default already leans photo: illustration, cartoon, flat graphic, poster, vector art, cgi. This is a retouching plug-in, so the model is told not to drift into vector art; change the line if you want a stylised result.

The parameter dialog

GIMP 3 does not build a dialog for a plug-in — the plug-in has to. This one calls _shared/lb_dialog.py from run(): interactive runs get a dialog, cancel really cancels, and batch runs or “last values” pass straight through instead of silently running with defaults.

Every plug-in in this project learned it the hard way: without a dialog of your own, every parameter is invisible and the defaults always win.

Four traps

all worked around

1. The mask is inverted.ComfyUI's LoadImage derives the mask from alpha (mask = 1 - alpha), so “repaint here” has to be transparent. Send a grey image and you get an all-zero mask — the run finishes and not one pixel moves.

2. Align to 8.A crop whose sides are not multiples of 8 gets truncated, comes back smaller than requested and pastes out of place.

3. Inpaint-only checkpoints ignore the prompt.A 9-channel model on ComfyUI's VAEEncodeForInpaint path only flattens the masked area and leaves a pale rim. The workflow uses a plain checkpoint, and the dropdown labels inpaint-only models so you can avoid them.

4. Aspect ratio.SD only draws well near the ratios it was trained on. A 1024×400 (2.56:1) strip across the eyes makes SDXL fall back to flat poster art — a prompt of sunglasses came back as a green board with repeated white arrows. plan_canvas_rect() pads to ≤ 2:1 first, growing into real pixels where the image allows and only replicating edges at the border; that ring is masked out when pasting back.

AI Environment

any folder

AI Environment… opens with the state: reachable or not, which version, how many checkpoints — and where ComfyUI lives and which python it runs. If the path is wrong, Choose folder… picks it by hand (the folder holding main.py, or the wrapper folder holding ComfyUI/); the choice is saved, so you only do it once.

Start / Stop manage the process the plug-in started, One-click install… sets everything up the first time (about 10 GB: embedded Python + torch cu128 + ComfyUI + one checkpoint), Model folder opens models\checkpoints, Refresh re-probes and shows the log tail.

“Start ComfyUI automatically when it is not running” is on by default: before an AI pass the plug-in probes /system_stats, and if nothing answers it starts the server in the background from the folder you picked (no console window, output to comfyui.log) and waits for it. Only an explicitly chosen folder is used — never a guess: guessing once meant launching someone else's ComfyUI with the wrong Python.

Config: %APPDATA%\SuperMrWang\comfyui.json on Windows, ~/.config/SuperMrWang/comfyui.json elsewhere. The installer ships with the plug-in, in the ai-setup/ folder of the zip.

Measured

check_ai_inpaint*.py

tools/check_ai_inpaint.py runs 168 assertions against a local mock service (no GPU needed): mask direction, 8× alignment, canvas padding, scale limits, checkpoint family detection, workflow nodes and wiring, Chinese-to-English prompt handling, failure paths.

tools/check_ai_inpaint_gimp.py runs the procedure inside real GIMP 3.2: selection → prompt → new layer, mask and channel, and a bogus checkpoint name being rejected by the dropdown.

Speed (RTX 3070 Ti, SDXL, 25 steps, 1024×512): 8.7 s. The same size on CPU fallback is 94 s (measured at 384×256) — it works, but not for batches.

Requirements

A running ComfyUI and one checkpoint. The plug-in uses only the standard library over HTTP — no Python dependencies; the HTTP and PNG code lives in plugin/_shared/ai_client.py, and the regression suite swaps the real service for tools/mock_comfy.py.

Chinese UI is complete for this plug-in: menus, the parameter dialog and the status messages are all translated in po/zh_CN.po.
