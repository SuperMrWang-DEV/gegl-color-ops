Layer to Selection

plugin/layer-to-selection 选区 图层转换

右键点一个图层，就把它转成当前选区。GEGL 算子跑完往往留下一张灰度图， 它往后的用途多半是当蒙版——原生流程要点四步（复制 → 建通道 → 粘贴 → 蒙版转选区），这里一步到位，而且彩色图层也能直接用。

菜单位置

两处
  • 图层右键 → SuperMrWang → Layer to Selection
  • 选择 → SuperMrWang → Layer to Selection

两处是同一个动作，处理的是当前选中的那一个图层。图层组不行—— 组没有自己的像素，会直接报错并提示先合并。

脚本调用

lb-plugin-layer-to-selection(
    image, drawable, channel, invert, operation)

标准 PDB 过程，参数留空走默认值。

依赖

不依赖任何自研算子：直接读图层字节（array 的 C 级切片，100 万像素约 4 毫秒），只调 GIMP 自己的选区 PDB。

转什么内容

五种通道

可选 Gray（亮度）/ R / G / B / Alpha——彩色图层选 Gray 时按亮度算， 不是 HSL 明度（纯红 ≈ 54/255，而不是 130）。黑白图层走零拷贝的通道切片 快捷路径，不改动任何像素。

怎么合进现有选区

替换 / 加 / 减 / 交，与 GIMP 选区菜单一致；还能反相 （选暗部而不是亮部）。已经有选区时不会丢，按你选的组合方式并进去。

偏移图层

图层比画布小、带偏移也没问题：只在自己位置生效，界外不选中。图层组没有 自己的像素，会明确报错并提示先合并。

两个 GIMP 3 的坑

已绕开

1. 临时通道会被选区截断。shadow buffer 的 merge 遵守当前选区， 所以读写临时通道前先 Selection.none 挂起、结束再恢复， 否则通道只有选区内有内容。

2. Y' float 不是亮度。babl 的 Y' 对纯红给 0.51， 那是 HSL 明度不是亮度，所以彩色图层的 Gray 走临时副本 desaturate（LUMA），用完即删。

实测

tools/check_layer_to_mask.py 23 条断言跑在真实 GIMP 3.2 里： 灰度值、反相、偏移图层、彩色亮度、四个单通道、四种组合方式、 以及有选区时结果不被截断。

速度：直接读 array 的 C 级切片，100 万像素约 4 毫秒。
