Alpha Curves（透明通道曲线）

plugin/alpha-curves 蒙版 Mask

GIMP 的曲线工具本来就有 Alpha 通道，但那条曲线只能调「已经存在的 透明度」——它不知道红通道是多少。要按颜色通道决定透明度，得先把通道搬进 alpha。这个插件把两步都做了：一条 通道 → Alpha，接一条 可以随便画的 alpha 曲线。两条都是非破坏滤镜。

菜单位置
  • SuperMrWang → Mask → Alpha Curves
  • 图层右键 → SuperMrWang → Mask → Alpha Curves

这几条是同一个动作，处理的是当前选中的那一个图层。图层组不行——组没有自己的像素，会直接报错并提示先合并。

脚本调用
lb-plugin-alpha-curves(image, drawables, channel, shape)

标准 PDB 过程，参数留空走默认值。

依赖

靠下面这些算子干活。它们已经打进这个插件的下载包（modules-windows-x64 / modules-linux-x64），不用另外去下：

  • lb:channel-range-to-alpha
  • gimp:curves

生成的结构

两条滤镜
Alpha Curves
  ├─ 2 · Alpha 曲线        gimp:curves（通道 = Alpha）
  └─ 1 · 通道 → Alpha      lb:channel-range-to-alpha

第 1 条把选定通道线性写进 alpha：四个滑块拉到 l1=0、l2=255、 r1=r2=255，斜坡占满全程，映射退化成「alpha ← 通道值」。 第 2 条就是普通的曲线，输入正好是那个通道值。

点开「2 · Alpha 曲线」，初始是三个控制点、一条平顶线： (0, 255)、(128, 255)、(255, 255)。 曲线是 SMOOTH（平滑样条）而不是手绘采样——只有三个抓手，往下拖任意 一个，整条曲线跟着走，不用在几十个采样点里找位置。往下压一点就是「暗部 半透明」，压到底就是「暗部全透明」，画成什么就是什么映射。

挂上来的瞬间该通道被推成满不透明；想要「装上去先不动」的样子，把三个点 拖回对角（45°）即可。

和 Range → Alpha 的关系

lb:channel-range-to-alpha 一步做完两件事：选通道、按四滑块 的梯形把它乘进 alpha。曲线不能一步做——它看不到「通道是多少」，只能 作用于 alpha 自己。所以这里拆成两条：先把通道搬进 alpha，再画曲线。

反过来，算子的梯形只是曲线的一种形状。shape 参数给了四个 现成起点（都是平滑曲线，挂上去以后随便拖）：

  • auto / flat（默认）＝ 三点全在顶，alpha 拉满
  • band ＝ 混合颜色带：两端收、中间满
  • identity（45°）＝ alpha 等于通道值，纯拷贝
  • soft ＝ smoothstep：暗部更透、亮部更实

实测

check_alpha_curves.py

恒等曲线时 alpha 与所选通道值差 ≤ 1 码，RGB 一个码都不动； 默认平顶把 alpha 拉满（最暗处也是 1）；band 与 lb:channel-range-to-alpha 的梯形在两端与中段一致（≤ 3 码）， 最陡的拐角被样条磨圆，最多差 42 码——曲线是软的，算子的是硬拐角。 8 位图 ≤ 2 码。

原图半透明时是乘不是替换：alpha = 原 alpha × 曲线(通道值)， 与算子一致。回归 45 项。

两条滤镜都在图层上，图层面板里可以逐条关掉、随时改参数，不碰像素。 选 alpha 作源通道时只挂第 2 条——那是最纯粹的「给现有透明度画曲线」。 曲线的 trc 钉在编码值上，与 channel-range-to-alpha 的 0–255 滑块 同一刻度。依赖 lb:channel-range-to-alpha（除 alpha 模式外）。

Alpha Curves

plugin/alpha-curves Mask Mask

GIMP's curves tool does have an Alpha channel, but that curve can only edit transparency that already exists — it has no idea what the red channel holds. Deciding transparency from a colour channel means moving the channel into alpha first. This plug-in does both steps: channel → alpha, then an alpha curve you can draw. Both are non-destructive filters.

Menu location
  • SuperMrWang → Mask → Alpha Curves
  • Layer right-click → SuperMrWang → Mask → Alpha Curves

These are all the same action, applied to the one layer you have selected. Layer groups do not work — a group has no pixels of its own, so the plug-in stops with an explicit error and asks you to merge first.

Scripting
lb-plugin-alpha-curves(image, drawables, channel, shape)

A standard PDB procedure; leave an argument empty to take its default.

Dependencies

The operators below do the work. They are already inside this plug-in's download (modules-windows-x64 / modules-linux-x64) — nothing else to fetch:

  • lb:channel-range-to-alpha
  • gimp:curves

What gets created

two filters
Alpha Curves
 ├─ 2 · Alpha curve    gimp:curves (channel = Alpha)
 └─ 1 · Channel → alpha  lb:channel-range-to-alpha

The first filter writes the chosen channel into alpha linearly: the four sliders go to l1=0, l2=255, r1=r2=255 so the ramp fills the whole range and the mapping collapses to "alpha ← channel value". The second is an ordinary curve whose input is exactly that channel value.

Open "2 · Alpha curve" and it starts with three control points on a flat top: (0, 255), (128, 255), (255, 255). The curve is SMOOTH rather than a hand-drawn sample table — three handles, drag any one and the whole curve follows, no hunting through dozens of sampled dots. Press it down a little and the shadows become semi-transparent; press it to the bottom and they vanish. Whatever you draw is the mapping.

The moment it is attached the channel is pushed to fully opaque; for "attach it and change nothing", drag the three points back onto the diagonal (45°).

Relation to Range → Alpha

lb:channel-range-to-alpha does two things in one step: pick a channel and multiply it into alpha through a four-slider trapezoid. A curve cannot do that in one step — it cannot see "what the channel is", only alpha itself. Hence two filters here: move the channel into alpha, then draw the curve.

Conversely, the operator's trapezoid is just one shape a curve can take. The shape parameter offers four starting points, all smooth curves and all draggable once attached:

  • auto / flat (default) = three points at the top, alpha wide open
  • band = blend-if style: closed at both ends, open in the middle
  • identity (45°) = alpha equals the channel value, a plain copy
  • soft = smoothstep: shadows more transparent, highlights more solid

Measured

check_alpha_curves.py

With the identity curve, alpha differs from the chosen channel by ≤ 1 code and RGB does not move by a single code; the default flat top opens alpha completely (even the darkest point is 1); band matches lb:channel-range-to-alpha's trapezoid at both ends and in the middle (≤ 3 codes), while the sharpest corner is rounded by the spline and can differ by up to 42 codes — the curve is soft where the operator has a hard corner. 8-bit output is ≤ 2 codes.

When the source is semi-transparent the result is a multiply, not a replace: alpha = original alpha × curve(channel value), matching the operator. 45 assertions in the regression suite.

Notes

Both filters sit on the layer, so they can be switched off one by one in the Layers panel and re-tuned at any time without touching pixels. Choosing alpha as the source channel attaches only the second filter — the purest form of "curve the transparency I already have".

The curve's trc is pinned to encoded values, the same scale as channel-range-to-alpha's 0–255 sliders. Depends on lb:channel-range-to-alpha (except in alpha mode).
