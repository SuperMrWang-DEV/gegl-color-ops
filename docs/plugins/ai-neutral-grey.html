中性灰磨皮（AI 预修）

plugin/ai-neutral-grey 磨皮 Retouch 修饰

那张 50% 灰的柔光层不再是平的 128：插件把「参考图比原图亮多少 / 暗多少」反解成柔光需要的灰度，直接写进灰层。打开文件就是已经做过一轮 中性灰、肤色被拉平了一截的状态。

菜单位置
  • SuperMrWang → Retouch → 中性灰磨皮（AI 预修）
  • 图层右键 → SuperMrWang → Retouch → 中性灰磨皮（AI 预修）

这几条是同一个动作，处理的是当前选中的那一个图层。图层组不行——组没有自己的像素，会直接报错并提示先合并。

脚本调用
lb-plugin-ai-neutral-grey( image, drawables, prompt, source, prepaint, radius, denoise, server, checkpoint, steps, group)

标准 PDB 过程，参数留空走默认值。

依赖

不依赖任何算子模块：只往缓冲区写像素，用 GIMP 自己的柔光模式。但要 plugin/_shared/retouch_prep.py 与 retouch_math.py——下载包里已经带上了。

生成的结构

128 ± 偏移
中性灰磨皮（AI 预修）        组 · 穿透
  └─ 1 · 中性灰（已预校正）  柔光 + 128±偏移的像素
     └─ 原图层（不动）

灰层里每个像素都是解析解：把柔光公式 out = x + (2g−1)·… 反推 出「要让这里变成参考图，g 该是多少」，不是估的。

它是像素，不是蒙版

所以橡皮擦、选区填充、渐变、复制粘贴都能用——比双曲线那版更耐改； 代价是画过头只能靠 #808080 盖回去（双曲线那版把蒙版涂黑就行）。

预校正多少

prepaint 70%

默认补七成：暗斑处灰层 > 128（提亮）、油光处 < 128（压暗）、背景 ≈ 128（不动）。设 0% 就是原版那张平灰层。

接着怎么修

  1. 选中灰层，柔边画笔、不透明度 5–15%：白色提亮、黑色压暗。
  2. 画过头：前景色设 #808080 涂回去，等于「这一块没做」。
  3. 觉得整体太强 / 太弱：关掉组，用 prepaint 换个比例重跑， 原图层一直没动。

实测

check_retouch_ai.py

灰层代回柔光公式，能把原图推回参考图的误差 ≤ 1 码（六组亮度/差值 组合，含正负方向）；软斑图上暗斑处 162、亮斑处 97、背景 128；prepaint=0 整层 128。

参数：source、prepaint 0–100%、 radius（本地参考）、denoise、prompt、 group。

Neutral Grey (AI prep)

plugin/ai-neutral-grey Retouching Retouch

That 50% grey Soft Light layer is no longer flat 128: the plug-in solves the soft-light formula backwards for the reference and writes the result into the layer. You open a file where one neutral-grey pass is already done.

Menu location
  • SuperMrWang → Retouch → Neutral Grey (AI prep)
  • Layer right-click → SuperMrWang → Retouch → Neutral Grey (AI prep)

These are all the same action, applied to the one layer you have selected. Layer groups do not work — a group has no pixels of its own, so the plug-in stops with an explicit error and asks you to merge first.

Scripting
lb-plugin-ai-neutral-grey( image, drawables, prompt, source, prepaint, radius, denoise, server, checkpoint, steps, group)

A standard PDB procedure; leave an argument empty to take its default.

Dependencies

No operator modules at all: it writes pixels into the buffer and uses GIMP's own soft-light mode. It does need retouch_prep.py and retouch_math.py from plugin/_shared/, already included.

What it builds

128 ± offset
Neutral Grey (AI prep)          group · pass-through
  └─ 1 · Neutral grey (pre-corrected)  soft light + 128±offset pixels
     └─ the original layer (untouched)

Every pixel is an analytic solution: out = x + (2g−1)·… inverted for g, not a guess.

Pixels, not a mask

So erasers, fills, gradients and paste all work — it takes more abuse than the dodge & burn version. The price: overshooting can only be undone with #808080, whereas the curve version just paints its mask black.

How much is pre-corrected

prepaint 70%

70% by default: shadows land above 128 (lightened), highlights below 128 (darkened), flat background at 128. 0% gives the original flat grey layer.

Finishing it

  1. Select the grey layer, soft brush at 5–15%: white lightens, black darkens.
  2. Overshot? Set the foreground to #808080 and paint it back — that means "do nothing here".
  3. Too strong overall? Hide the group, change prepaint and run again; your original layer never moved.

Measured

check_retouch_ai.py

Feeding the grey layer back through the soft-light formula reproduces the reference within ≤ 1 level across six combinations of base value and delta, in both directions. On the blob image: 162 on the dark blob, 97 on the bright one, 128 on the background; prepaint=0 is flat 128.

Arguments: source, prepaint 0–100%, radius (local reference), denoise, prompt, group.
