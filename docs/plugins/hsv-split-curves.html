HSV Split (Curves)

plugin/hsv-split-curves 曲线 Shortcut 快捷方式

GIMP 的曲线只能选 R / G / B / Alpha——想单独曲「色相」或 「饱和度」没有入口。这个插件把图层换成一张数据图（红=S、绿=V、蓝=色相）， 三条曲线各管一个分量，再由一个算子解回颜色：恒等时逐像素还原原图， 改哪条曲线就只动那个分量。想要「每层能单独关掉」的老做法，把「模式」 切到 multi 就行。

菜单位置

两处
  • 颜色 → SuperMrWang → Shortcut → HSV Split (Curves)
  • 图层右键 → SuperMrWang → Shortcut → HSV Split (Curves)

两处是同一个动作，处理的是当前选中的那一个图层。图层组不行—— 组没有自己的像素，会直接报错并提示先合并。

脚本调用

lb-plugin-hsv-split-curves(image, drawable, mode, group)

标准 PDB 过程，参数留空走默认值。

依赖

靠下面这些算子干活，装插件时它们必须已注册（build.sh 或 dll 包里都有）：

  • lb:hsv-dual
  • lb:hsv-compose
  • gimp:curves

两种模式

mode 参数
single   HSV split            组 · 穿透（带 alpha 时组上还有蒙版）
           └─ 1 · HSV S/V/H     模式 正常      ← 一条算子链算完整 HSV 色

multi    HSV split            组 · 穿透（带 alpha 时组上还有蒙版）
           ├─ 3 · Value         模式 HSV 明度
           ├─ 2 · Saturation    模式 HSV 饱和度
           └─ 1 · Hue           模式 HSV 色相

single 的滤镜栈：decompose（lb:hsv-dual）→ S 曲线（红） → V 曲线（绿） → H 曲线（蓝） → compose（lb:hsv-compose）。三个分量各占一个通道，互不串门。

single 还是 multi

single 把 S、V、H 一起送进 lb:hsv-compose：一层、 五条滤镜，一次算完，只编码一次，误差最小。

multi 是三张分量层，每层 extract → 曲线 → encode，再靠 HSV 的三个分量混合模式叠回去。三层就是三次 编码、三次量化；换来的是每层都能单独关——拨掉 Hue 层就只剩调过 S/V 的 中间结果，判断在改什么时很直观。

两个模式的恒等曲线都逐像素还原原图。

实测精度

single：32 位浮点图恒等往返 0.0002 码；8 位图 0.49 码（就是 量化本身）。只改 S 曲线时，结果的 V 与色相偏差 < 0.001 码—— 三个分量确实互不干扰。

multi：浮点图三层合成的恒等往返 0.0015 码，隐藏原图层后照样叠得回去。 比 single 大七倍——多出来的是三次编码来回的余数，但仍然在千分之一码量级， 肉眼无感。8 位图上两个模式都是 0.49 码，量化盖过一切。所以精度上 single 更准，multi 换来的是「每层能单独关」。

通道约定是硬的：S 在红、V 在绿、色相在蓝。改曲线时选错通道， 等于把另一个分量的数据当曲线输入。色相曲线必须连续（两端相等、中间不跳变）， 整体旋转色相请用 lb:hue-saturation。single 依赖 lb:hsv-dual / lb:hsv-compose；multi 只用 GIMP 自带的 gegl:component-extract 与 HSV 分量混合模式。
