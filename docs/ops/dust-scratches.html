Dust & Scratches

lb:dust-scratches 杂色 AreaFilter

Photoshop「滤镜 → 杂色 → 蒙尘与划痕」的等价物：把与周围差得太远的孤立像素（灰尘、划痕、传感器坏点）用邻域中值替换，同时尽量不动真实的边缘与细节。

lb:dust-scratches · 菜单 SuperMrWang → Noise → Dust & Scratches · 单输入

把与周围差得太远的孤立像素（灰尘、划痕、传感器坏点）用邻域中值替换，同时尽量不动真实的边缘与细节。PS「杂色 → 蒙尘与划痕」的等价物。

参数 / Parameters

参数范围默认含义
radius 半径1–102邻域半径，1 即 3×3。越大去掉的斑点越大，细节也丢得越多
threshold 阈值0–2550与中心差超过这个码数的邻居不参与取中值。阈值就是「多大的差才算灰尘」

算法

对每个像素、每个通道：

  1. 收集半径 r 内所有满足 |v − v₀| ≤ threshold 的邻居——中心自己不算；
  2. 取这些值的中值；
  3. 一个合格的都没有时，退回整窗（去中心）的中值。

用中值而不是均值，是因为中值不会被少数极端值拉动：一个亮斑在均值里会被摊成一个更大的灰斑，在中值里直接被丢掉。

中心自己不入集合是与「直接套中值滤波」的关键差别。灰尘之所以是灰尘，就因为它和周围都不一样；把它算进集合，它自己就会当选，等于什么都没做。第 3 步的兜底是为了硬边正中——那里两侧邻居都不合格，此时宁可轻微平滑，也不要留下一个孤点。

用法 / Recipes

  • 扫底片灰尘：radius=1 threshold=12
  • 去传感器坏点：radius=2 threshold=30
  • 柔化皮肤小瑕疵：radius=3 threshold=18，只做局部

半径与阈值是一对反向旋钮：threshold=0 时就是纯中值滤波（很糊），阈值开到 30 以上才只动「明显不对」的像素。

与 Photoshop 的差异

PS 蒙尘与划痕lb:dust-scratches
半径 / 阈值有有
中值集合是否含中心含（阈值 0 时等于纯中值）不含，孤点在阈值很大时也能去掉
全不合格时的行为保持原值退回整窗中值（硬边不糊，孤点不残留）

测试 / Testing

python tools/check_noise_sharpen.py：孤立亮点被抹掉、硬边不动、纯色图不变、α 透传。

Dust & Scratches

lb:dust-scratches Noise AreaFilter

Replaces isolated specks with the median of the neighbours that are within the threshold, so dust disappears and real edges stay put.

lb:dust-scratches · menu SuperMrWang → Noise → Dust & Scratches · one input

Replaces pixels that differ too much from their surroundings — dust, scratches, sensor defects — with the median of the neighbourhood, while leaving real edges alone. Photoshop's Dust & Scratches, with one deliberate difference explained below.

Parameters

ParameterRangeDefaultMeaning
radius1–102Neighbourhood radius; 1 is a 3×3 window. Bigger removes bigger specks and loses more detail
threshold0–2550Neighbours that differ from the centre by more than this are excluded from the median. It is literally "how much of a difference counts as dust"

Algorithm

Per pixel, per channel:

  1. Collect every neighbour within radius r that satisfies |v − v₀| ≤ threshold — the centre itself does not count;
  2. take the median of those values;
  3. if nothing qualified, fall back to the median of the whole window (again without the centre).

A median rather than a mean, because a median is not dragged by a few extreme values: a bright speck averaged becomes a bigger grey smudge, medianed it simply disappears.

Keeping the centre out of the set is the crucial difference from plain median filtering. Dust is dust precisely because it differs from everything around it; include it and it elects itself, which does nothing. Step 3 covers the middle of a hard edge, where neither side qualifies: a slight smoothing is preferable to leaving an isolated pixel behind.

Recipes

  • Film scanning dust: radius=1 threshold=12
  • Sensor defects: radius=2 threshold=30
  • Small skin blemishes: radius=3 threshold=18, locally only

Radius and threshold pull against each other: at threshold=0 this is a plain median filter (and blurs a lot); above roughly 30 it only touches pixels that are clearly wrong.

Compared with Photoshop
