Vibrance

lb:vibrance 色彩 逐像素

按 Photoshop「自然饱和度」的实测响应改饱和度：低饱和吃得饱、高饱和主动收手、红带（肤色）额外保护、浅色少给一点，色相与明度不动

按实测逆向出来的 Photoshop「自然饱和度」，不是凭经验的近似。同一张标定图分别过 PS 26.10 和本算子，像素级逐位对比见文末「验收」。

  • GEGL id：lb:vibrance
  • 菜单：Colors → SuperMrWang → Color → Vibrance
  • 类型：GeglOperationPointFilter（逐像素，无邻域）
  • 参数：vibrance（−100…100）、protect_reds、compensate_lightness

只管 Vibrance，色温色调不在这里

PS 2026（27.0）把自然饱和度图层改名成「色彩与自然饱和度」，多出色温 / 色调两个 滑块，动作上就是先一层白平衡、再走原来的 Vibrance。

本工程不把这两段揉进一个算子：色温 / 色调由独立的 lb:color-temperature-tint 负责， lb:vibrance 只做 Vibrance 本身。想复刻「色彩与自然饱和度」，按顺序叠两层即可：

图层 / 滤镜栈：  色温色调（lb:color-temperature-tint）  →  Vibrance（lb:vibrance）

要 2025 的纯 Vibrance，把底下那层删掉就是。这样拆的好处：

  • 两个算子各有一个滑块职责，界面上不会出现「这个色温到底管整层还是只管这段」；
  • 顺序由图层栈显式表达（PS 的顺序是白平衡在前，实测中位差 1.4 码；反过来差 36 码）， 想换顺序就换图层顺序，不用再来回勾开关；
  • 白平衡的结果和 lb:color-temperature-tint 单跑逐位相同，不存在两套代码 各自漂移的问题。

算法

在 sRGB 编码值（R~G~B~A float，感知域而非线性光）上转 HSV，按源图饱和度 S 取增量：

ΔS = A(v) · S^p(v) · (1−S)^q(v) · r(H,S,v) · c(L)
S' = min(1, S + ΔS)
项含义数据来源
A(v)、p(v)、q(v)幅度与两端曲率，随 v 逐档查表16 位 / 步长 5 标定，20 档
r(H,S,v)红带（离红色 40° 以内）的额外压制；26°–40° 线性过渡出去同 v 下 H0 与 H120 的比值
c(L)亮度修正：浅色少给（L=80 只有 0.72 倍，L=20 有 1.39 倍）E 段 L 阶梯

RGB 重建：保持 max 不动，其余通道按 S'/S 缩放 —— out = mx − (mx − c)·S'/S。 因为 mx − mn = S·mx，当 S' ≤ 1 时最小通道恰好落在 [0, mx]，数学上不会越界， 不需要任何裁剪或色域收敛。

负方向（v<0）是另一套机制，不是正向的镜像：实测结果是 S 降、V 也会跟着降， 而且没有色相项，所以直接用两张表（S' 与 V'/V），同样按 (v, S) 双线性插值。

参数表在 vibrance-tables.h 里，由 tools/gen_vibrance_tables.py 从 vibrance-cal/vibrance_model.json 生成 —— 要改数值请改上游 JSON 再重新生成， 不要手抄。

性能

v 对整张图是常量，所以每条随 v 变化的曲线都在 prepare() 里先折叠成一行 （11 个采样点），process() 只剩一维查表和两次 powf。全图 1080×880 的标定图 用 gegl CLI 渲染约 0.2 s（含 PNG 编解码）。

v=0 逐位相同，说明色彩管线（线性↔编码往返）没有偷偷改像素。C 实现与 vibrance-cal/vibrance_ref.py 的 Python 参考实现逐像素一致（差 ≤1 码，纯舍入）。

两层叠加的「色彩与自然饱和度」组合验收（对 PS 2026 实测）与色温色调本身的精度， 见 ops/color-temperature-tint/README.md —— 那里有 v/t/n 七组参数的中位/p90/p99/最大 偏差，以及色温 ≤ −50 且色调 ≥ +38 对角线上 PS 硬裁切造成的已知偏差。

已知偏差

拟合残差只在采样点上成立（A 段 ΔS 残差 0.41 pp @ v=+100），整图上的大头在两处 标定维度没覆盖到的地方：

  1. 红带里 H≈17° 的橙/肤色（B 段，L62）：r 只按 H0 拟合，H17 处 PS 压得更狠。 v=+60 时该段中位偏差 2.9 码、v=+100 时 8.4 码（最大 14.8）。
  2. 负方向在浅色上的明度变化（E 段）：V'/V 表只在 L=50 上拟合，L=80 时 PS 实际压得比表里小得多（该处最大偏差 29 码，sRGB 下是肉眼可见的变暗）。

这两处都不是实现问题，是模型维度不够（色相只有 6 个采样点、明度 5 档）。要补， 方向是做 probe v2：L×S 网格 + 5° 色相细扫，然后重拟合 r(H,S,v) 与负向的 V'(S,L,v)。

与 lb:vibrance-hyper 的关系

vibrance-hyper 是 LAB 域的外观建模（色度双曲蒙版 + 肤色窗 + 色域收敛）， 调出来的手感好、参数可解释，但不保证和 PS 数值一致。 vibrance 是数值复刻：和 PS 对得上，但没有可调的艺术性参数。 两个并存，按需要选。
