CMYK Primary

lb:cmyk-primary-correction 色彩 逐像素

经典图像编辑器 可选颜色：红/黄/绿/青/蓝/品红/白/中性/黑九组各自独立记忆

cmyk-primary-correction

参数说明（本工程版本）

与 经典图像编辑器的「可选颜色」一致，九个色域各存一份独立的 C/M/Y/K，切换查看不会 覆盖别组的数值，九组同时对整图生效（一个像素同时落在「红」和「白」时两组都起作用）。

  • 滑块按「色域 – 墨量」命名：Reds – Cyan、Yellows – Magenta、… 共 9 × 4 = 36 个， 顺序与 经典图像编辑器 页签一致：红 → 黄 → 绿 → 青 → 蓝 → 品红 → 白 → 中性 → 黑
  • Absolute Mode：对应 经典图像编辑器的「绝对」复选框
  • 数值范围 -100 ~ +100，与 经典图像编辑器 滑块同刻度

注：本机 GEGL 0.4.72 不支持 property_group，所以 36 个滑块在面板里是平铺的， 靠名字前缀区分色域；等 GEGL 升级后可以改成折叠分组。

九组的偏移先按色域权重求和，再按绝对 / 相对两种口径落到墨量上：

$$\delta = \sum_{g=1}^{9} w_g\,\delta_g,\qquad c' = \begin{cases} c + \dfrac{\delta}{100}, & \text{绝对模式} \\[8pt] c\,\Bigl(1 + \dfrac{\delta}{100}\Bigr), & \text{相对模式} \end{cases}$$

回归验证脚本：python tools/check_cmyk_sections.py（校验单组结果与旧版逐像素一致、 多组同时生效互不覆盖）。

CMYK Primary

lb:cmyk-primary-correction Color per-pixel

The classic editor's Selective Color — nine colour-range tabs, each holding its own C/M/Y/K ink amounts, all active at once.

Menu: Colors → SuperMrWang → Color → CMYK Primary

Parameters

Matching the classic editor's Selective Color: each of the nine colour ranges keeps its own independent C/M/Y/K values, so switching tabs never overwrites another group's numbers, and all nine act on the image at the same time (a pixel that falls into both "Reds" and "Whites" is affected by both).

  • Sliders are named "range – ink": Reds – Cyan, Yellows – Magenta, … 9 × 4 = 36 of them, in the classic editor's tab order: Reds → Yellows → Greens → Cyans → Blues → Magentas → Whites → Neutrals → Blacks.
  • Absolute Mode is the classic editor's "Absolute" checkbox.
  • The range is −100…+100, the same scale as the classic editor's sliders.

Note: GEGL 0.4.72 as shipped here has no property_group, so the 36 sliders are flat in the panel and are told apart by their name prefix. Once GEGL is upgraded they can be folded into groups.

Regression check: python tools/check_cmyk_sections.py — verifies that a single group matches the old build pixel for pixel, and that several groups act at once without overwriting each other.

2. How to Open the Plugin (2 Methods)

After installation, restart GIMP to activate the plugin.

Method 1: Menu Bar (Recommended)

Menu path: Colors → SuperMrWang → Color → CMYK Primary

Method 2: GEGL Operation

  1. Go to Filters → Generic → GEGL Operations
  2. In the search box, enter: lb:cmyk-primary-correction
  3. Select it and click OK to apply
