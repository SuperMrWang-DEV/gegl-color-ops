Hue/Saturation

lb:hue-saturation 色彩 逐像素

全局或按红/黄/绿/青/蓝/品红六个色相区间调整色相、饱和度、明度

仿 GIMP「色相-饱和度」滤镜的 GEGL point filter，在 HSL 空间逐像素调整， 工作于感知（非线性）RGB 格式 R~G~B~A float，自动跟随源色彩空间。

功能

  • 主控：hue（度数 ±180）、saturation（±1，加法）、lightness（±1，加法）
  • 六个色相区间（红/黄/绿/青/蓝/品红，中心各相隔 60°）各自拥有独立的 *-hue / *-saturation / *-lightness，按三角形权重与主控叠加
  • overlap（0–1）：区间宽度 = 60° × (1 + overlap)。默认 0 = 六个区间恰好铺满色环、 区间中心获得 100% 设定；调大则相邻区间互相渗透（柔和但峰值强度按权重比例稀释）
  • 灰阶像素（S < 1e-5）不染色：色相/饱和度调整被跳过，仅应用明度
  • 全零参数时直接 memcpy 透传（含 alpha），HDR 超范围值按 [0,1] 截断后计算

构建（MSYS2 mingw64 / Git Bash）

export PKG_CONFIG_PATH="/d/fastsoftware/GIMP 3/lib/pkgconfig"
eval gcc -shared -I. -O2 -Wall wb-hue-saturation.c \
  $(pkg-config --cflags --libs gegl-0.4) -o wb-hue-saturation.dll

验证（不进 GIMP）

export GEGL_PATH="$(pwd -W);D:/fastsoftware/GIMP 3/lib/gegl-0.4"
gegl --info wb:hue-saturation
gegl test-in.png -o out.png -- wb:hue-saturation hue=45 green-saturation=-0.5

安装到 GIMP 3

把 wb-hue-saturation.dll 拷入 %LOCALAPPDATA%\gegl-0.4\plug-ins\ 后重启 GIMP， 用 / 打开 Search Actions 搜索 "Hue-Saturation (WB)"，滤镜以非破坏性 fx 形式挂在图层上。

在 GIMP 3 Python 中调用

from gi.repository import Gimp, Gegl

filter = Gimp.DrawableFilter.new(drawable, Gegl.Orientation.AUTO, "wb:hue-saturation", 0)
config = filter.get_config()
config.set_property("hue", 45.0)          # 度
config.set_property("saturation", 0.3)    # -1..1
config.set_property("green-saturation", -0.5)
drawable.merge_filter(filter)             # 非破坏性；Gimp.displays_flush() 刷新

Hue/Saturation

lb:hue-saturation Color per-pixel

GIMP-style Hue/Saturation — a master control plus six hue ranges, all offsets added in HSL.

A GEGL point filter modelled on GIMP's Hue-Saturation filter: per-pixel adjustments in HSL, working on the perceptual (non-linear) R~G~B~A float format and following the source colour space automatically.

Features

  • Master: hue (degrees, ±180), saturation (±1, additive), lightness (±1, additive)
  • Six hue ranges (red / yellow / green / cyan / blue / magenta, centres 60° apart), each with its own *-hue / *-saturation / *-lightness, blended with the master by a triangular weight
  • overlap (0–1): range width = 60° × (1 + overlap). The default of 0 makes the six ranges tile the wheel exactly, with each centre getting 100% of its setting; raising it lets neighbours bleed into each other (softer, but the peak strength is diluted in proportion)
  • Grey pixels (S < 1e-5) are not tinted: the hue and saturation adjustments are skipped and only lightness is applied
  • All-zero parameters memcpy straight through (alpha included); HDR values outside the range are clipped to [0,1] before the maths

Usage in GIMP 3 Python

from gi.repository import Gimp, Gegl

filter = Gimp.DrawableFilter.new(drawable, Gegl.Orientation.AUTO, "lb:hue-saturation", 0)
config = filter.get_config()
config.set_property("hue", 45.0)          # degrees
config.set_property("saturation", 0.3)    # -1..1
config.set_property("green-saturation", -0.5)
drawable.merge_filter(filter)             # non-destructive; Gimp.displays_flush() to refresh
