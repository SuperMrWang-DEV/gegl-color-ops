Hue/Saturation Range

lb:hue-range-basic 色彩 逐像素

色系范围调整：选一个色相族，在其软范围内应用色相/饱和度/明度，与 lb:hue-saturation-basic（全图）串联即接近某图像编辑器「色相/饱和度」对话框的「编辑」下拉 + 底部色条模型。

色相/饱和度·范围 —— 在一个色相族的软范围内调整色相、饱和度、明度。 与 Hue/Saturation (Basic)（全图/Master）串联，再用 Colorize 着色： 三个算子合起来复刻经典「色相/饱和度」对话框（编辑下拉 + 底部色条 + 着色）。

算法要点

  • 权重作用在【原始】色相上（先算 w 再调整），语义与内部蒙版一致； 无彩像素（R=G=B）不参与任何色系。四柄色条的权重是分段线性：
$$w(h) = \begin{cases} 0, & h < o_l \ \text{或}\ h > o_r \\[4pt] 1, & i_l \le h \le i_r \\[4pt] \dfrac{h-o_l}{i_l-o_l}, & o_l \le h < i_l \\[10pt] \dfrac{o_r-h}{o_r-i_r}, & i_r < h \le o_r \end{cases}$$

四柄都在 $0..360°$ 的圆上，先绕内区跨度解环绕再分段，所以范围可以拖过 $0/360$。

  • 调整量按 w 缩放后走全图算子的同一套公式（明度 screen/multiply → HSL → 色相加法 → 饱和度相对缩放）：w=1 时与 Hue/Saturation (Basic) 逐位一致， w=0 时逐位等于原图。
  • 四柄可拖过 0/360，实现按内区跨度解环绕。

Hue/Saturation Range

lb:hue-range-basic Color per-pixel

Hue, saturation and lightness inside one hue family with a soft four-handle colour bar — the per-family half of the classic Hue/Saturation dialog. Chain it after Hue/Saturation (Basic) for master + per-family editing, and with Colorize the trio reproduces the whole dialog.

Hue/Saturation Range

A classic Hue/Saturation dialog does three things: master adjustments over the whole image, per-family adjustments inside soft hue ranges, and colorize. This project splits that across three operators — Hue/Saturation (Basic) covers the master path, Colorize covers colorize, and this op is the missing per-family half: pick a hue family, adjust hue / saturation / lightness inside its soft range.

The four-handle colour bar

Each family has four handles on the hue circle. Pixels between the two inner handles are selected fully (weight 1); the weight ramps linearly from the inner handles out to the outer two handles; everything beyond is untouched. The defaults give each family centre ±15° selected and ±45° falloff, so the six families tile the wheel with overlapping feather:

A handle value of -1 (the default) follows the family default; dragging it sets an absolute angle from 0 to 360. Handles may cross 0/360 — the range is unwrapped around its inner span first.

Weighted adjustments, same formula as the master op

The weight is computed on the pixel's original hue — the range behaves like an internal mask. Achromatic pixels (R = G = B) join no family, so greys are never tinted. The four-handle bar weights are piecewise linear:

$$w(h) = \begin{cases} 0, & h < o_l \ \text{or}\ h > o_r \\[4pt] 1, & i_l \le h \le i_r \\[4pt] \dfrac{h-o_l}{i_l-o_l}, & o_l \le h < i_l \\[10pt] \dfrac{o_r-h}{o_r-i_r}, & i_r < h \le o_r \end{cases}$$

Handles live on the $0..360°$ circle; the range is unwrapped around its inner span first, so handles dragged across $0/360$ still work. The adjustments then scale by the weight and run through the exact same formula as Hue/Saturation (Basic): lightness as screen/multiply toward white/black, hue as a rotation, saturation as a relative scale (s/(1−x) up, s(1+x) down). At weight 1 the result is bit-identical to the master op; at weight 0 the pixel passes through untouched.

Verification

tools/check_hue_range_basic.py renders a nine-patch swatch card and compares every pixel against a line-by-line Python reference of the same maths: 8 cases — default ranges, weight-scaled hue (orange at 30° gets exactly half the shift of red), saturation driven to full, lightness, wrap-around handles, the green family, and a chained master → range run — all match to 0.0 codes across 216 sample points (tolerance 2).

Just this one

Windows module hue-range-basic.dll, drop it into %LOCALAPPDATA%\gegl-0.4\plug-ins; Linux module hue-range-basic.so, drop it into ~/.local/share/gegl-0.4/plug-ins, then restart GIMP. Every module here is a standalone GEGL module: it links only against the GEGL and babl that ship with GIMP, never against another module of this project, so one download is all it needs. The full bundle is on the download page.
