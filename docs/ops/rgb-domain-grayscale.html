Black & White

lb:rgb-domain-grayscale 影调与色阶 逐像素

经典图像编辑器 黑白：六个色相滑块（红/黄/绿/青/蓝/品红）加权转灰，可着色the classic editor Black & White: six hue sliders (red, yellow, green, cyan,blue, magenta) weight the grey conversion, with optionaltinting.

算法

六个色相滑杆（红 / 黄 / 绿 / 青 / 蓝 / 品红）决定每种颜色对灰度的贡献， 结果还可以着色——就是 经典图像编辑器的「黑白」对话框：把蓝拉低压暗天空，把黄推高提亮肤色， 其余部分不受影响。

RGB 三通道按六色权重加权求和；滑块量程 −200…300 与 经典图像编辑器 界面一致，默认值 （红 40、黄 60、绿 40、青 60、蓝 20、品红 80）取自 经典图像编辑器。

参数

参数默认说明
red / yellow / green40 / 60 / 40各色系的权重，−200…300
cyan / blue / magenta60 / 20 / 80各色系的权重，−200…300
tint_enabled关给灰度结果着色
tint_color#E0D4B2着色颜色（默认是暖棕）
tint_strength1着色强度，0…1

说明

  • 逐像素在 8 位 sRGB 伽马域计算，滑块手感与 经典图像编辑器 对话框一致。
  • alpha 保留，透明像素仍然透明。
  • 与 GIMP 的「去色」不同：这里的灰度不是固定亮度公式，每种颜色变成什么由你决定， 这正是「黑白」的用处。

Black & White

lb:rgb-domain-grayscale Tone per-pixel

the classic editor's Black & White — six hue sliders decide how much each colour contributes to grey, with an optional tint.

lb:rgb-domain-grayscale · menu Colors → SuperMrWang → Tone → Black & White · GeglOperationPointFilter (per-pixel)

What it does

Six hue sliders — red, yellow, green, cyan, blue, magenta — decide how strongly each colour in the image contributes to the grey result, and the grey can then be tinted. This is the classic editor's Black & White dialog: pull blue down and a blue sky goes dark, push yellow up and skin brightens, without any of it touching the rest of the frame.

The three RGB channels are combined with the six hue weights summed; the slider range −200…300 matches the the classic editor dialog, and the defaults (red 40, yellow 60, green 40, cyan 60, blue 20, magenta 80) are the classic editor's.

Parameters

ParameterDefaultNotes
red / yellow / green40 / 60 / 40Weight of each hue family, −200…300
cyan / blue / magenta60 / 20 / 80Weight of each hue family, −200…300
tint_enabledoffTint the grey result
tint_color#E0D4B2Tint colour (a warm sepia by default)
tint_strength1How strongly the tint is applied, 0…1

Notes

  • The operator runs per pixel in the 8-bit sRGB gamma domain, so the weights behave like the ones in the classic editor's dialog.
  • Alpha is preserved; transparent pixels stay transparent.
  • Unlike GIMP's Colors → Desaturate, the conversion is not a fixed luma formula: you choose what each colour becomes, which is the whole point of Black & White.

Just this one

Windows module rgb-domain-grayscale.dll, drop it into %LOCALAPPDATA%\gegl-0.4\plug-ins; Linux module rgb-domain-grayscale.so, drop it into ~/.local/share/gegl-0.4/plug-ins, then restart GIMP. The full bundle is on the download page.

2. How to Open the Plugin (2 Methods)

After installation, restart GIMP to activate the plugin.

Method 1: Menu Bar (Recommended)

Menu path: Colors → SuperMrWang → Tone → Black & White

Method 2: GEGL Operation

  1. Go to Filters → Generic → GEGL Operations
  2. In the search box, enter: lb:rgb-domain-grayscale
  3. Select it and click OK to apply
