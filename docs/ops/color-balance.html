Color Balance

lb:color-balance 色彩 整块区域

PS 色彩平衡：阴影 / 中间调 / 高光各自调 C-R、M-G、Y-B 三对色轴

对应 Photoshop「色彩平衡」调整。两个模式：

  • 不保留明度（默认）：PS 的逐通道曲线，见下面「算法」一节。
  • 保留明度：MATLAB 零和矩阵（系数减中位数 → 高光 in/(1−α) → 阴影 (in−α)/(1−α) → 中间调 in^γ），与 PS 实测最大差 3.0 码，未做改动。

算法（不保留明度）

一个通道（C-R 动 R、M-G 动 G、Y-B 动 B）只由自己那条滑杆决定，与其它两个通道无关。 三个色调区间的参数先合并成一条曲线：

G = g_阴影 · g_中间调 · g_高光          三个指数相乘
b = |s|        当阴影滑杆为负（黑场抬起来）
W = 255 − s    当高光滑杆为正（白场压下来）
其余情况 b = 0、W = 255

u   = (v − b) / (W − b)
out = 255 · u^G                       (u ≥ H)

近黑端另有一段「趾部」：G < 1 时 u^G 在 0 处斜率无穷，PS 实际是有限斜率起步。 把 [b, h0] 这一段换成三次 Hermite：

h0  = b + H · (W − b)
y1  = 255 · H^G                      区间右端值
out = Hermite( (v−b)/(h0−b), Su·H, y1, G·y1 )
  • 指数：中间调 2^(∓s/100)，阴影和高光各只有它的一半 2^(∓s/200)； 算子用实测表（cb-tables.h 的 CB_G），不套公式。
  • Su（归一化起点斜率）与 H（趾部宽度占比）都只随复合指数 G 变化， 与「这个 G 是哪个区间给的」无关：单区间档与组合档落在同一条曲线上（表 CB_TOE）。 G ≥ 0.85 时 H 衰减到 0，趾部自然消失。
  • 忽略趾部的话，中间调 +100 在 v≈4 处会差 16 码；补上后全档 ≤ 0.3 码。

参数由 cb-cal 的 Photoshop 标定得到（PS 26.10、16 位、600 档单区间 + 9 组合）， 完整推导与精度见 ../../cb-cal/RESULTS.md。

不要手改 cb-tables.h，它由 cb-cal/gen_cb_tables.py 从标定数据生成。

精度（1024 px 连续斜坡、16 位、全图逐像素）：

分组最大中位
阴影 ±1…±1000.21 码0.01 码
中间调0.30 码0.00 码
高光0.27 码0.00 码
组合0.65 码0.06 码

（0.03 码 = 1 个 16 位 LSB）

sh build_linux.sh

2. How to Open the Plugin (2 Methods)

After installation, restart GIMP to activate the plugin.

Method 1: Menu Bar (Recommended)

Menu path: Colors → SuperMrWang → Color → Color Balance

Method 2: GEGL Operation

  1. Go to Filters → Generic → GEGL Operations
  2. In the search box, enter: lb:color-balance
  3. Select it and click OK to apply

3. Algorithm (preserve-luminosity off)

Each range drives exactly one channel, independent of the other two. The three ranges do not apply as three curves in sequence; their parameters merge into a single levels-style curve:

G = g_shadow · g_midtone · g_highlight      exponents multiply
b = |s|        when the shadow slider is negative    (black point)
W = 255 - s    when the highlight slider is positive (white point)
otherwise b = 0, W = 255

out = 255 · ((v - b)/(W - b))^G            (u >= H)

Near black the power law is replaced by one cubic Hermite on [b, h0]: h0 = b + H·(W-b), y1 = 255·H^G, and the curve is Hermite((v-b)/(h0-b), Su·H, y1, G·y1).

Midtones use 2^(∓s/100), shadows and highlights half of that (2^(∓s/200)); the op reads measured tables (CB_G) instead of the formula. Both Su (normalised initial slope) and H (toe width) depend on the composite exponent G alone — single-range and combo settings fall on the same Su(G) — and H decays to 0 at G >= 0.85 (table CB_TOE).

Measured against Photoshop 26.10 (16-bit, 600 slider settings + 9 combos): max 0.30 codes per range, 0.65 codes for combos. See ../../cb-cal/RESULTS.md.

4. Preserve luminosity

Unchanged MATLAB zero-sum implementation; max 3.0 codes against Photoshop.
