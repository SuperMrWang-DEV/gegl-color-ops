Natural Saturation

lb:vibrance-hyper 色彩 逐像素

自然饱和度：提升低饱和区，抑制高饱和与肤色，不破坏色相

算法说明（2026-11 重写）

在 LAB（D65）空间处理，工作于线性 sRGB，自动跟随输入色彩空间。

蒙版结构 $M = M_{\text{chroma}}(C^*)\times M_{\text{skin}}(h)\times M_{\text{gamut}}$

  • $M_{\text{chroma}} = \dfrac{1}{1+\alpha\,(C^*/50)^{1.3}}$：读源图色度 $C^*$，色度越高增益越低； 指数 1.3 让 C*>60 掉得比纯双曲线更快。与 Saturation 滑杆互不影响。
  • M_skin：LAB 色相 55° 附近（橙/肤色带）、色度 8–80 区间时降权， 用 smoothstep 软窗，边界无硬边。强度由 Skin Protection（默认 0.7）控制，0 = 关闭。
  • M_gamut：色度沿原色相、原明度放大后，若超出 sRGB 色域，按 5 步二分收敛 到色域边界内的最大值。色相与明度恒不变，替代逐通道硬裁剪（硬裁剪会扭色相）。

vibrance 滑杆（±50 UI 范围）等效于低饱和区 C* 的最大 ×2（+50）/ ×3（+100）放大； 全局 Saturation 是独立的线性色度乘法，与蒙版无关。

实测（10 个标准色块，vibrance=+50）：色相偏移 ≤0.7°（旧版最高 10.2°）； 肤色增幅 1.16–1.18×（旧版 1.47–1.55×）；低饱和区 1.76–2.00×。 vibrance=0 且 saturation=1 时输出与输入逐字节一致。

Vibrance (Lab)

lb:vibrance-hyper Color per-pixel

An appearance-based vibrance in Lab — hyperbolic chroma mask, skin-tone protection and gamut mapping that never shifts hue.

Algorithm (rewritten 2026-11)

Everything happens in LAB (D65) on linear sRGB, following the input colour space automatically.

Mask structure M = M_chroma(C*) × M_skin(h) × M_gamut

  • $M_{\text{chroma}} = \dfrac{1}{1+\alpha\,(C^*/50)^{1.3}}$: reads the source chroma C\, so the higher the chroma the lower the gain; the exponent 1.3 makes C\>60 fall off faster than a plain hyperbola. Independent of the Saturation slider.
  • M_skin: reduces the weight around LAB hue 55° (orange and skin tones) with chroma 8–80, using a smoothstep window so the boundary has no hard edge. Strength is set by Skin Protection (default 0.7); 0 disables it.
  • M_gamut: after chroma is scaled at the original hue and lightness, anything outside sRGB is pulled back by a five-step bisection to the largest value inside the gamut. Hue and lightness never change, which replaces per-channel clipping (clipping twists hue).

The vibrance slider (±50 in the UI) is equivalent to at most ×2 at +50 and ×3 at +100 for low-chroma C\*; the global Saturation is a separate linear chroma multiply that ignores the mask.

Measured (10 standard patches, vibrance=+50): hue shift ≤ 0.7° (the old build reached 10.2°); skin tones gain 1.16–1.18× (old build 1.47–1.55×); low-chroma areas 1.76–2.00×. At vibrance=0 and saturation=1 the output is byte-identical to the input.

Relation to lb:vibrance

lb:vibrance is the numerical reproduction of the classic editor's Vibrance — match the numbers, no artistic controls. This one is an appearance model: the parameters mean something (chroma ceiling, skin protection, gamut handling) and the result looks good, but it will not agree with the classic editor code for code. Use this when you want control, that one when you want the classic editor to agree.
