Reduce Noise

lb:reduce-noise 杂色 AreaFilter

Photoshop「滤镜 → 杂色 → 减少杂色」的等价物：只平均那些「和中心像素差不多」的邻居，差得多的（边缘、细节）不参与。结果是平坦区被磨平、边缘原样保留。

lb:reduce-noise · 菜单 SuperMrWang → Noise → Reduce Noise · 单输入

只平均「和中心差不多」的邻居，差得多的（边缘、细节）不参与。结果是平坦区被磨平、边缘原样保留——这是 sigma 滤波（Lee 1983），PS「减少杂色」用的也是这一族。

参数 / Parameters

参数范围默认含义
strength 强度0–100%50阈值 t = 22% × strength；越大抹得越狠
detail 保留细节0–100%20把 t 最多收窄 80%，保纹理
radius 半径1–102邻域半径，1 即 3×3
per-channel 每通道开 / 关关关时三通道共用一份权重（色噪点一起消失、色调不变）；开时各算各的

算法

对每个像素，取 (2r+1)² 邻域，用通道差的最大值 d 定权重：

w = max(0, 1 − (d / t)²)
out = Σ(w·v) / Σw

d > t 的邻居权重为 0，所以边缘另一侧的像素不会把这一侧拉过去——这就是它不糊边的原因，不需要任何边缘检测。中心像素的 d = 0，权重恒为 1。

per-channel 关闭时，d 取三个通道的最大值，权重只有一份，三个通道共用：彩色噪点被平均掉，通道之间的比例关系不变（不会出现「降噪后颜色发灰」）。

strength = 0 时 t = 0，只有完全相同的邻居参与平均，结果就是原图。

用法 / Recipes

  • 高 ISO 降噪：strength=60 detail=25 radius=2 per-channel=on
  • 只剩彩色噪点：strength=80 detail=0 radius=3 per-channel=off
  • 磨皮前置：strength=40 detail=60 radius=2，随后交给高低频磨皮

Reduce Noise

lb:reduce-noise Noise AreaFilter

A sigma filter that averages only neighbours close to the centre pixel, so flat areas smooth out and edges stay exactly where they were.

lb:reduce-noise · menu SuperMrWang → Noise → Reduce Noise · one input

Averages only the neighbours that are close to the centre pixel; the ones that differ a lot — edges, detail — take no part. Flat areas are smoothed, edges survive untouched. This is a sigma filter (Lee 1983), the family Photoshop's Reduce Noise belongs to.

Parameters

ParameterRangeDefaultMeaning
strength0–100%50Threshold t = 22% × strength; larger smooths harder
detail0–100%20Narrows t by up to 80%, keeping texture
radius1–102Neighbourhood radius; 1 is a 3×3 window
per-channelon / offoffOff: one weight set shared by all channels (colour speckle goes, hues stay). On: each channel on its own

Algorithm

For every pixel, over the (2r+1)² neighbourhood, the weight comes from the largest channel difference d:

w = max(0, 1 − (d / t)²)
out = Σ(w·v) / Σw

Neighbours with d > t get weight 0, so pixels on the far side of an edge cannot pull this side over. That is why it does not blur edges — and it needs no edge detection to do it. The centre pixel has d = 0 and therefore weight 1.

With per-channel off, d is the maximum over the three channels and one weight set is applied to all of them: colour noise averages out while the ratios between channels stay put, so nothing turns grey. With strength = 0 the threshold is 0 and only identical neighbours contribute — the output is the input.

Recipes

  • High-ISO cleanup: strength=60 detail=25 radius=2 per-channel=on
  • Colour speckle only: strength=80 detail=0 radius=3 per-channel=off
  • Before frequency separation: strength=40 detail=60 radius=2

Testing
