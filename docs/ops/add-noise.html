Add Noise

lb:add-noise 杂色 整块区域

Photoshop「滤镜 → 杂色 → 添加杂色」的等价物：给每个像素叠一层随机扰动。加颗粒、做旧、掩盖色带、给渐变加「胶片感」都是它。

lb:add-noise · 菜单 SuperMrWang → Noise → Add Noise · 单输入

给每个像素叠一层随机扰动。加胶片颗粒、做旧、掩盖 8 位渐变的色带都用它。与 PS 的不同在于种子可控：同一张图、同一个种子，输出逐位相同。

参数 / Parameters

参数范围默认含义
amount 数量0–100%10噪点强度。高斯时 σ = 25% × amount，均匀时幅度 ±50% × amount
distribution 分布高斯 / 均匀高斯高斯像胶片与传感器噪点；均匀像数字抖动
monochrome 单色开 / 关关三个通道共用同一个扰动，得到灰度颗粒而不是彩色噪点
seed 种子0–9999991决定随机序列，用于复现

算法

按行播种：第 y 行的种子由 seed 与 y 混合得到（y 参与哈希，不是简单相加），因此分带处理与整张处理逐位相同——这是「可复现」能成立的前提。高斯用 Box–Muller：

u1, u2 ~ U(0,1]
n = sqrt(−2 ln u1) · cos(2π u2)

三个通道各自取一个 n；monochrome 时只取一次，三个通道共用。

alpha 完全不动：叠噪点改的是像素值，不是图层透明度。

用法 / Recipes

  • 胶片颗粒：amount=8 distribution=gaussian monochrome=on
  • 掩盖 8 位色带：amount=3 distribution=uniform monochrome=on，再叠 1px 模糊
  • 做旧：amount=15 distribution=gaussian，配合 lb:reduce-noise 反向调节

与 Photoshop 的差异

PS 添加杂色lb:add-noise
数量 / 分布 / 单色有有
可复现无（每次应用都换随机数）有（同种子逐位相同）
影响 alpha不动不动

测试 / Testing

python tools/check_noise_sharpen.py：数量 0 恒等、同种子逐位相同、换种子不同、单色时三通道相等、均值不偏移、α 透传。

Add Noise

lb:add-noise Noise area

Gaussian or uniform noise, monochromatic or per channel, with a seed so the grain can be reproduced exactly.

lb:add-noise · menu SuperMrWang → Noise → Add Noise · one input

Random perturbation per pixel — film grain, ageing, or hiding the banding in an 8-bit gradient. Unlike Photoshop, the seed is exposed: same image and same seed give byte-identical output.

Parameters

ParameterRangeDefaultMeaning
amount0–100%10Strength. Gaussian: σ = 25% × amount. Uniform: ±50% × amount
distributionGaussian / UniformGaussianGaussian looks like film and sensor noise, uniform looks like dithering
monochromeon / offoffOne value for all three channels, giving grey grain instead of colour speckle
seed0–9999991Drives the sequence, so a look can be reproduced

Algorithm

Seeding is per row: row y gets a seed mixed from seed and y (hashed, not added), so processing the image in bands gives exactly the same bytes as processing it in one go. That is what makes reproducibility hold.

Gaussian noise comes from Box–Muller:

u1, u2 ~ U(0,1]
n = sqrt(−2 ln u1) · cos(2π u2)

Each channel draws its own n; with monochrome one draw is shared by all three. alpha is never touched — noise changes pixel values, not opacity.

Recipes

  • Film grain: amount=8 distribution=gaussian monochrome=on
  • Hide 8-bit banding: amount=3 distribution=uniform monochrome=on, then a 1px blur
  • Ageing: amount=15 distribution=gaussian, balanced with lb:reduce-noise

Testing

python tools/check_noise_sharpen.py — identity at amount 0, same seed identical, different seed different, three channels equal in monochrome mode, mean unmoved, alpha passthrough.

Just this one

Every module here is a standalone GEGL module: it links only against the GEGL and babl that ship with GIMP, never against another module of this project, so one download is all it needs.
