Channel Mixer Plus

lb:channel-mixer-plus 混合与通道 逐像素

经典图像编辑器 通道混合器：每路输出通道由 RGB 三源加权相加，并带通道偏移the classic editor Channel Mixer: every output channel is a weighted sum of

算法

每路输出通道都是 RGB 三源通道的加权和，再加该通道自己的常数项：

$$\begin{aligned} R' &= r_r\,R + r_g\,G + r_b\,B + r_{\text{off}} \\ G' &= g_r\,R + g_g\,G + g_b\,B + g_{\text{off}} \\ B' &= b_r\,R + b_g\,G + b_b\,B + b_{\text{off}} \end{aligned}$$

默认是单位矩阵（对角 1、其余 0）、常数全 0，所以什么都不动时算子等于直通。 结果裁到 0..1。增益允许 −2…2，既能加也能减某个通道。

单色

monochrome 打开后三路共用一组系数（mono_r / mono_g / mono_b，默认 0.33 / 0.33 / 0.34）加一个 mono_offset，输出灰图——就是 经典图像编辑器 那个单色勾选框。 此时逐通道矩阵被忽略，两套设置可以共存，来回切换不丢。

参数

参数默认说明
monochrome关单组系数出灰（经典图像编辑器 单色）
mono_r / mono_g / mono_b0.33 / 0.33 / 0.34单色权重，默认和为 1
mono_offset0单色常数
rr_gain / rg_gain / rb_gain1 / 0 / 0输出 R 取 R / G / B 的权重
gr_gain / gg_gain / gb_gain0 / 1 / 0输出 G 的三个权重
r_offset / g_offset / b_offset0各输出通道的常数项

与 GEGL 内置 channel-mixer 的差别

GEGL 自带 gegl:channel-mixer，矩阵是一样的，但没有每通道常数，多一个 「保持明度」。本算子补上常数项（就是 经典图像编辑器的「常数」滑杆），去掉保持明度： 加完常数再按亮度缩放，两个方向会互相拉扯。

Channel Mixer Plus

lb:channel-mixer-plus Blend per-pixel

The classic editor's Channel Mixer — a 3×3 matrix from R/G/B into each output channel, plus a constant offset per channel and a monochrome mode.

lb:channel-mixer-plus · menu Colors → SuperMrWang → Blend → Channel Mixer Plus · GeglOperationPointFilter (per-pixel)

What it does

Each output channel is a weighted sum of the three input channels plus its own constant offset:

$$\begin{aligned} R' &= r_r\,R + r_g\,G + r_b\,B + r_{\text{off}} \\ G' &= g_r\,R + g_g\,G + g_b\,B + g_{\text{off}} \\ B' &= b_r\,R + b_g\,G + b_b\,B + b_{\text{off}} \end{aligned}$$

The defaults are the identity matrix (1 on the diagonal, 0 elsewhere) with every offset at 0, so the operator passes the image through untouched until you move something. Results are clipped to 0..1.

Monochrome

With monochrome on, the three output channels share one set of coefficients (mono_r / mono_g / mono_b, plus mono_offset) and the image turns grey — the same thing the classic editor's monochrome checkbox does. The per-channel matrix is ignored in that mode, so you can keep both settings and flip between them.

Parameters

ParameterDefaultNotes
monochromeoffSingle-coefficient grey output, classic style
mono_r / mono_g / mono_b0.33 / 0.33 / 0.34Monochrome weights (sum to 1 by default)
mono_offset0Monochrome constant
rr_gain, rg_gain, rb_gain1, 0, 0R out of R / G / B
gr_gain, gg_gain, gb_gain0, 1, 0G out of R / G / B
bg_gain etc.…Blue row, same layout
r_offset, g_offset, b_offset0Constant added to each output channel

Every gain accepts −2…2, so you can subtract a channel as well as add it.

How it differs from GEGL's built-in channel-mixer

GEGL core ships a gegl:channel-mixer with the same matrix, but no per-channel constant and a "keep luminosity" option. This operator adds the offsets — which is what the classic editor's Constant sliders are — and leaves luminosity preservation out, because adding a constant and then rescaling luminance pulls the result in two directions at once.
