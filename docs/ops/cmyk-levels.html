CMYK Levels

lb:cmyk-levels 色阶家族 整块区域

CMYK 四个分量各自设输入 / 输出黑白场与伽马

菜单：SuperMrWang → Levels → CMYK Levels（Filter 类）

概述

对 C / M / Y / K 四个印版各自做独立色阶：墨量黑场、白场、gamma、输出上下限。想做「K 版单独压暗中间调」「只给青版加反差」这类分色调整时用它。

色彩空间

工作在 babl 的 CMYKA float 上，RGB↔CMYK 由 babl 完成，与 GIMP 「分解 → CMYK」同一套转换。

这不是 ICC 分色。 babl 的 CMYK 带黑版生成（GCR/UCR 意义上的），实测：

RGBCMYK
中性灰 0.500078.6%
(0.8, 0.45, 0.2)071.7%94.5%39.6%
纯红0100%100%0

所以 K 不是 1−max(R,G,B)（灰 0.5 时那是 50%，这里是 78.6%）。要按印前特性文件（SWOP/FOGRA 等）分色，得走 ICC 流程，本算子只提供「设备无关的 babl 分色 + 分版色阶」。

$$u = \operatorname{clamp}\!\left(\frac{x-x_{\text{lo}}}{x_{\text{hi}}-x_{\text{lo}}},\,0,\,1\right), \qquad \text{out} = o_{\text{lo}} + u^{1/\gamma}\,\bigl(o_{\text{hi}}-o_{\text{lo}}\bigr)$$

$o_{\text{lo}} > o_{\text{hi}}$ 时输出反相；结果夹在 $[\min(o_{\text{lo}},o_{\text{hi}}),\ \max(o_{\text{lo}},o_{\text{hi}})]$ 内。

规则细则

  • 四个分量都是线性 0–100% 墨量通道：clamp → 归一化 → gamma → 输出范围。
  • K 拉满（输出 100%）→ 全黑：K=100 时 CMY 已经无关，整幅压成黑版。
  • C/M/Y 归零 → 只剩 K 的中性图：没有彩色墨，只剩黑版灰度。
  • 色阶只映射已经算出来的墨量，不回算 GCR：把 K 从 78.6% 拉到 90% 之后， CMY 不会自动减少去补总墨量（TAC）。想要「加深 K 同时减 CMY」得分别调两条 曲线，或者改用 ICC 分色 + 曲线。
  • 黑白场交叉自动交换；输出反向即墨量反相（白字变成实地）。
  • alpha ≤ 0 透传。

验证

python tools/check_color_levels.py cmyk（3 项）：

用例判据实测
恒等（默认参数）与源图逐像素 ≤1 码最大 0
C/M/Y 归零全图中性（|R−G|、|G−B| ≤2）0
K 拉满全图最亮通道 ≤120

恒等 0 码说明 RGB→CMYK→RGB 这条 babl 往返在默认参数下不漂；后两条验证「某个版归零/拉满必须产生可预期的画面」——也就是说色阶确实作用在对应的印版上，没有错位。

已知事项

  • babl 的 CMYK 是没有纸白与油墨特性的简化分色，同一组 RGB 换算出的 墨量与实际印刷无关；它适合「按版做局部调整」这类操作，不适合当作打样数值。
  • CMYK 色域比 sRGB 小，来回转换会在饱和色上产生裁切（尤其纯绿/纯蓝）。
  • 8 位/16 位模式下墨量量化台阶比 RGB 粗，重压 K 曲线时容易出现断层。

只要这一个

Windows 模块 cmyk-levels.dll，放进 %LOCALAPPDATA%\gegl-0.4\plug-ins；Linux 模块 cmyk-levels.so，放进 ~/.local/share/gegl-0.4/plug-ins，然后重启 GIMP。这里的每个模块都是独立的 GEGL 模块，只链接 GIMP 自带的 GEGL 与 babl，不依赖本项目里的其它模块——下这一个就够用，不会缺东西。要一次装齐，用整包。

CMYK Levels

lb:cmyk-levels Levels area

Independent levels for the C/M/Y/K plates — ink black and white points, gamma, output range — on babl's device-independent CMYK.

Menu: Colors → SuperMrWang → Tone → CMYK Levels (a filter op)

Overview

Independent levels for each of the four printing plates: ink black point, white point, gamma and output range. Use it for separations-level adjustments such as "darken the K plate's midtones" or "add contrast to cyan only".

Colour space

The operator works on babl's CMYKA float; RGB↔CMYK is done by babl, the same conversion GIMP's "Decompose → CMYK" uses.

This is not an ICC separation. babl's CMYK includes black generation (in the GCR/UCR sense). Measured:

RGBCMYK
neutral grey 0.500078.6%
(0.8, 0.45, 0.2)071.7%94.5%39.6%
pure red0100%100%0

So K is not 1−max(R,G,B) — that would be 50% for grey 0.5, and this gives 78.6%. For a real prepress separation (SWOP/FOGRA profiles) you need an ICC workflow; this operator offers "device-independent babl separation + per-plate levels" and nothing more.

$$u = \operatorname{clamp}\!\left(\frac{x-x_{\text{lo}}}{x_{\text{hi}}-x_{\text{lo}}},\,0,\,1\right), \qquad \text{out} = o_{\text{lo}} + u^{1/\gamma}\,\bigl(o_{\text{hi}}-o_{\text{lo}}\bigr)$$

An inverted output ($o_{\text{lo}} > o_{\text{hi}}$) gives a negative-style inverse; the result is clamped to $[\min(o_{\text{lo}},o_{\text{hi}}),\ \max(o_{\text{lo}},o_{\text{hi}})]$.

Rules

  • All four components are linear 0–100% ink channels: clamp → normalise → gamma → output range.
  • K at maximum (output 100%) means solid black: with K=100 the CMY values no longer matter, since the whole image collapses into the black plate.
  • C/M/Y at zero leaves only the K plate: a neutral greyscale image with no coloured ink.
  • Levels map the ink that was already computed; they never re-run GCR. Pulling K from 78.6% to 90% does not make CMY drop to keep total area coverage in check. To "deepen K while reducing CMY" you adjust two curves by hand, or go ICC.
  • Crossing black and white points swap automatically; inverting the output range inverts the ink (white type becomes a solid).
  • alpha ≤ 0 is passed through.

Verification

python tools/check_color_levels.py cmyk (3 cases):

CaseCriterionMeasured
identity (defaults)≤1 code per pixel against the sourcemax 0
C/M/Y to zerowhole image neutral (|R−G|, |G−B| ≤ 2)0
K at maximumbrightest channel ≤ 12 everywhere0

The identity case at 0 codes shows the RGB→CMYK→RGB round trip through babl does not drift at default settings; the other two prove that zeroing or maxing a plate produces the expected picture — i.e. the levels really act on the plate they name.

Known issues

  • babl's CMYK is a simplified separation with no paper white or ink characteristics; the ink it computes from a given RGB has nothing to do with real printing. It suits "adjust one plate locally", not proofing numbers.
  • CMYK's gamut is smaller than sRGB, so round trips clip saturated colours (especially pure green and blue).
  • In 8- and 16-bit modes the ink quantisation step is coarser than in RGB, so a hard K curve shows banding.

Just this one
