LCh Compose

lb:lch-compose 分量 整块区域

LCh 分量曲线工作流的合成器：把「R = L/100、G = C/140、B = 色相/360」的数据图还原成真实颜色

把数据图还原成真实颜色：R = L/100、G = C/140、B = 色相/360，先把它们乘回物理量（L、C、h），再由 babl 转成 RGB。

(L/100, C/140, h/360) ──lb:lch-compose──> 真实颜色

输入约定是硬的

本算子无法分辨输入是一张数据图还是一张普通照片——它一律按「R 是明度、 G 是彩度、B 是色相」解释。挂错地方会把照片当成数据算出一张乱七八糟的图。

正常用法是紧跟在 lb:lch-dual 之后（中间夹三条曲线）：

lb:lch-dual → L 曲线(红) → C 曲线(绿) → h 曲线(蓝) → lb:lch-compose

和 Lab 的关系

LCh 就是 Lab 的极坐标：a = C·cos h、b = C·sin h。转换走 babl 的 CIE LCH(ab) alpha float（D50），与 lb:lch-levels、lb:lab-compose 同一套 Lab 口径，所以三家算出来的颜色是一致的。

实测

  • dual → compose 恒等往返：32 位浮点 0.0005 码，8 位 0.49 码。
  • 在完整插件里（tools/check_lch_split.py 33 项）：改 C 曲线后 L* 与色相的偏差 在 0.00001 码级。

注意

  • 输出 alpha 恒 1，理由同 lb:lch-dual。
  • 彩度或色相推到极端会出 sRGB 色域，8 位图按 0/1 裁掉——LCh 的色域比 sRGB 大， 这是它本身的性质，不是算子的近似。
  • 色相是环形量：0 与 1 表示同一个角度。

只要这一个

Windows 模块 lch-compose.dll，放进 %LOCALAPPDATA%\gegl-0.4\plug-ins；Linux 模块 lch-compose.so，放进 ~/.local/share/gegl-0.4/plug-ins，然后重启 GIMP。这里的每个模块都是独立的 GEGL 模块，只链接 GIMP 自带的 GEGL 与 babl，不依赖本项目里的其它模块——下这一个就够用，不会缺东西。要一次装齐，用整包。

LCh Compose

lb:lch-compose Component area

Turns the LCh data image back into colour — lightness, chroma and hue multiplied back to physical units, then converted through babl's D50 LCh space.

Menu: Colors → SuperMrWang → Component → LCh Compose (a filter op)

Overview

Restores a data image to real colour: R = L/100, G = C/140, B = hue/360 are scaled back to physical units (L, C, h) and handed to babl for the RGB conversion.

(L/100, C/140, h/360) ──lb:lch-compose──> real colour

The input convention is strict

The operator cannot tell a data image from an ordinary photo — it always reads R as lightness, G as chroma and B as hue. Put it in the wrong place and it will happily turn a photo into nonsense.

The intended chain keeps it right behind lb:lch-dual, with the curves in between:

lb:lch-dual → L curve (red) → C curve (green) → h curve (blue) → lb:lch-compose

Relation to Lab

LCh is Lab in polar form: a = C·cos h, b = C·sin h. The conversion goes through babl's CIE LCH(ab) alpha float (D50), the same Lab definition lb:lch-levels and lb:lab-compose use, so all three agree on the resulting colour.

Verification

  • dual → compose identity round trip: 0.0005 codes in 32-bit float, 0.49 codes in 8-bit.
  • Inside the full plug-in (tools/check_lch_split.py, 33 assertions): after editing the C curve, L* and hue deviate on the order of 0.00001 codes.

Notes

  • Output alpha is always 1, for the same reason as lb:lch-dual.
  • Extreme chroma or hue leaves the sRGB gamut and 8-bit output clips at 0/1 — LCh's gamut is larger than sRGB, which is a property of the space, not an approximation in the operator.
  • Hue is circular: 0 and 1 are the same angle.

Just this one

Windows module lch-compose.dll, drop it into %LOCALAPPDATA%\gegl-0.4\plug-ins; Linux module lch-compose.so, drop it into ~/.local/share/gegl-0.4/plug-ins, then restart GIMP. Every module here is a standalone GEGL module: it links only against the GEGL and babl that ship with GIMP, never against another module of this project, so one download is all it needs. The full bundle is on the download page.
