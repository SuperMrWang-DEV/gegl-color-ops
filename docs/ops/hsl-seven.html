HSL 7 Bands

lb:hsl-seven 色彩 逐像素

红/橙/黄/绿/青/蓝/紫/洋红八段色相各自调 H/S/L，ACR 风格

2026-11-12：按 ACR 8 段混色器补齐洋红段——原紫段 0.78~0.92 对半拆为 紫 0.78~0.85 与洋红 0.85~0.92。旧 7 段属性名与边界行为不变，算子 id 仍为 lb:hsl-seven（GIMP 存进 XCF 的字符串，不能改）。

这个算子做什么

八段色相（红 / 橙 / 黄 / 绿 / 青 / 蓝 / 紫 / 洋红）各带一组 H/S/L 偏移，共 24 个 滑块，按色相段加权叠加，段间由 feather 交叉淡化；饱和度低于 min-saturation 的灰像素可以选择跳过（灰没有有意义的色相）。参照物是 Adobe Camera Raw 的 HSL 面板： 只想压掉某几个色相的饱和、或者只把某个色相提亮，就拖那一段。

2026-11-12：补上洋红段

Camera Raw 的混色器是八段，本算子原来只有七段。原紫段（0.78–0.92）对半拆成 紫 0.78–0.85 与洋红 0.85–0.92。

原来七段的属性名与边界行为不变，算子 id 仍是 lb:hsl-seven——这个字符串是 GIMP 存进 XCF 的东西，不能改。

与 lb:hue-saturation 的分工

lb:hue-saturation 是 PS 的对话框：一个主控加六个色相区间，做的是相对偏移、在 HSL 上加减。本算子对应 Camera Raw 的混色器：八段、每段三个分量。思路相同，面板与数值 都不同，看惯哪个用哪个。

HSL 8 Bands

lb:hsl-seven Color per-pixel

Eight hue bands (red, orange, yellow, green, cyan, blue, purple, magenta), each with its own H/S/L shift — Camera Raw's HSL panel.

lb:hsl-seven · menu Colors → SuperMrWang → Color → HSL 8 Bands · GeglOperationPointFilter (per-pixel)

What it does

Eight hue bands — red, orange, yellow, green, cyan, blue, purple, magenta — each with its own hue, saturation and lightness shift: 24 sliders in all, weighted by hue band and summed, with feather cross-fading adjacent bands. Pixels below min-saturation (greys, which have no meaningful hue) can be skipped.

The reference is Adobe Camera Raw's HSL panel: pull one band's saturation down to desaturate just those hues, or push a band's lightness to open up one colour without touching the rest.

Change of 2026-11-12: the magenta band was added

Camera Raw's mixer has eight bands; this operator had seven. The old purple band (0.78–0.92) is now split in half: purple 0.78–0.85 and magenta 0.85–0.92.

The seven original property names and their boundary behaviour are unchanged, and the operator id stays lb:hsl-seven — that string is what GIMP stores in XCF files and cannot be renamed.

Relation to lb:hue-saturation

lb:hue-saturation is Photoshop's dialog: a master control plus six hue ranges, relative offsets, HSL arithmetic. This one is Camera Raw's mixer: eight bands, all three components per band. Same idea, different layout and different numbers — pick the one whose panel you are used to.

Just this one

Windows module hsl-seven.dll, drop it into %LOCALAPPDATA%\gegl-0.4\plug-ins; Linux module hsl-seven.so, drop it into ~/.local/share/gegl-0.4/plug-ins, then restart GIMP. The full bundle is on the download page.
