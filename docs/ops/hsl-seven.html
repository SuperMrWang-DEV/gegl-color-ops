HSL 7 Bands

lb:hsl-seven 色彩 逐像素

红/橙/黄/绿/青/蓝/紫/洋红八段色相各自调 H/S/L，经典 RAW 编辑器风格

2026-11-12：按 RAW 编辑器 8 段混色器补齐洋红段——原紫段 0.78~0.92 对半拆为 紫 0.78~0.85 与洋红 0.85~0.92。旧 7 段属性名与边界行为不变，算子 id 仍为 lb:hsl-seven（GIMP 存进 XCF 的字符串，不能改）。

这个算子做什么

八段色相（红 / 橙 / 黄 / 绿 / 青 / 蓝 / 紫 / 洋红）各带一组 H/S/L 偏移，共 24 个 滑块，按色相段加权叠加，段间由 feather 交叉淡化；饱和度低于 min-saturation 的灰像素可以选择跳过（灰没有有意义的色相）。参照物是 RAW 编辑器 的 HSL 面板： 只想压掉某几个色相的饱和、或者只把某个色相提亮，就拖那一段。

算法

八段色相各有一套 H/S/L 偏移，按段权重叠加；段边界用 smoothstep 交叉淡化：

$$w_k(h) = \sigma\!\left(h,\ s_k-f,\ s_k\right)\cdot\Bigl(1-\sigma\bigl(h,\ e_k,\ e_k+f\bigr)\Bigr), \qquad f = 0.01\cdot\text{feather}$$
$$H \mathrel{+}= \frac{\Delta H_k}{100}\cdot 60°\,w_k,\qquad S \mathrel{+}= \frac{\Delta S_k}{100}\,w_k,\qquad L \mathrel{+}= \frac{\Delta L_k}{100}\,w_k$$

八段首尾相接（红 0–45°、橙 45–90°……洋红 315–360°），权重和恒为 1； $S < \text{min-saturation}$ 的灰像素可以整段跳过。

2026-11-12：补上洋红段

RAW 编辑器 的混色器是八段，本算子原来只有七段。原紫段（0.78–0.92）对半拆成 紫 0.78–0.85 与洋红 0.85–0.92。

原来七段的属性名与边界行为不变，算子 id 仍是 lb:hsl-seven——这个字符串是 GIMP 存进 XCF 的东西，不能改。

与 lb:hue-saturation 的分工

lb:hue-saturation 是 经典图像编辑器的对话框：一个主控加六个色相区间，做的是相对偏移、在 HSL 上加减。本算子对应 RAW 编辑器 的混色器：八段、每段三个分量。思路相同，面板与数值 都不同，看惯哪个用哪个。

只要这一个

Windows 模块 hsl-seven.dll，放进 %LOCALAPPDATA%\gegl-0.4\plug-ins；Linux 模块 hsl-seven.so，放进 ~/.local/share/gegl-0.4/plug-ins，然后重启 GIMP。这里的每个模块都是独立的 GEGL 模块，只链接 GIMP 自带的 GEGL 与 babl，不依赖本项目里的其它模块——下这一个就够用，不会缺东西。要一次装齐，用整包。

HSL 8 Bands

lb:hsl-seven Color per-pixel

Eight hue bands (red, orange, yellow, green, cyan, blue, purple, magenta), each with its own H/S/L shift — the RAW editor's HSL panel.

lb:hsl-seven · menu Colors → SuperMrWang → Color → HSL 8 Bands · GeglOperationPointFilter (per-pixel)

What it does

Eight hue bands — red, orange, yellow, green, cyan, blue, purple, magenta — each with its own hue, saturation and lightness shift: 24 sliders in all, weighted by hue band and summed, with feather cross-fading adjacent bands. Pixels below min-saturation (greys, which have no meaningful hue) can be skipped.

The reference is the RAW editor's HSL panel: pull one band's saturation down to desaturate just those hues, or push a band's lightness to open up one colour without touching the rest.

Change of 2026-11-12: the magenta band was added

the RAW editor's mixer has eight bands; this operator had seven. The old purple band (0.78–0.92) is now split in half: purple 0.78–0.85 and magenta 0.85–0.92.

The seven original property names and their boundary behaviour are unchanged, and the operator id stays lb:hsl-seven — that string is what GIMP stores in XCF files and cannot be renamed.

Algorithm

Eight hue bands each carry their own H/S/L offset, summed with band weights; the boundaries cross-fade with smoothstep:

$$w_k(h) = \sigma\!\left(h,\ s_k-f,\ s_k\right)\cdot\Bigl(1-\sigma\bigl(h,\ e_k,\ e_k+f\bigr)\Bigr), \qquad f = 0.01\cdot\text{feather}$$
$$H \mathrel{+}= \frac{\Delta H_k}{100}\cdot 60°\,w_k,\qquad S \mathrel{+}= \frac{\Delta S_k}{100}\,w_k,\qquad L \mathrel{+}= \frac{\Delta L_k}{100}\,w_k$$

The bands tile the circle (red 0–45°, orange 45–90°, … magenta 315–360°), so the weights sum to 1. Pixels below min-saturation can be skipped entirely.

Relation to lb:hue-saturation

lb:hue-saturation is the classic editor's dialog: a master control plus six hue ranges, relative offsets, HSL arithmetic. This one is the RAW editor's mixer: eight bands, all three components per band. Same idea, different layout and different numbers — pick the one whose panel you are used to.

Just this one

Windows module hsl-seven.dll, drop it into %LOCALAPPDATA%\gegl-0.4\plug-ins; Linux module hsl-seven.so, drop it into ~/.local/share/gegl-0.4/plug-ins, then restart GIMP. Every module here is a standalone GEGL module: it links only against the GEGL and babl that ship with GIMP, never against another module of this project, so one download is all it needs. The full bundle is on the download page.
