Apply Image

lb:apply-image 混合与通道 双输入

PS 应用图像：把 aux 输入当成源，按混合模式、不透明度与遮罩压到主输入上，可选只作用于某一个通道

lb:apply-image · 菜单 颜色 → SuperMrWang → Blend → Apply Image · 双输入（input + aux）

对应 Photoshop 的 图像 → 应用图像：把一张图（另一个图层 / 另一个文件）当作源， 按混合模式、不透明度、遮罩压到当前图层上，还可以只作用于某一个通道。

Replicates Photoshop's Image → Apply Image: takes a second image as the source, blends it onto the current layer with a blend mode, opacity and mask, optionally into a single channel.

PS 的遮罩可以指向第三张图（既不是目标也不是源），GEGL 的 composer 只有 两个输入，所以这里限定在「本层」或「源层」二选一——实际用法里这两处覆盖了 绝大多数场合。

行为细节 / Behaviour notes

  • aux 没接时源退化为本图，可以用来做「同图内通道互混」； Without an aux connected the source falls back to the input itself.
  • 源层的透明像素（alpha = 0）不参与作用：源层是抠图、文字层或带透明背景 的图层时，透明区的 RGB 是 0，照常混合会把目标乘成黑色。alpha 同时当作覆盖率， 半透明的柔边会渐隐而不是留硬边。 Transparent source pixels take no part: on a cut-out or text layer the holes hold RGB 0, which would blacken the target under multiply. The alpha doubles as coverage, so soft mattes fade instead of leaving a hard edge.
  • 目标是单通道时只改那一个通道，其余原样保留；源是合成时取亮度作标量。 With a single-channel target only that channel changes; a composite source is reduced to luminance.
  • 深色 / 浅色（Darker / Lighter Color）比较整像素亮度后取其中一方全部通道， 不是逐通道取最小/最大——这一点和「变暗 / 变亮」不同。
  • 在 8bit sRGB 伽马域计算，与 PS 的混合模式定义同域；结果会裁到 0..1。
  • GIMP 里这类带 aux 的滤镜目前只能合并应用，不能保存成非破坏性 fx。

源图层的尺寸与位置 / Source layer size and position

PS 的应用图像要求两个图层像素尺寸完全一致，尺寸不同时源图层直接灰掉； GIMP 里图层可以比画布小、也可以带偏移，所以这里得自己定规则：

  • 算子按 aux 缓冲区自己的 extent（即源图层的大小和位置）做粗筛，没盖到 的像素原样输出；
  • 盖到的范围内，再由源像素的 alpha 决定真正有没有像素：alpha = 0 的地方 原样输出，alpha 介于 0 和 1 之间按覆盖率减弱。只有「既属于源层、又有像素」 的地方才被改动，这才是 PS 意义上「只有相交部分起作用」。

早先版本用的是 GeglOperationPointComposer，process 只拿到一段裸指针， 看不到 aux 的 extent，界外被 GEGL 补成透明黑再参与混合：正片叠底会把外侧涂 黑，正常模式会把外侧擦成透明。改成 GeglOperationComposer 后 process 拿到 的是真正的 GeglBuffer，gegl_buffer_get_extent(aux) 就能取到图层尺寸， tools/auxrun 也补了 aux-x / aux-y 用来模拟带偏移的源层。

extent 只能说明「这块地方属于源层」，说明不了「这块地方有像素」——抠图的透明 洞也在 extent 里面，光看 extent 会把洞一起乘黑。所以两者要配合用。

Photoshop requires both layers to have exactly the same pixel size and greys the source out otherwise; GIMP layers may be smaller than the canvas or offset, so the rule here is two-stage: the aux buffer's own extent is the coarse filter, and the source alpha decides which pixels inside that area really carry pixels. Uncovered and transparent pixels are passed through untouched. The older point-composer version only received a raw pointer for the aux, could not see its extent, and treated the outside as transparent black — multiply blackened it, normal erased it. The extent alone is not enough: a cut-out's holes lie inside the extent, so pure extent logic would still blacken them.

PS's mask may point at a third image. A GEGL composer only exposes two inputs, so the mask is limited to either the target or the source, which covers the common cases.
