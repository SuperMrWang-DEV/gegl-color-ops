Displace

lb:displace 扭曲 双输入

按位移图重采样图像。相对 GEGL 自带的 gegl:displace，这里修掉四件事：单张图同时给水平/垂直、位移图不强制乘 alpha、位移图覆盖不到的区域原样输出而不是硬移、默认用无振铃的采样器。

lb:displace · 菜单 SuperMrWang → Distort → Displace · 双输入（input + aux）

按位移图重采样图像。GEGL 自带的 gegl:displace 能跑，但参数面被写死在几处地方，这个算子把它们逐个打开。

为什么不用 gegl:displace

gegl:displace 每像素算的是 2 × amount × (Y′ − 0.5) × alpha，aux 的格式是 Y'A float。这一行决定了它的全部性格：

项gegl:displacelb:displace
位移图读法只取亮度 Y′；水平、垂直各要一张图矢量场取 R→X、G→Y，一张图同时给两轴；也可切单通道模式
alpha强制相乘，位移图透明处位移静默归零默认不乘，alpha-weight 显式打开
中性值固定 0.5，不可改midpoint 可调，另有 black-point / white-point 做动态范围压缩与超量位移
单位像素像素 或 长边百分比（换分辨率不用重调）
越界clamp / loop / black / white同上，另加 transparent
重采样默认 bicubic，高对比边缘会振铃出白边默认 nohalo，可换 bilinear / cubic / lohalo
位移图未覆盖区读出 0 → 整块被硬移 −amount原样输出
输出尺寸跟随主图跟随主图（显式覆盖 bbox，位移图偏移不会撑大画布）

前两条最要命：拿一张带透明背景的图层当位移图，gegl:displace 会在透明处不报错地取消位移；想同时控制 X 和 Y 又得准备两张对齐的灰度图。这里一张 RGBA 就够。

参数 / Parameters

参数默认说明
amount-x0水平位移量，对应位移图白场处
amount-y0垂直位移量，对应位移图白场处
unitsPixelsPixels 固定像素；Percent of long edge 按主图长边百分比
map-modeVectorVector 取 R→X、G→Y；Single channel 取一个通道同时喂两轴
map-channelLuminance单通道模式读哪个通道（亮度 / R / G / B / A）
black-point0位移图取这个值时是 −1 倍位移
midpoint0.5位移图取这个值时不动。灰图用 0.5，零中性矢量场用 0
white-point1位移图取这个值时是 +1 倍位移
alpha-weight否位移量乘以位移图的 alpha（复刻 gegl:displace 的行为）
abyssWrap around采到图外时：环绕 / 重复边缘 / 透明 / 黑 / 白
resamplingNohalo最近邻 / 双线性 / 双三次 / Nohalo / Lohalo

black-point、midpoint、white-point 三个一起决定映射曲线：中点两侧各自线性映射到 −1 和 +1。所以 0 / 0.5 / 1 是标准灰图，−1 / 0 / 1 是零中性矢量场， 0.2 / 0.4 / 0.6 则是「只取中间一段做完整位移」，相当于先把位移图加对比度。

算法

flowchart TD
  A["aux 位移图（R/G 或单通道）"] --> B["remap：black → −1，mid → 0，white → +1"]
  B --> C["× amount-x / amount-y × 单位"]
  C --> D["源坐标 = 像素中心 + 偏移"]
  D --> E["采样 input（默认 nohalo，越界按 abyss）"]
  E --> F["写回同位置"]
  G["aux 没覆盖到这里"] --> H["原样输出"]
$$t(v)=\begin{cases}\dfrac{v-\text{mid}}{\text{white}-\text{mid}} & v\ge \text{mid}\\[4pt] \dfrac{v-\text{mid}}{\text{mid}-\text{black}} & v<\text{mid}\end{cases} \qquad \text{src}=(x+\tfrac12+t_x A_x u,\; y+\tfrac12+t_y A_y u)$$

u 是单位换算（像素时 1，百分比时长边 × 0.01）。矢量模式下 t_x=t(R)、t_y=t(G)；单通道模式下两者取同一个 t，方向由 amount-x 与 amount-y 的比值决定。

用法 / Recipes

  • 水波、热浪：gegl:perlin-noise 当位移图，midpoint=0（噪声以 0 为中心）、 amount 10–30 px，resampling=nohalo。
  • 无缝贴图的接缝：位移图也要是无缝的，abyss=Wrap around，否则拉伸后接缝会 出现在另一个位置。
  • 镜头桶形逆映射：用 gegl:lens-distortion 的反向参数生成一张坐标场，切 map-mode=Single channel 只能处理同心圆，真正要按半径算还是得用矢量图。
  • 文字磨损 / 涂抹：amount 大（>50 px）时把 resampling 提到 Lohalo， 并在位移图上先做一次轻微高斯模糊——硬边的位移图会把边缘采样成锯齿。

与 gegl:displace 的迁移

把原来的「两张灰度图」换成「一张 RGBA」：R 放水平图、G 放垂直图，两个都按 0 / 0.5 / 1 保持中灰不动。如果只有一张灰度图，切 map-mode=Single channel、 map-channel=Luminance，amount-x 与 amount-y 分别填原来的两个比例即可。

测试 / Testing

python tools/check_displace.py -v

11 项逐像素断言：零位移恒等、黑白满量位移、环绕与夹边的区别、矢量场 XY 独立、单通道模式、百分比单位、白场外推、透明位移图默认仍然生效、勾上 alpha-weight 后透明区不动、位移图只盖半个画面时未覆盖区原样。

只要这一个

Windows 模块 displace.dll，放进 %LOCALAPPDATA%\gegl-0.4\plug-ins；Linux 模块 displace.so，放进 ~/.local/share/gegl-0.4/plug-ins，然后重启 GIMP。这里的每个模块都是独立的 GEGL 模块，只链接 GIMP 自带的 GEGL 与 babl，不依赖本项目里的其它模块——下这一个就够用，不会缺东西。要一次装齐，用整包。

Displace

lb:displace Distort two inputs

Resample the image through a displacement map: one RGBA map drives both axes, five edge policies, and a sampler that does not ring by default.

lb:displace · menu SuperMrWang → Distort → Displace · two inputs (input + aux)

Resamples the image through a displacement map. GEGL's own gegl:displace works, but several of its knobs are welded shut; this one opens them.

Why not gegl:displace

gegl:displace computes 2 × amount × (Y′ − 0.5) × alpha per pixel, with the map read as Y'A float. That single line defines its whole character:

gegl:displacelb:displace
Map is read asluminance Y′ only; one image per axisvector field R→X, G→Y, one image for both axes; single channel mode too
alphaalways multiplied, so a transparent part of the map silently cancels the displacementnot multiplied by default; alpha-weight turns it on explicitly
Rest valuepinned at 0.5midpoint is adjustable, plus black-point / white-point for range compression and over-range shifts
Unitpixelspixels or percent of the long edge, so resizing the image does not invalidate the amount
Out of boundsclamp / loop / black / whitesame, plus transparent
Resamplingbicubic by default, which rings into white halos on hard edgesnohalo by default, switchable to bilinear / cubic / lohalo
Where the map does not reachreads zero and hard-shifts the area by −amountpasses through untouched
Output sizefollows the inputfollows the input (bounding box overridden, so an offset map cannot grow the canvas)

The first two matter most: with a layer that has transparency as the map, gegl:displace cancels the displacement there without a word, and driving both axes needs two perfectly aligned greyscale images. One RGBA map does both here.

Parameters

ParameterDefaultNotes
amount-x0Horizontal displacement at the map's white point
amount-y0Vertical displacement at the map's white point
unitsPixelsPixels stays fixed; Percent of long edge scales with the image
map-modeVectorVector reads R→X and G→Y; Single channel feeds one channel to both axes
map-channelLuminanceWhich channel single channel mode reads (luminance / R / G / B / A)
black-point0Map value meaning −1 × the amount
midpoint0.5Map value meaning no displacement. Grey maps use 0.5, zero-centred vector fields use 0
white-point1Map value meaning +1 × the amount
alpha-weightnoMultiply the displacement by the map's alpha (reproduces gegl:displace)
abyssWrap aroundSampling outside the image: wrap / repeat edge / transparent / black / white
resamplingNohalonearest / bilinear / bicubic / nohalo / lohalo

The three mapping points put −1 at black, 0 at the midpoint and +1 at white, each side scaled independently. 0 / 0.5 / 1 is a plain grey map, −1 / 0 / 1 is a zero-centred vector field, and 0.2 / 0.4 / 0.6 stretches a narrow band of the map into the full range.

Algorithm

flowchart TD
  A["aux map (R/G or one channel)"] --> B["remap: black → −1, mid → 0, white → +1"]
  B --> C["× amount-x / amount-y × unit"]
  C --> D["source = pixel centre + offset"]
  D --> E["sample input (nohalo by default, abyss policy for outside)"]
  E --> F["write back to the same pixel"]
  G["map does not cover this area"] --> H["pass through"]
$$t(v)=\begin{cases}\dfrac{v-\text{mid}}{\text{white}-\text{mid}} & v\ge \text{mid}\\[4pt] \dfrac{v-\text{mid}}{\text{mid}-\text{black}} & v<\text{mid}\end{cases} \qquad \text{src}=(x+\tfrac12+t_x A_x u,\; y+\tfrac12+t_y A_y u)$$

u is the unit factor (1 for pixels, long edge × 0.01 for percent). Vector mode uses t(R) and t(G); single channel mode feeds one t to both axes, so the ratio of the two amounts picks the direction.

Recipes

  • Water ripples, heat haze: use gegl:perlin-noise as the map with midpoint=0 (the noise is centred on zero), amounts of 10–30 px, resampling=nohalo.
  • Seamless tiles: the map has to be seamless too, and use abyss=Wrap around; otherwise the seam simply moves somewhere else.
  • Inverse lens distortion: generate a coordinate field from the reverse of gegl:lens-distortion. Single channel mode only handles concentric cases; anything radial really needs the vector map.
  • Worn type, smearing: with amounts above ~50 px raise resampling to Lohalo and blur the map slightly first — a hard-edged map samples into stair steps.

Migrating from gegl:displace

Move the two greyscale maps into one RGBA map: R takes the horizontal map, G the vertical one, both still resting at mid grey. With a single grey map, switch to single channel mode and put the two old ratios into the two amounts.

Testing

python tools/check_displace.py -v

Eleven per-pixel assertions: identity at zero amount, full-scale shifts in both directions, wrap versus clamp, X and Y independent in a vector field, single channel mode, percent units, over-range white point, a transparent map still shifting by default, alpha-weight freezing the transparent part, and a map that only covers half the canvas leaving the rest untouched.
