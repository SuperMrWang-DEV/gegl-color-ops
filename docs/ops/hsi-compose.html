HSI Compose

lb:hsi-compose 分量 整块区域

HSI 分量曲线工作流的合成器：把「R = 饱和度、G = 强度、B = 色相/360」的数据图还原成真实颜色

lb:hsi-dual 的逆运算：把「R = 饱和度、G = 强度、B = 色相/360」的数据图还原成真实颜色。alpha 被忽略，输出恒不透明。

(R=S, G=I, B=H/360) ──lb:hsi-compose──> sRGB

它是怎么算的

逆变换用 HSI 的余弦式，不是 HSV 的线性扇区：

H  < 120°   B = I(1−S)、R = I[1 + S·cosH / cos(60−H)]、G = 3I − R − B
H  < 240°   轮转 120°，R 取低值
其余        轮转 240°，G 取低值

用 HSV 的扇区公式会在 S 高、I 低时偏几十码——两者在等亮度平面上不是同一组基。这段代码在 common/color-levels.h（lb_cl_hsi_to_rgb），与 lb:hsi-levels 共用。

输入输出

格式含义
inputR'G'B'A float数值是数据：lb:hsi-dual 的输出
outputR'G'B'A floatsRGB 编码值，已裁到 [0,1]

S、I 在转换里会被夹到 [0,1]，色相走 wrap360，RGB 输出裁到 [0,1]——HSI 的色域是六边形棱锥，S/I 拉到极端时出界只能裁。

注意

  • 「R 是饱和度、G 是强度、B 是色相」是硬约定：挂到照片上会把像素当 HSI 数据 解释，结果出错但不报错。
  • 把它和 lb:hsi-levels 区分开：那个是按色阶参数逐分量做 1D 映射，这个是给 「曲线工作流」用的合成器。

只要这一个

Windows 模块 hsi-compose.dll，放进 %LOCALAPPDATA%\gegl-0.4\plug-ins；Linux 模块 hsi-compose.so，放进 ~/.local/share/gegl-0.4/plug-ins，然后重启 GIMP。这里的每个模块都是独立的 GEGL 模块，只链接 GIMP 自带的 GEGL 与 babl，不依赖本项目里的其它模块——下这一个就够用，不会缺东西。要一次装齐，用整包。

HSI Compose

lb:hsi-compose Component area

The inverse of HSI Triple Extract, using HSI's cosine inverse rather than HSV's linear sectors — the two are not the same basis on the constant-luminance plane.

Menu: Colors → SuperMrWang → Component → HSI Compose (a filter op)

Overview

The inverse of lb:hsi-dual: turns the R = saturation, G = intensity, B = hue/360 data image back into real colour. Alpha is ignored; the output is always opaque.

(R=S, G=I, B=H/360) ──lb:hsi-compose──> sRGB

How it computes

The inverse transform uses HSI's cosine form, not HSV's linear sectors:

H  < 120°   B = I(1−S),  R = I[1 + S·cosH / cos(60−H)],  G = 3I − R − B
H  < 240°   rotate by 120°, R takes the low value
otherwise   rotate by 240°, G takes the low value

Using HSV's sector formula instead is off by tens of codes at high S and low I — the two are not the same basis on the constant-luminance plane. The code lives in common/color-levels.h (lb_cl_hsi_to_rgb) and is shared with lb:hsi-levels.

Input and output

FormatMeaning
inputR'G'B'A floatthe numbers are data: the output of lb:hsi-dual
outputR'G'B'A floatsRGB encoded values, clipped to [0,1]

S and I are clamped to [0,1] inside the transform, hue wraps with wrap360, and the RGB output is clipped to [0,1] — HSI's gamut is a hexagonal pyramid, so out-of-gamut results at extreme S/I can only be clipped.

Notes

  • "R is saturation, G is intensity, B is hue" is a hard convention: pointed at a photo it interprets pixels as HSI data — wrong output, no error.
  • Do not confuse it with lb:hsi-levels: that one applies per-component 1D levels mappings, this one is the composer for the curve workflow.

Just this one

Windows module hsi-compose.dll, drop it into %LOCALAPPDATA%\gegl-0.4\plug-ins; Linux module hsi-compose.so, drop it into ~/.local/share/gegl-0.4/plug-ins, then restart GIMP. Every module here is a standalone GEGL module: it links only against the GEGL and babl that ship with GIMP, never against another module of this project, so one download is all it needs. The full bundle is on the download page.
