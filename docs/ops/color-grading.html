Color Grading

lb:color-grading 色彩 逐像素

等价 经典 RAW 编辑器的「颜色分级」：阴影 / 中间调 / 高光 / 全局四个轮盘（色相 + 饱和度）加各自的明度滑杆，按亮度分带给画面上色。

2026-11-12 新增。复刻 classic RAW editors 的 Color Grading（颜色分级）面板：阴影 / 中间调 / 高光 / 全局四个轮盘 （色相 + 饱和度），各带独立的明度滑杆，外加 Blending 与 Balance。

菜单位置

Colors → SuperMrWang → Color → Color Grading

参数（14 项，与 RAW 编辑器 面板一一对应）

参数范围默认说明
Global Hue / Saturation / Luminance0–360 / 0–100 / −100–1000 / 0 / 0全局轮盘，整幅画面均匀生效
Shadows Hue / Saturation / Luminance同上0 / 0 / 0阴影轮盘
Midtones Hue / Saturation / Luminance同上0 / 0 / 0中间调轮盘
Highlights Hue / Saturation / Luminance同上0 / 0 / 0高光轮盘
Blending0–10050相邻亮度带的交叉淡化宽度（0 = 硬分界）
Balance−100–1000平移阴影/高光的势力范围（正 = 偏高光）

算法模型

按像素的 Rec.709 亮度（伽马域）分带：

  • 分界默认：阴影/中间调 0.3，中间调/高光 0.7；
  • Blending 把两条硬边界铺成 smoothstep 过渡（100 → 各 ±0.25）， 中间调权重 = 1 − 阴影 − 高光；
  • Balance ±100 把两条分界一起平移 ±0.25。
$$h = 0.25\cdot\frac{\text{Blending}}{100},\qquad e_{\text{sh}} = 0.3 + 0.25\cdot\frac{B}{100},\qquad e_{\text{hi}} = 0.7 + 0.25\cdot\frac{B}{100}$$
$$w_{\text{sh}} = 1-\operatorname{smooth}\!\left(\frac{Y-e_{\text{sh}}}{2h}+\frac{1}{2}\right),\qquad w_{\text{hi}} = \operatorname{smooth}\!\left(\frac{Y-e_{\text{hi}}}{2h}+\frac{1}{2}\right),\qquad w_{\text{mid}} = 1-w_{\text{sh}}-w_{\text{hi}}$$

每个轮盘的一次染色（乘以带权重 w）：

  • 明度：V += Lw × 0.005 × w（与 lb:hsl-bands 同系数）；
  • 染色强度 t = Sat/100 × w：往同明度的轮盘纯色混合， rgb = rgb·(1−t) + tint·t，tint = HSV(轮盘色相, 1, V)。 灰像素自然吃到染色；与轮盘色接近互补的色相则被去饱和（掺灰）， 不在色相上做插值，所以没有「旋转方向翻转」的接缝。
$$V \leftarrow V + 0.005\,L_w\,w,\qquad t = \frac{\text{Sat}}{100}\,w,\qquad \text{rgb} \leftarrow \text{rgb}\,(1-t) + \text{tint}\,t,\qquad \text{tint} = \operatorname{HSV}(h_w,\,1,\,V)$$

2026-11-12 修正：初版用「色相向轮盘色相收敛」的模型，在互补色相 （色相差 ≈ 180°）处 roundf 的旋转方向会翻转，裁切高光上会爆出 竖条纹（在 night-blue 演示图里可见）。已改为向轮盘色混合， check_color_grading.py 新增「互补色相无接缝」检测（相邻列跳变 1.2 码，阈值 8）。

执行顺序：全局轮盘（权重 1）先做，三个带再做。

标定状态（诚实声明）

本机经典图像编辑器2025 未装 RAW 编辑器 插件，无法像 colorize / color-mask-select 那样逐码标定。分界 0.3/0.7、过渡 ±0.25、Rec.709 亮度等均为按 RAW 编辑器 公开 行为设定的合理模型，不是黑盒实测值。结构、参数语义与 RAW 编辑器 面板 一一对应；数值行为由 tools/check_color_grading.py 按设计模型验证。

验证

python tools/check_color_grading.py    # 行为验证 12 项（恒等 / 分带 / 落位 / Blending / Balance / 全局 / 无接缝）
python tools/smoke.sh                  # 全算子冒烟

已知限制

  • 轮盘没有独立的「范围」滑杆（RAW 编辑器 悬停轮盘可调亮度范围端点）； 分界固定 0.3/0.7，只能用 Blending/Balance 调整过渡与偏移。
  • 亮度分带用的是像素自身亮度（Rec.709 伽马域），不是邻域亮度； 要「按邻域」的效果请用 lb:shadows-highlights。

只要这一个

Windows 模块 color-grading.dll，放进 %LOCALAPPDATA%\gegl-0.4\plug-ins；Linux 模块 color-grading.so，放进 ~/.local/share/gegl-0.4/plug-ins，然后重启 GIMP。这里的每个模块都是独立的 GEGL 模块，只链接 GIMP 自带的 GEGL 与 babl，不依赖本项目里的其它模块——下这一个就够用，不会缺东西。要一次装齐，用整包。

Color Grading

lb:color-grading Color per-pixel

The RAW editor's Color Grading panel — shadow, midtone, highlight and global wheels with per-band luminance, plus Blending and Balance.

Added 2026-11-12. Reproduces the Color Grading panel of the RAW editor / the classic RAW editor: shadow, midtone, highlight and global wheels (hue + saturation), each with its own luminance slider, plus Blending and Balance.

Menu

Colors → SuperMrWang → Color → Color Grading

Parameters (14, one for one with the the RAW editor panel)

ParameterRangeDefaultNotes
Global Hue / Saturation / Luminance0–360 / 0–100 / −100–1000 / 0 / 0Global wheel, acts evenly over the whole frame
Shadows Hue / Saturation / Luminancesame0 / 0 / 0Shadow wheel
Midtones Hue / Saturation / Luminancesame0 / 0 / 0Midtone wheel
Highlights Hue / Saturation / Luminancesame0 / 0 / 0Highlight wheel
Blending0–10050Cross-fade width between neighbouring tonal bands (0 = hard split)
Balance−100–1000Shifts the shadow/highlight reach (positive = toward highlights)

Model

Bands are chosen from the pixel's own Rec.709 luminance (gamma domain):

  • default splits: shadow/midtone 0.3, midtone/highlight 0.7;
  • Blending spreads both hard boundaries into smoothstep transitions (100 → ±0.25 each), and the midtone weight is 1 − shadow − highlight;
  • Balance ±100 shifts both boundaries by ±0.25.
$$h = 0.25\cdot\frac{\text{Blending}}{100},\qquad e_{\text{sh}} = 0.3 + 0.25\cdot\frac{B}{100},\qquad e_{\text{hi}} = 0.7 + 0.25\cdot\frac{B}{100}$$
$$w_{\text{sh}} = 1-\operatorname{smooth}\!\left(\frac{Y-e_{\text{sh}}}{2h}+\frac{1}{2}\right),\qquad w_{\text{hi}} = \operatorname{smooth}\!\left(\frac{Y-e_{\text{hi}}}{2h}+\frac{1}{2}\right),\qquad w_{\text{mid}} = 1-w_{\text{sh}}-w_{\text{hi}}$$

One pass of a wheel (multiplied by the band weight w):

  • luminance: V += Lw × 0.005 × w (same coefficient as lb:hsl-bands);
  • tint strength t = Sat/100 × w: blend toward the wheel colour at the same luminance, rgb = rgb·(1−t) + tint·t with tint = HSV(wheel hue, 1, V). Grey pixels pick up the tint naturally; a hue close to the wheel's complement is desaturated (mixed with grey). Hue is never interpolated, so there is no seam where the rotation direction flips.
$$V \leftarrow V + 0.005\,L_w\,w,\qquad t = \frac{\text{Sat}}{100}\,w,\qquad \text{rgb} \leftarrow \text{rgb}\,(1-t) + \text{tint}\,t,\qquad \text{tint} = \operatorname{HSV}(h_w,\,1,\,V)$$

Fixed 2026-11-12: the first version used "converge the hue toward the wheel hue", which flipped roundf's rotation direction at complementary hues (≈180° apart) and produced vertical banding on clipped highlights (visible in the night-blue demo image). It now blends toward the wheel colour, and check_color_grading.py gained a "no seam at complementary hues" test (jump of 1.2 code values between adjacent columns, threshold 8).

Order of execution: the global wheel (weight 1) first, then the three bands.

Calibration status (honest disclosure)

the classic editor 2025 on this machine has no the RAW editor plug-in installed, so this operator could not be calibrated code by code the way colorize and color-mask-select were. The 0.3/0.7 splits, the ±0.25 transitions and the Rec.709 luminance are a reasonable model built from the RAW editor's documented behaviour, not black-box measurements. The structure and parameter semantics map one for one onto the the RAW editor panel; numeric behaviour is checked against that design model by tools/check_color_grading.py.

Verification

python tools/check_color_grading.py    # 12 behavioural checks (identity / bands / placement /
                                       # Blending / Balance / global / no seam)
python tools/smoke.sh                  # smoke test for every operator

Known limitations

  • The wheels have no separate "range" slider (hovering a wheel in the RAW editor lets you move the luminance endpoints); the splits are fixed at 0.3/0.7 and only Blending/Balance adjust the transition and the offset.
  • Banding uses the pixel's own luminance (Rec.709, gamma domain), not a neighbourhood luminance; for neighbourhood behaviour use lb:shadows-highlights.

Just this one

Windows module color-grading.dll, drop it into %LOCALAPPDATA%\gegl-0.4\plug-ins; Linux module color-grading.so, drop it into ~/.local/share/gegl-0.4/plug-ins, then restart GIMP. Every module here is a standalone GEGL module: it links only against the GEGL and babl that ship with GIMP, never against another module of this project, so one download is all it needs. The full bundle is on the download page.
