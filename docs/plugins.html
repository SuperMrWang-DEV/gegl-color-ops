图层 → 选区 / 通道，一键

配套的 GIMP 3 Python 插件（layer-to-mask）：右键点哪个图层，就把哪个 图层转成选区或 Alpha 通道——算子跑完留下的那张灰度图，一步就能接着用。

为什么需要它

这套 GEGL 算子（计算、色彩范围、通道区间到 alpha……）的产出常常是一张灰度图： 它本身就是一张蒙版。原生流程要把它变成能用的东西得四步——复制图层 → 新建通道 → 粘贴 → 蒙版转选区；这两个动作把它压成一次右键，而且不要求图层是「纯灰度」。

Layer to Selection

把点击的图层变成当前选区：

  • 通道：Gray（亮度）/ R / G / B / Alpha 任选——彩色图层选 Gray 时按亮度算， 不是 HSL 明度（纯红 ≈ 54/255，而不是 130）；
  • 组合方式：替换 / 加 / 减 / 交，与 GIMP 选区菜单一致；
  • 可反相（选暗部而不是亮部）；
  • 图层比画布小、带偏移也没问题：只在自己位置生效，界外不选中。

Layer to Channel

把点击的图层变成一条新的 Alpha 通道。恒为灰度：

  • 彩色图层先按亮度转成灰度，黑白图层原样——然后把这些灰度值写进通道 （黑 = 不选中、白 = 完全选中、中间灰 = 部分选中）；
  • 没有「取 R 通道」这类选项——要的就是明暗，不给单色通道捣乱的机会；
  • 可反相、可自定义通道名（默认沿用图层名）；建好后状态栏会提示通道名；
  • 想把它变回选区：在「通道」面板右键该通道 → 通道到选区（GIMP 原生）。

入口与安装

两个动作都挂在两处：图层右键 → SuperMrWang → Layer to Selection / Layer to Channel，以及 选择 → SuperMrWang 下（不用鼠标右键、或想写脚本时用这处）。

git clone https://github.com/SuperMrWang-DEV/gegl-color-ops.git
cd gegl-color-ops
bash install-plugin.sh   # 把 plugin/ 下的 .py 拷进 GIMP 的 plug-ins 目录

然后完全重启 GIMP。脚本能直接调 PDB 过程 lb-plugin-layer-to-selection / lb-plugin-layer-to-channel（后者参数 invert / name）。

实现与验证

直接读图层像素（array 的 C 级切片，100 万像素约 4 毫秒），不走复制粘贴；灰度内容 走零拷贝快路径，彩色图层才临时复制一份做去色（用完即删，并把活动图层还给原来 选中的那个）。有活动选区时写通道会先把选区挂起再恢复——GIMP 的 shadow 合并 遵守选区，不挂起的话通道会被截成选区那一块。

回归：tools/check_layer_to_mask.py，23 条断言（灰度值、反相、 偏移图层、彩色亮度、四个单通道、通道值/名字/反相、彩色转通道=亮度、 选区不被截断、四种组合方式），跑在 gimp-console 的 python-fu-eval 里。
