换天 Sky Replace一键换天

选中照片图层 + 指定一张天空图，一次点击完成：泛洪分割 → 收缩羽化 → 天空 cover 合成 → gamma 亮度匹配 → 图层蒙版。经典算法， 不需要 AI 模型，蓝天 / 晴天照片效果最好。

分割

经典算法

从图像顶边三个种子点做泛洪选择，把连通的天空选出来（GIMP 3 的采样 阈值/判据走 context，插件用 context_push/pop 包住，不污染你的设置）。 蓝天、晴天照片效果最好。

收边

选区按参数收缩/羽化：edge 正=收缩、负=扩张，默认收 1px 收掉前景光晕。顶行天空覆盖率低于 60% 时直接报错提示，而不是静默输出一张坏结果。

合成

天空图按 cover 方式缩放、居中裁切，插到照片图层正上方； 再按两张天空区的直方图均值算 gamma，把新天空亮度拉到与原天空一致 （可在对话框关掉）。

输出

选区转成天空图层的图层蒙版，前景自然露出。可勾选存一条 Sky Mask 通道：对分割不满意时，用 lb:color-mask-select 等蒙版算子手工精修，再重新生成选区合成。

参数范围 / 默认做什么
sky-file文件替换用的天空图
threshold0 – 0.5泛洪采样阈值
edge默认 1选区收缩（正值）/ 扩张（负值）像素数
feather羽化半径选区边缘羽化
match-brightness开gamma 亮度匹配，把新天空拉到原天空亮度
save-mask-channel关把分割蒙版存成 Sky Mask 通道，方便精修

效果边界：泛洪只认颜色连通，不认语义。云层破碎、天空被树枝 零碎切割、或前景顶边与天空颜色接近的照片，分割质量会下降——这类图建议勾上 「存 Sky Mask 通道」，用蒙版算子精修后再合成。

蒙版 Layer to Selection / Channel一键转选区 / 通道

这套 GEGL 算子（计算、色彩范围、通道区间到 alpha……）的产出 常常是一张灰度图——它本身就是一张蒙版。原生流程要把它变成能用的东西得四步 （复制图层 → 新建通道 → 粘贴 → 蒙版转选区），这两个动作把它压成一次右键， 而且不要求图层是「纯灰度」。

Layer to Selection

转选区

把点击的图层变成当前选区：

  • 通道：Gray（亮度）/ R / G / B / Alpha 任选；
  • 组合方式：替换 / 加 / 减 / 交，与 GIMP 选区菜单一致；
  • 可反相（选暗部而不是亮部）；
  • 图层比画布小、带偏移也没问题：只在自己位置生效，界外不选中。

Layer to Channel

转通道

把点击的图层变成一条新的 Alpha 通道，恒为灰度：

  • 彩色图层先按亮度转灰度、黑白图层原样，再把这些灰度值写进通道 （黑 = 不选中、白 = 完全选中、中间灰 = 部分选中）；
  • 没有「取 R 通道」这类选项——要的就是明暗，不给单色通道捣乱的机会；
  • 可反相、可自定义通道名（默认沿用图层名），建好后状态栏提示通道名；
  • 想变回选区：通道面板右键该通道 → 通道到选区（GIMP 原生）。

彩色图层的 Gray 是亮度，不是 HSL 明度：纯红 ≈ 54/255， 而不是 HSL 明度的 130——和你在 PS 里按亮度去色的结果一致。 实现上走临时副本去色（GIMP 3.2 的 LUMA 模式），用完即删，活动图层还原。

与 plugin/gray-mask 的分工：gray-mask 走复制/粘贴，会带上 图层蒙版等显示效果；layer-to-mask 读原始像素、更快、支持任意通道。 日常「灰度图 → 蒙版」优先用它。有活动选区时写通道会先把选区挂起再恢复—— GIMP 的 shadow 合并遵守选区，不挂起的话通道会被截成选区那一块。

三步装上

  1. 拿代码

    git clone https://github.com/SuperMrWang-DEV/gegl-color-ops.git
cd gegl-color-ops

  2. 拷进 GIMP 插件目录

    一条脚本把 plugin/ 下的 .py 全部拷进 GIMP 的 plug-ins 目录（Windows / Linux 通用）：

    bash install-plugin.sh

  3. 重启 GIMP，找菜单

    Sky Replace：图层 → SuperMrWang → Sky Replace； Layer to Selection / Channel：图层右键 → SuperMrWang， 另有一份挂在 选择 → SuperMrWang 下（不依赖右键、方便写脚本）。

脚本调用

三个动作都是标准 PDB 过程，脚本里直接调（第二个参数列表可留空走默认值）：

PDB 过程参数用途
lb-plugin-sky-replace sky-file / threshold / edge / feather / match-brightness / save-mask-channel 批处理换天
lb-plugin-layer-to-selection channel / invert / 组合方式 图层 → 选区
lb-plugin-layer-to-channel invert / name 图层 → 灰度 Alpha 通道

实现：直接读图层像素（array 的 C 级切片，100 万像素约 4 毫秒）， 不走复制粘贴；灰度内容走零拷贝快路径，彩色图层才临时复制一份做去色。 图层组没有自己的像素，会明确报错提示先合并组。

回归

两套断言跑在 gimp-console 的 python-fu-eval 里： tools/check_sky_replace.py（13 条：分层、蒙版、合成像素、亮度匹配、 开关行为、报错路径；直方图期望值按 255·enc_srgb(v) 刻度换算）与 tools/check_layer_to_mask.py（23 条：灰度值、反相、偏移图层、 彩色亮度、四个单通道、通道值/名字/反相、彩色转通道=亮度、选区不被截断、 四种组合方式）。
