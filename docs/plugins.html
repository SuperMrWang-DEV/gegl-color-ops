十个 Python 插件

免编译的 GIMP 3 插件，装进 plug-ins 目录、重启即用。 两处入口：图层右键 → SuperMrWang（十个都在）与 颜色 → SuperMrWang；分量曲线与三个磨皮收在 Shortcut 子菜单里。 点方块进去看结构、原理、实测误差与下载。

选区layer-to-selection

Layer to Selection

右键任意图层，把它转成当前选区：Gray / R / G / B / Alpha，四种组合方式，可反相。

打开 →
通道layer-to-channel

Layer to Channel

右键任意图层，把它变成一条灰度 Alpha 通道，可反相、可自定义名。

打开 →
曲线hsv-split-curves

HSV Split (Curves)

拆成 H / S / V 三张分量层，每层一条原生曲线，恒等还原。

打开 →
曲线lch-split-curves

LCh Split (Curves)

同上，换成 CIE LCh 明度 / 彩度 / 色相，感知均匀。

打开 →
曲线hsl-split-curves

HSL Split (Curves)

GIMP 没有 HSL 分量模式，这个插件精确换算，不拿 HSV 近似。

打开 →
曲线lab-split-curves

Lab Split (Curves)

a 与 b 合一层、L* 一层，调 a 只动 a、调 b 只动 b。

打开 →
曲线hsi-split-curves

HSI Split (Curves)

I 借不到任何分量模式，三个分量合进一层、三条曲线各管一个。

打开 →
磨皮frequency-separation

高低频磨皮

低频管影调、高频管细节，叠起来就是原图；半径决定分界。

打开 →
磨皮dodge-burn

双曲线磨皮

提亮 / 压暗两条曲线压在黑蒙版下：涂到哪里动哪里。

打开 →
磨皮neutral-grey

中性灰磨皮

一层 50% 灰、柔光下恒等；白笔提亮、黑笔压暗、灰盖回去。

打开 →

每个插件页里各有一个 .zip（只有一个 .py 和一份安装说明）；一次装全部就跑 bash install-plugin.sh， 细节见 安装指南。
