# lb:mesh-warp · 自由变形（非破坏）

`plugin/mesh-warp` 的 C 版：FFD + 双三次 Bezier 面片，挂成**图层上的实时滤镜**。
网格串存在滤镜上，像素不动，重跑对话框会读回来接着拖。

```
图层 ──▶ ┌──────────────────────────┐ ──▶ 画布
         │ lb:mesh-warp（滤镜栈里） │      网格串 = 唯一属性
         └──────────────────────────┘
```

> 菜单：`SuperMrWang → Distort → Mesh Warp (live)…`。
> 破坏性那版是 Python 的「自由变形（网格 + 把手）」，两者并存。

## 属性

只有一个 `mesh` 字符串：

```
cols,rows; x,y,ux,uy,vx,vy[,auto]; …        # 默认 U 分割线
u:0,1,2,3                                   # 自己加过线时才写
v:0,1,2
```

`x,y` 是交点位置，`ux,uy` / `vx,vy` 是两个方向的切向（每参数单位），
`auto=1` 表示把手按邻居自动重算并限幅。格式与
`plugin/_shared/mesh_warp.py` 的 `format_mesh_string` 一致，两边互读。

## 算法要点

- 每格用 16 个控制点的 Bezier 面片（PS 的网格变形同款），目标像素用 Newton
  反解 `(u,v)`，**源坐标取 uv 在原位格上的位置**——弄反了整幅图会平移一次。
- Newton 必须限步（0.75 格）并钳在 `[0,cols]×[0,rows]`，否则在格界上无限震荡。
- 反解初值按**目标画布**的 w/h 归一化；拿 mesh 自己的 w 会在预览与应用两路
  收敛到不同分支（实测差 28 px）。
- 把手要按邻居弦长自动限幅，否则片会甩过头、格子自交，画面上撕一道。
- 与 Python 版在**折点**附近 Newton 可能落到另一支：逐像素对拍 mean ≈ 0.2 级，
  十几个像素最大差 ~110 级，属已知口径差，回归按这个容差卡。

## CLI

```bash
gegl in.png -o out.png -- lb:mesh-warp mesh="3,3;10,10,60,0,0,45,1;…"
```

值里不能有空格（GEGL CLI 按空格拆参数），写错只会拿到原图、不报错。
