# CMYK Levels（lb:cmyk-levels）

菜单：`颜色 → SuperMrWang → Levels → CMYK Levels`（Filter 类）

## 概述

对 C / M / Y / K 四个印版各自做独立色阶：墨量黑场、白场、gamma、输出上下限。
想做「K 版单独压暗中间调」「只给青版加反差」这类分色调整时用它。

## 色彩空间

工作在 babl 的 `CMYKA float` 上，RGB↔CMYK 由 babl 完成，与 GIMP
「分解 → CMYK」同一套转换。

**这不是 ICC 分色。** babl 的 CMYK 带黑版生成（GCR/UCR 意义上的），实测：

| RGB | C | M | Y | K |
|---|---|---|---|---|
| 中性灰 0.5 | 0 | 0 | 0 | 78.6% |
| (0.8, 0.45, 0.2) | 0 | 71.7% | 94.5% | 39.6% |
| 纯红 | 0 | 100% | 100% | 0 |

所以 K 不是 `1−max(R,G,B)`（灰 0.5 时那是 50%，这里是 78.6%）。要按印前
特性文件（SWOP/FOGRA 等）分色，得走 ICC 流程，本算子只提供「设备无关的
babl 分色 + 分版色阶」。

```math
u = \operatorname{clamp}\!\left(\frac{x-x_{\text{lo}}}{x_{\text{hi}}-x_{\text{lo}}},\,0,\,1\right),
\qquad
\text{out} = o_{\text{lo}} + u^{1/\gamma}\,\bigl(o_{\text{hi}}-o_{\text{lo}}\bigr)
```

$o_{\text{lo}} > o_{\text{hi}}$ 时输出反相；结果夹在
$[\min(o_{\text{lo}},o_{\text{hi}}),\ \max(o_{\text{lo}},o_{\text{hi}})]$ 内。

## 规则细则

- 四个分量都是**线性 0–100% 墨量通道**：clamp → 归一化 → gamma → 输出范围。
- **K 拉满（输出 100%）→ 全黑**：K=100 时 CMY 已经无关，整幅压成黑版。
- **C/M/Y 归零 → 只剩 K 的中性图**：没有彩色墨，只剩黑版灰度。
- **色阶只映射已经算出来的墨量，不回算 GCR**：把 K 从 78.6% 拉到 90% 之后，
  CMY 不会自动减少去补总墨量（TAC）。想要「加深 K 同时减 CMY」得分别调两条
  曲线，或者改用 ICC 分色 + 曲线。
- 黑白场交叉自动交换；输出反向即墨量反相（白字变成实地）。
- **alpha ≤ 0 透传**。

## 验证

`python tools/check_color_levels.py cmyk`（3 项）：

| 用例 | 判据 | 实测 |
|---|---|---|
| 恒等（默认参数） | 与源图逐像素 ≤1 码 | 最大 0 |
| C/M/Y 归零 | 全图中性（\|R−G\|、\|G−B\| ≤2） | 0 |
| K 拉满 | 全图最亮通道 ≤12 | 0 |

恒等 0 码说明 RGB→CMYK→RGB 这条 babl 往返在默认参数下不漂；后两条验证
「某个版归零/拉满必须产生可预期的画面」——也就是说色阶确实作用在对应的
印版上，没有错位。

## 已知事项

- babl 的 CMYK 是**没有纸白与油墨特性**的简化分色，同一组 RGB 换算出的
  墨量与实际印刷无关；它适合「按版做局部调整」这类操作，不适合当作打样数值。
- CMYK 色域比 sRGB 小，来回转换会在饱和色上产生裁切（尤其纯绿/纯蓝）。
- 8 位/16 位模式下墨量量化台阶比 RGB 粗，重压 K 曲线时容易出现断层。
