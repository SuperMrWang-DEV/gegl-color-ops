# HSB Levels（lb:hsb-levels）

菜单：`颜色 → SuperMrWang → Tone → HSB Levels`（Filter 类）

## 概述

对 HSB（即 HSV，取色器上那三个数）的 H / S / B 各自做独立色阶。
和 HSL Levels 长得很像，但 **S 和 B 是另一套量**，同一个滑块值在两个算子里
手感不同，别混着用。

## 色彩空间

工作在 babl 的 `HSVA float` 上，RGB↔HSV 交给 babl。

| 分量 | 量程 | 定义 |
|---|---|---|
| H | 0–360° | 与 HSL 同一个色相角 |
| S | 0–100% | `S = (max−min)/max = 1 − min/V`（HSV 的 S） |
| B | 0–100% | `B = V = max(R,G,B)`，即最亮的那个通道 |

HSL 的 S 是 `(max−min)/(1−|2L−1|)`，HSV 的 S 是 `(max−min)/max`——同一块
颜色两边的数值可以差很多（比如纯红：HSL 的 S=100%，HSV 的 S 也是 100%，
但浅粉色 HSL 的 S=100% 时 HSV 只有约 20%）。所以「把 S 压到 60%」这两个
算子给出的画面完全不同。

## 规则细则

- **H 环形重映射**：主弧（黑场 → 白场）映到输出弧，剩余弧按比例跟进，
  两段共用 gamma；整圈连续，默认参数逐位还原。黑白场重合按整圈处理
  = 纯色相旋转。
- **S/B 线性**：clamp → 归一化 → gamma → 输出范围，输出反向即反相。
- **黑白场交叉自动交换**。
- **alpha ≤ 0 透传**。
- B 归零 = 全黑（V 是最大通道，压到 0 三通道全 0）；B 的反向输出会得到
  「亮部变暗、暗部变亮」的负片式结果，但色相与饱和度仍保留各自的映射。

## 与 lb:hsl-levels 的选择

- 只想改「颜色有多艳」而不动亮度 → 两者都行，但 HSL 的 S 与感知饱和度更
  接近，HSV 的 S 在暗部会虚高（暗红 S 也是 100%）。
- 要单独控制「最亮通道」→ 用 HSB 的 B，它等于 max，压 B 就是压高光上限。
- 要按「中间调亮度」调 → 用 HSL 的 L 或 `lab-levels` 的 L。

## 验证

`python tools/check_color_levels.py hsb`（3 项）：

| 用例 | 判据 | 实测 |
|---|---|---|
| 恒等（默认参数） | 与源图逐像素 ≤1 码 | 最大 0 |
| 饱和度归零 | 全图中性（\|R−G\|、\|G−B\| ≤2） | 0 |
| 公式对拍 | Python 复算 HSV↔RGB 与同一条色阶链路，≤2 码 | 最大 1 |

公式对拍的参数：H 整体 +40°（0/360 → 40/40 的整圈旋转）、S 15/100 → 0/100
γ=1.2、B 0/100 → 10/90，覆盖色相环绕与两段 gamma 方向。

## 已知事项

- 黑（B=0）像素的 S 与 H 都没有定义，算子按 0 处理；B 抬起来之后颜色仍是
  黑的（V 决定亮度上限）。
- 8 位精度下 B 很低的深色区只有几个量化台阶，B 曲线拉陡会出现断层。
