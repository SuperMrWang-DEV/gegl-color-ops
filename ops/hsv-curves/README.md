# HSV Curves（lb:hsv-curves）

菜单：`SuperMrWang → Curves → HSV Curves`（Filter 类）

## 概述

HSV 三个分量各自一条曲线（H 色相、S 饱和度、V 明度/值）。
和 `lb:hsb-levels` 是同一个模型。日常最常用的用法是 **S 曲线压高饱和**（把接近 1
的饱和度往下压，画面不再刺眼）和 **V 曲线提中间调**。

曲线与色阶的分工：色阶是**三点映射**（黑场、灰点、白场），曲线是**任意形状**。
需要「只提亮中间调、压住两端」或者「把某个亮度区间整段抬起来」时，三点不够用。

曲线内核在 `common/curve.h`，四个曲线算子共用：控制点解析、单调三次插值、
1024 点 LUT、采样。算子本身只负责声明 babl 格式与分量量程。

## 色彩空间

直接工作在 babl 的 `HSVA float` 上，与 `lb:hsv-dual`、`lb:hsb-levels`
同一套口径。**babl 的 HSVA 内部是 0…1**，不是 0–360 / 0–100。

| 分量 | 量程 | 说明 |
|---|---|---|
| H | 0…1 | 色相，**环形**，用偏移曲线（0.5 = 不偏） |
| S | 0…1 | 饱和度 |
| V | 0…1 | 明度（值） |

## 插值

用 **Fritsch–Carlson 单调三次 Hermite**，不是自然样条。

样条在控制点之间会过冲：画一条「先陡后平」的曲线，平台段会被顶出一个比控制点
还高的包。落在明度上是可见的灰阶断层，落在 a/b 上就是中性灰附近冒出一圈本不存在
的色光。Fritsch–Carlson 把每一对切线夹进半径 $3|d|$ 的圆里（$d$ 为割线斜率），
插值因此不会越出相邻控制点的上下界。

```math
t = \frac{3}{\sqrt{a^2+b^2}},\quad
a = \frac{m_i}{d_i},\quad b = \frac{m_{i+1}}{d_i},\quad
m_i \leftarrow t\,a\,d_i,\ m_{i+1} \leftarrow t\,b\,d_i
```

仅在 $a^2+b^2 > 9$ 时收缩。

## 参数

只有一个字符串参数 `curves`，按分量分段，段间用 `|`，段内是 `x,y` 控制点：

```
curves="H 0,0.5 1,0.5|S 0,0 0.85,0.52 1,0.7|V 0,0 1,1"
```

- 坐标一律**归一到 0…1**；物理量程的换算在算子内部完成。
- 没写到的分量保持恒等（环形分量保持零偏移）。
- 端点缺失自动补 `(0,0)` / `(1,1)`；同 `x` 只留后一个；坏 token 跳过而不是整体
  失效——这个串存在滤镜参数里，允许人手改。
- 少于两个有效点时整条退化为恒等。

## 坑

- **量程按 babl 的内部单位走**，不是属性单位。`CIE LCH(ab) float` 是物理量
  （L 0–100、C 0–132、h 0–360），而 `HSVA` / `CMYKA` 内部是 **0–1**。
  照 `color-levels.h` 的属性量程去写，色相偏移会完全不动（写回去的 18 被当成 18 个整圈）。
- **透明像素原样透传**：alpha ≤ 0 的像素不做映射。
- **曲线是 0…1 的严格映射**，不像色阶那样允许输出黑白场交叉做负片。要负片请用色阶。

## 回归

`tools/check_curves.py`：恒等、语义方向、**不过冲**、透明、解析容错，以及
C 算子与 Python 曲线实现的逐点对拍（`plugin/_shared/curve_math.py`，最大差 ≤ 2 码）。

```bash
python tools/check_curves.py
gegl in.png -o out.png -- lb:hsv-curves curves="L 0,0 0.5,0.7 1,1"
```
