# lb:puppet-warp · 木偶变形（非破坏）

把 `plugin/puppet-warp` 那套解算（MLS 相似 / MLS 仿射 / ARAP）搬进 C，做成一条
**挂在图层上的实时滤镜**：钉子串存在滤镜上，原像素一个字节都不动。

```
图层 ──▶ ┌──────────────────────────┐ ──▶ 画布
         │ lb:puppet-warp（滤镜栈里）│      钉子 / 模式 / 影响半径
         └──────────────────────────┘      都是这条滤镜的属性
```

点应用只是把 `pins` 写进滤镜 config，重算一遍；再跑一次对话框会把钉子读回来，
接着拖。存成 XCF 再打开，钉子还在，随时能改、能临时关掉。

> 菜单：`SuperMrWang → Distort → Puppet Warp (live)…`。
> 同一子菜单里还有 Python 版那个破坏性的「木偶变形」，两版并存：要能回改参数
> 用这一条，要直接烤进像素用那一条（对话框里选「覆盖当前图层」也一样）。

## 属性

| 属性 | 说明 |
| --- | --- |
| `pins` | `sx,sy,dx,dy; …`：钉子放下的位置 → 拖到的位置，图层像素坐标 |
| `mode` | `similarity`（保形）/ `affine`（放开拉伸）/ `arap`（大弯折最准） |
| `radius` | 影响半径，长边的百分比；圈外严格恒等。ARAP 不用它（全局弱锚定） |

## 为什么是 C

非破坏只认 GEGL 算子（`Gimp.DrawableFilter.new`），Python 插件只能读写像素。
MLS 是逐像素闭式解，天生 tile 安全；ARAP 在 48 节点网格上用带状 LDL 解，
分解一次、12 轮迭代复用，反向场用「钉子原位/现位互换」再解一遍——和 Python 版
同一套公式，回归逐像素对拍（`check_warp.py` / `_pw_probe.py`）。

## 两个坑

- **场要缓存，但不能直接 free。** GEGL 的 `process` 会被多线程按 tile 调，
  三态槽（FREE / RESERVED / READY）+ LRU 才安全，否则正在用的数组被别人释放。
- **CLI 传参是 `pins=值`，不是 `--pins=值`**，而且值里不能有空格（GEGL 按空格拆）。
  写错不会报错，只会拿到一张原图——对拍脚本一开始就是这么假通过的。
