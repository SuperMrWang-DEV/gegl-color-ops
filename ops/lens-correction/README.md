# Lens Correction · 镜头校正

> `lb:lens-correction` · 菜单 **SuperMrWang → Distort → 镜头校正…** · 单输入

PS「滤镜 → 镜头校正」里真正会动的三项——桶形 / 枕形畸变、暗角、横向色差——
一个算子一次重采样全解决。GIMP 自带的 `gegl:lens-distortion` 只有畸变，没有
暗角和色差；把三项分开挂三条滤镜，就得重采样三遍、画质掉三轮。

## 归一化半径：为什么是半对角线

所有半径都按**画面半对角线**归一化，四角恰好落在 `r = 1`：

```
r = |p − c| / (0.5 · √(w² + h²))
```

用短边归一化的话，同一组 k1 在 4:3 和 3:2 上看到的角落形变不一样——角落
是畸变最明显的地方，那里不一致，参数就没有可移植性。用对角的另一半同理，
只是把 1 挪到了别处。半对角线让「r = 1」和「画面四角」是同一件事。

## 畸变 / Distortion

Brown–Conrady 的径向项，只取前两阶：

```
s(r) = 1 + k1·r² + k2·r⁴
src  = c + (p − c) · s(r) · zoom
```

- `k1 > 0`：从更外面取样 → 画面**收缩** → 去桶形畸变（DxO / Lightroom 里
  「桶形」滑杆往正方向拉）。
- `k1 < 0`：画面**膨胀**，加桶形 / 鱼眼味道。
- `k2` 是 r⁴ 项，只在角落附近咬得住：k1 修不干净的「角落还差一点」，用它补。
  常见量级在 0.01–0.05，给到 ±0.5 是为了极端鱼眼。

`r → s(r)` 必须单调递增，否则同一块画面会被折回去两次，边缘出现镜像重影。
`k1 = -0.5` 已经接近边界（`s'(1) = 1 + 3k1 + 5k2 ≈ -0.5`），量程就夹在
±0.5，再大不是「更强的效果」而是碎图。

### 自动缩放 / Auto scale

`s(1) = 1 + k1 + k2` 就是角落的采样倍率。自动缩放直接除以它：

```
zoom = 1 / (1 + k1 + k2)
```

于是角落映射回角落，画面只是被压进中心一点，不会在四个角留下透明缺口。
关掉它（`auto-zoom = off`）就能看到那四个缺口——这也是为什么它默认开。
`zoom` 是在自动缩放之上再乘一个手调系数，PS 的「缩放」滑杆是同一件事。

## 暗角 / Vignette

```
t    = smoothstep(mid, mid + feather, r)
gain = 1 + vignette/100 · t
```

- 负值压暗、正值提亮，`-100` 就是角落全黑。
- `midpoint`（默认 0.55）是开始衰减的半径，`feather`（默认 0.45）是过渡宽度。
  feather 太小会看到一圈硬边同心环，这是暗角最容易做丑的地方。
- 暗角按**输出半径**算，不按畸变后的源半径：它描述的是成像面上的照度衰减，
  与几何校正无关。所以畸形调完再压暗角，位置不会跟着跑。

## 横向色差 / Lateral CA

```
r_red  = r · (1 + ca_red  / halfdiag · r²)
r_blue = r · (1 + ca_blue / halfdiag · r²)
```

- 位移按**角落处的像素**给：`ca_red = 2` 表示红通道在四角向外偏 2 px，中心
  不动（r² 让它在中心附近几乎为零）。24 MP 的机器上常见量级是 ±1–3 px。
- **绿通道不参与**。横向色差是镜头色散让三个颜色的成像尺寸略有不同，绿通常
  落在中间、也是合焦参考，修它等于把整幅往外拉。
- 红蓝一般反号：一边大一边小，紫边就是这么来的。

## 参数 / Parameters

| 参数 | 默认 | 说明 |
|---|---|---|
| `k1` | 0 | 畸变 r² 项；正 = 去桶形（画面收缩），负 = 加桶形 |
| `k2` | 0 | 畸变 r⁴ 项，只修角落残余 |
| `auto-zoom` | on | 除以 `1 + k1 + k2`，四角兜回画面 |
| `zoom` | 1.0 | 在自动缩放之上再乘的手调比例 |
| `vignette` | 0 | 暗角强度 %，负压暗、正提亮 |
| `vignette-midpoint` | 0.55 | 开始衰减的半径（四角 = 1） |
| `vignette-feather` | 0.45 | 过渡宽度 |
| `ca-red` | 0 | 红通道在角落的径向偏移（px） |
| `ca-blue` | 0 | 蓝通道在角落的径向偏移（px） |
| `abyss` | clamp | 越界：clamp / transparent / loop / black |
| `resampling` | nohalo | nearest / bilinear / cubic / nohalo / lohalo |

## 快路径

几何三项全关时不做逐像素采样：

| 情形 | 做法 | 1600×2400 实测 |
|---|---|---|
| 全默认 | `gegl_buffer_copy` 直接拷 | 0.09 s |
| 只有暗角 | 整块读入 → 乘增益 → 写回 | 0.05 s |
| 只调畸变（无 CA） | nohalo 采样一次 | 1.10 s |
| 畸变 + 色差 | 红 / 绿 / 蓝各采样一次 | 2.69 s |
| 畸变 + 色差，双线性 | 同上但线性采样 | 0.92 s |

色差让采样次数从 1 变 3，这是它贵的原因；不需要色差时别让它在栈上留一个
非零值。`768×1024` 上分别是 0.07 / 0.05 / 0.22 / 0.56 s。插件的实时预览是
缩到 560 长边再挂滤镜，一次 30 ms 上下，拖滑杆跟手。

## 和 PS 差在哪

**有**：三项一个对话框、非破坏滤镜、11 个参数全可脚本化、四档越界、五档
重采样、自动缩放、暗角 / 色差各自独立（PS 也是）。

**没有**：镜头配置文件（`.lcp` / lensfun 数据库）自动匹配——那要一份镜头
数据库和一个按 EXIF 查表的入口；几何校正（梯形 / 旋转 / 横向偏移）；用边缘
检测自动估 k1 的那个「自动」按钮。三者都不是重采样本身的问题，是「找参数」
的问题。手上有 EXIF 的人可以自己算，没有的人照 PS 的习惯拖滑杆就行。

## 回归

`tools/check_lens_correction_gimp.py`，28 项：算子能否挂成图层滤镜、参数回读、
恒等参数下逐字节不动、挂滤镜后原像素不变、k1 正负两个方向的取样半径（用
`R = 255·r` 的径向渐变当标尺，实测 135 / 122 对 135 / 123）、自动缩放兜住
四角、transparent / clamp 两档越界、暗角中心 / 中间 / 角落三点、正值提亮、
色差只挪红蓝且方向相反、极端参数不炸、240×240 全参数 0.077 s。

The test image encodes its own radius in the red channel (`R = 255·r`), so the
distortion and the CA can be read straight off the pixels instead of being
compared against a second implementation.
