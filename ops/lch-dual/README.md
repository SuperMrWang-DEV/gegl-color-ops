# lb:lch-dual · LCh 双通道提取

把一张图打包成**一张数据图**：`R = 明度 L*/100`、`G = 彩度 C*/140`、
`B = 色相/360`，全部 0…1。alpha 恒为 1。

```
原图 ──lb:lch-dual──> (R=L/100, G=C/140, B=h/360)
                          │
                 ┌────────┼────────┐
              L(红)     C(绿)    h(蓝)
                 └────────┼────────┘
                          ▼
                    lb:lch-compose  ──> 真实颜色
```

## 为什么是极坐标

Lab 的 `a`、`b` 是直角坐标：`C² = a² + b²`、`h = atan2(b, a)`。一条一维曲线改 a，
彩度和色相都跟着变——画面上看就是「整体偏色」。想「只加彩度」「只转色相」，
就得先在极坐标里表达，那正是本算子做的事。

转成 (L, C, h) 之后，三条曲线各自独立，再由 `lb:lch-compose` 一起算回颜色。
`LCh Split (Curves)` 的旧版用三张分量层 + 三个 LCh 混合模式，还要把分量值编码成
「混合模式读得出来的颜色」（色相层得造等 L*、等 C* 的色相圆）；一层写法把这些
全部省掉。

## 量程（实测标定，babl D50）

| 分量 | babl 单位 | 数据图 |
|---|---|---|
| L* | 0…100 | `L/100` |
| C* | 0…约 133.8（sRGB 全色域） | `C/140` |
| h | 0…360° | `h/360` |

彩度取 140 而不是 135：sRGB 最饱和的点是纯蓝，`C*≈133.8`，留一点余量让整圈都
装得下。8 位图上 1 码 ≈ 0.55 个 C* 单位，往返量化误差仍在 0.5 码内。

## 实测

`tools/check_lch_split.py` 里 `dual → compose` 恒等往返：32 位浮点 **0.0005 码**，
8 位 **0.49 码**。中性灰（C=0）的色相在 babl 侧无定义，算子把非有限值折成 0。

## 注意

- 输出是数据图，**不要直接看它当照片**。
- 它和 `lb:lch-compose` 配对使用，量程必须一致（改一边就要改另一边）。
