PS 的「滤镜 → 杂色」下面挂着一排：添加杂色、减少杂色、蒙尘与划痕、中间值。听起来是
四件不相干的事，其实是两个方向——**加噪**和**去噪**——加上一个「去掉孤立点」的特例。
我们按这个划分做了三个算子：`lb:add-noise`、`lb:reduce-noise`、`lb:dust-scratches`。

## 一、添加杂色：随机数必须可复现

PS 的添加杂色每次应用都换一批随机数。这意味着：同一个图层调两次参数，颗粒完全不同；
想对比「数量 8 和数量 10 哪个好」，你其实在同时比较颗粒和随机种子，判断不了。
要复现只能把图层复制一份存着，笨且占地。

真正的难点不是「随机」，是**分带处理下的随机**。GEGL 会把大图切成带、多线程分配，
如果按「处理到第几个像素」取随机数，切法一变结果就变——同一张图在不同线程数下出
不同的颗粒，这种不可复现比 PS 那种还糟。

所以种子的算法是：**第 `y` 行的随机数由 `seed` 与 `y` 混合得到**（`y` 参与哈希，
不是简单相加）。每一行自带一个独立的随机流，行内顺序推进。于是：

- 整张算完、切八带算、单线程算、八线程算 —— 结果**逐位相同**；
- 换个 `seed` 就换一整套颗粒，但同一 `seed` 永远回到同一套。

高斯用 Box–Muller，`u1, u2 ~ U(0,1]`：

```math
n = \sqrt{-2 \ln u_1} \cdot \cos(2\pi u_2)
```

`monochrome` 打开时三个通道共用一次 `n`（灰度颗粒），关掉则各取各的（彩色颗粒）。
`alpha` 一律不动——叠颗粒改的是像素值，不该改图层透明度。

## 二、减少杂色：只平均「像自己」的邻居

普通模糊会糊边，双边滤波不糊边但慢。PS 的减少杂色走的是中间那条路：sigma 滤波
（Lee, 1983）。对每个像素取 `(2r+1)²` 邻域，用**通道差的最大值** `d` 做权重：

```math
w = \max\left(0,\; 1 - \left(\frac{d}{t}\right)^2\right),
\qquad \text{out} = \frac{\sum w\,v}{\sum w}
```

`d > t` 的邻居权重为 0，所以边缘另一侧的像素**根本不会参与**这一侧的平均——
这就是它不糊边的原因，不需要任何边缘检测，也没有双边滤波那种指数运算。

三个参数各管一件事：

- `strength` 决定 `t`（越大抹得越狠）；
- `detail` 把 `t` 调小，保留更多纹理（PS 的「保留细节」）；
- `radius` 是搜索范围。PS 里这个是内部按强度推导的，我们把它放出来——半径 2 和半径 5
  的差别，比强度 40 和 50 的差别大得多。

`per-channel` 关闭时，`d` 取三通道最大差，**三通道共用一份权重**。这一点很关键：
彩色噪点是三个通道各自随机偏移，共用权重意味着它们被同一组邻居平均掉，
通道之间的比例关系不变，不会出现「降噪后颜色发灰」。打开时每通道各算各的，
适合处理单色噪点。

`strength=0` 时 `t=0`，只有完全相同的邻居能参与，结果逐位等于原图——这条是自检项。

## 三、蒙尘与划痕：孤点不能自己当选

这个滤镜的想法一句话说完：**把与周围差得太远的孤立像素，用邻域中值替换。**
中值而不是均值，是因为中值不会被少数极端值拉动——一个亮斑在均值里会被摊成一个
更大的灰斑，在中值里直接被丢掉。

但照抄「中值滤波」不行，原因很实在：**灰尘之所以是灰尘，就因为它和周围都不一样。**
假设一个亮点在纯色区域里，周围全是 0.5，而它自己是 0.9。阈值取 0.1 时，邻居因为
差得太远**全部被筛掉**，集合里只剩中心自己——中值就是它自己，像素原封不动。
也就是说，把中心放进集合，恰好在这个滤镜最该起作用的场合完全失效。

所以集合**排除中心**。剩下的邻居按阈值筛：

```math
\text{out} = \operatorname{median}\{\,v_k : |v_k - v_0| \le \tau,\; k \ne 0\,\}
```

一个都不合格时（比如硬边正中，两侧邻居都差得远），退回整窗中值。这条兜底是为了
「宁可轻微平滑，也不要留下孤点」：硬边正中的整窗中值会落在边缘上，看起来仍然是一条边，
而孤点会被彻底换掉。

`threshold=0` 时任何差异都算，集合为空 → 全部退回整窗中值，等于纯中值滤波（很糊）。
阈值开到 30 以上才只动「明显不对」的像素。

## 三个算子的顺序

| 想做的事 | 顺序 |
|---|---|
| 胶片颗粒 | `add-noise`（单色，数量 8）→ 可选 `unsharp-mask` |
| 高 ISO 清理 | `reduce-noise`（强度 60、细节 25）→ `unsharp-mask`（数量 60） |
| 扫底片 / 去坏点 | `dust-scratches`（半径 1、阈值 12）→ 其余照旧 |
| 做旧 | `add-noise` → `reduce-noise`（把颗粒磨得不均匀） |

**先降噪再锐化**，反过来会把噪点当边缘放大。

## 自检

`python tools/check_noise_sharpen.py` 23 项，覆盖三个算子：

- 数量 / 强度为 0 时逐位恒等；
- 同种子两次运行逐位相同，换种子结果不同；
- 单色时三通道扰动相等；
- 叠加噪点后均值不漂移（±3 码以内）；
- 降噪把噪点标准差压到一半以下、均值不漂移、硬边不动；
- 孤立亮点被抹掉、纯色图不变；
- 三个算子的 alpha 全部原样透传。

菜单在 `SuperMrWang → Noise` 下，三项排在一起。
